# packs

> `packs/` 是所有可下载方案包的入口目录；`miniapp-lab/` 是当前这批微信小程序相关方案包所在的下一级目录。

---

## 👀 这一层怎么理解

- `packs/`：一级目录，放各类方案包
- `miniapp-lab/`：二级目录，放微信小程序助手这组包

也就是说，这里不是一个叫 `packs/miniapp-lab` 的单独目录名，
而是：
- `packs`
  - `miniapp-lab`

---
