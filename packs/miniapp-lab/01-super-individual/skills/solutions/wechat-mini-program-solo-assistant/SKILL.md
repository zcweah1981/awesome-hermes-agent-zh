# 什么时候触发
当用户想先用一个 Agent 把微信小程序 MVP 拆成可开工方案时触发。

# 输入
- 业务目标
- 目标用户
- 最小闭环
- 当前约束（不做什么）

# 输出
- 页面清单
- 功能清单
- 数据结构建议
- 接口建议
- 开发顺序
- 测试检查单

# 最小步骤
1. 收敛一句话场景
2. 压出 MVP 边界
3. 输出页面/功能
4. 输出数据/接口
5. 输出开发顺序
6. 输出测试检查单

# 常见坑
- 范围过大
- 约束条件没写
- 把 UI 设计稿和实现包混成一个请求

# 验证方式
用 sample-input 跑一次，检查六类输出是否完整。
