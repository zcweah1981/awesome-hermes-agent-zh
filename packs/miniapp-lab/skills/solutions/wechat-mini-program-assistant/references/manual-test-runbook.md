# 手工验证 Runbook

## 测试目标
验证“微信小程序助手”是否真的能把一个小程序想法转成可开工 MVP 实施包。

## 前提
- 已加载 miniapp-lab profile 或等价 SOUL/skill
- 可在 CLI 或 ACP 中输入完整任务

## 测试输入
使用 examples/sample-input.md

## 触发方式
在 CLI 或 ACP 中提交输入，要求输出：页面清单、功能清单、数据结构建议、接口建议、开发顺序、测试检查单。

## 通过标准
- 六类输出全部出现
- 没把范围自动扩成支付/后台/裂变
- 超级个体版与团队协作版有清楚边界
- 输出可以被人直接拿去开工

## fail 判定
- 输出少于六类核心产物
- 大量空泛建议，缺少结构化结果
- 没有明确 MVP 边界
- 团队协作版没有交接物
