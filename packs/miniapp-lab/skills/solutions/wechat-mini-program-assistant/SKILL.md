# 什么时候触发
当用户已经明确要做微信小程序，并且希望先拿到“可开工结构化方案”而不是直接写代码时触发。

# 输入
- 业务目标
- 目标用户
- 最小闭环
- 当前约束（不做什么）

# 输出
- 页面清单
- 功能清单
- 数据结构建议
- 接口建议
- 开发顺序
- 测试检查单
- 超级个体版 / 团队协作版最小流程

# 最小步骤
1. 先收敛一句话场景
2. 压出 MVP 边界
3. 生成页面清单与功能清单
4. 生成数据结构和接口建议
5. 给出开发顺序与测试检查单
6. 判断是超级个体版还是团队协作版

# 常见坑
- 场景太大，默认想一步做到“完整商业产品”
- 没写清楚先不做什么
- 把 UI 设计稿、接口文档、代码实现混成一个请求
- 团队协作版只有角色名，没有交接产物

# 验证方式
用 sample-input 跑一次，检查输出是否完整覆盖：页面、功能、数据、接口、顺序、测试 六项。
