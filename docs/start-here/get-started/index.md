# 开始上手

![开始上手的 4 步路径图：基础使用、会话管理、技能精选、接入消息平台](../assets/rm2-3-get-started-index-01-daily-usage-path.png)

这一阶段只解决一件事：让你从“已经跑通一次”进入“开始稳定使用”。  
这里不再重复安装和首跑，也不直接跳去高级定制；重点是先把一个 Hermes 助手真正用顺。

---

## <img src="../assets/icon-hands-on.svg" width="18" alt="阶段目标图标" /> 这一阶段的目标

走完这一阶段，你应该已经完成四件事：

1. 你已经知道 Hermes 日常最常见的使用入口。  
2. 你已经知道最常用的一批 slash 命令和会话管理方式。  
3. 你已经知道第一批最值得先看的 Skills。  
4. 你已经知道什么时候该把 Hermes 接到消息平台里。  

这一阶段不解决的内容，我先帮你收住：
- 不展开持久人格
- 不展开持久记忆
- 不展开自定义模型与复杂 endpoint
- 不展开 MCP、API Server、Cron、ACP 这些系统层能力

这些都放到后面的阶段再学。

## <img src="../assets/icon-terminal-entry.svg" width="18" alt="适合谁图标" /> 什么人现在应该进入这一阶段

如果你符合下面任意一种情况，就应该从这里继续：

- 你已经跑通过一次 Hermes，但还不会稳定复现日常使用  
- 你已经能启动 Hermes，但还不知道平时最该先学什么  
- 你想先建立一条“每天都能用”的最短路径，而不是马上跳到高级定制  

现在做什么：
- 先把这一阶段理解成“单助手日常使用入门”，不是“高级玩法大全”。

为什么做这一步：
- 跑通一次，只能证明它能工作；开始上手，才会让它变成你能持续使用的工具。

看到什么算成功：
- 你已经知道自己接下来不是回去重复安装，而是进入稳定使用阶段。

如果没看到这个结果，先检查什么：
- 你是不是还没有真正完成第一次互动。
- 你是不是还把“安装成功”误当成“已经会用”。

当下面这些事已经成立，这一阶段就算通过：

- 你已经不再只会安装，而是开始按固定顺序学习日常使用。  
- 你已经知道这一阶段会覆盖基础使用、会话管理、Skills 和消息平台接入。
