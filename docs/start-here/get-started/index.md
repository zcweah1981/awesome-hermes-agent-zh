# 🚀 开始上手

![开始上手阶段路径图：把 Hermes 从“跑通一次”变成“每天会用”，依次经过基础使用、会话管理、Skills 精选、消息平台接入](../assets/rm2-3-get-started-index-01-daily-usage-path.png)

如果你刚刚已经拿到过一次正常回复，这一阶段只做一件事：
把 Hermes 从“已经能跑”变成“你真的会反复使用的日常助手”。

先别急着跳去持久人格、持久记忆、自定义模型或系统接入。
先把日常使用主线走顺，再扩能力。

---

## ✅ 你现在就该进入这一阶段吗

符合下面 3 条，就直接从这里继续：

- 你已经完成过一次 [第一次互动](../get-running/first-hello.md)
- 你已经能在终端里正常启动 Hermes
- 你现在最想解决的是“怎么稳定使用”，不是“怎么深度定制”

如果这 3 条里还有没成立的，先回到：
- [先跑起来](../get-running/index.md)

---

## 🎯 这一阶段会帮你拿到什么

走完这一阶段，你应该已经建立起这 4 个最小能力：

1. 会进入 Hermes，知道怎么提问、追问、退出、快速发一条请求  
2. 会把重要会话接住，知道怎么保存、命名、继续、恢复  
3. 会按场景挑第一批常用 Skills，而不是被完整目录淹没  
4. 会判断什么时候该把 Hermes 从 CLI 带到消息平台里  

一句话说完：
这一阶段不是继续“折腾安装”，而是开始形成你的日常使用路径。

这 4 步的关系不是并列阅读材料，而是一条从“会用”到“接入日常工作流”的连续路径。

如果你今天只想先推进一步：
- 就从第 1 步 [认识 Hermes 的基本使用方式](./basic-usage.md) 开始

---

## 🧩 这一阶段先不解决什么

这一阶段先收住，不往后抢内容：

- 持久人格
- 持久记忆
- 自定义模型与复杂 endpoint
- MCP、API Server、Cron、ACP 这类系统层能力

这些不是不重要，而是现在先不该抢在前面学。

---

## 🌱 什么时候算这一阶段已经过关

当下面这些事已经成立，这一阶段就算通过：

- 你已经能自然进入 Hermes 做日常提问  
- 你已经知道怎么保存、命名、继续一个会话  
- 你已经完成过至少一次按场景选择 Skills 的最小尝试  
- 你已经能判断自己是不是该进入消息平台接入  

真正的变化是：
你不再只是“装过一次 Hermes”，而是已经开始拥有一条稳定、可重复的使用路径。
