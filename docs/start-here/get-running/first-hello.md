# 配好 AI 大模型并完成第一次互动

现在你离跑通 Hermes 只差最后一小段：选一个可用模型，让 Hermes 成功启动，然后和它说第一句话。

做完这一步后，你不只是“装好了 Hermes”，而是真的拿到了第一次完整可用的对话闭环。

## 你现在还差什么

如果上一页你已经把 Hermes 装好了，那现在通常只差这两件事：

- 选一个你能使用的模型提供方和模型
- 启动 Hermes，并确认它能正常回复

常见可用来源包括 Nous Portal、OpenRouter、OpenAI，或者你自己的 OpenAI-compatible endpoint。你不需要一开始就把所有模型都研究清楚，先选一个你已经有账号和密钥的来源即可。

## 第 1 步：准备好模型账号或 API Key

开始前，先确认你手里已经有至少一项可用配置：

- 某个模型平台的账号
- 对应的 API Key
- 如果你走自定义接口路线，已经知道 endpoint 和模型名

如果这些还没准备好，这一步就先停在这里，先把模型访问条件补齐，再继续。

## 第 2 步：运行模型选择命令

在终端里执行：

```bash
hermes model
```

这个命令会带你进入模型选择流程。按照提示选择提供方、输入所需密钥，并确定一个默认模型。

![模型配置完成后的成功界面示意图](../assets/rm2-2-first-hello-01-model-setup-success.png)

## 第 3 步：启动 Hermes

模型选好后，直接启动：

```bash
hermes
```

如果一切正常，你会进入 Hermes 的交互界面，可以直接开始说话。

## 第 4 步：对 Hermes 说第一句话

你可以直接输入一句最简单的话，例如：

- 你好，Hermes
- 请介绍一下你自己
- 请确认你现在已经可以正常工作

只要你能正常发出消息，并收到一条完整回复，就说明这条链路已经跑通。

![第一次获得 Hermes 正常回复的终端示例](../assets/rm2-2-first-hello-02-first-reply-success.png)

## 第 5 步：如果没有正常回复，先看哪里

### 情况 1：模型选择时就卡住

优先检查：

- API Key 是否填写正确
- 账号权限或额度是否正常
- 自定义 endpoint 是否可访问
- 模型名是否选错

### 情况 2：`hermes` 能启动，但发消息没回复

优先检查：

- 当前默认模型是否已经正确保存
- 网络是否正常
- 终端里是否已经出现明显报错信息

### 情况 3：你不确定问题出在安装还是模型

先重新跑一次：

```bash
hermes doctor
```

如果 doctor 明确提示环境问题，先回头把环境修好；如果环境正常，再回到模型配置继续查。

## 看到什么，算这一阶段正式完成

满足下面 3 件事，就说明你已经把 Hermes 真正跑起来了：

1. 你已经通过 `hermes model` 选好一个可用模型。
2. 你可以用 `hermes` 正常进入交互界面。
3. 你已经收到 Hermes 的第一条正常回复。

这意味着你已经完成了“先跑起来”整个阶段。
