# 配好 AI 大模型并完成第一次互动

这一步完成后，你不只是“装好了 Hermes”，而是真的拿到了第一次完整可用的对话闭环。

## 第 1 步：先确认你已经准备好一套可用模型配置

现在做什么：
- 先确认你手里至少已经有下面这一套信息中的一套：
  - 某个模型提供方账号
  - 对应的 API Key
  - 如果你走自定义接口路线，还要知道 endpoint 和模型名

为什么做这一步：
- `hermes model` 不是空跑，它需要你真的有一套可用配置，后面才能正常启动和回复。

看到什么算成功：
- 你已经能明确说出：你接下来要用哪个提供方，以及你手里已经有对应凭据。

如果没看到这个结果，先检查什么：
- 你是不是还没有 API Key。
- 你是不是还不知道自己要用哪个提供方。
- 如果这些还没准备好，先不要继续下面步骤。

## 第 2 步：运行模型配置命令

现在做什么：
- 在终端里执行：

```bash
hermes model
```

为什么做这一步：
- 你要先把默认模型保存好，后面的 `hermes` 才知道该调用哪个模型。

### 第 2.1 步：选择提供方

现在做什么：
- 在配置流程里选择你要使用的模型提供方。

为什么做这一步：
- Hermes 需要先知道你接下来走哪条模型接入路径。

看到什么算成功：
- 你已经选中一个提供方，并进入下一步配置。

如果没看到这个结果，先检查什么：
- 你是不是还没有可用账号或 API Key。
- 你是不是选了自己实际上不能用的提供方。

### 第 2.2 步：输入 API Key 或连接信息

现在做什么：
- 按提示输入 API Key。
- 如果你走自定义接口路线，再按提示填写 endpoint 和模型名。

为什么做这一步：
- 这是 Hermes 真实调用模型所需的核心配置。

看到什么算成功：
- 你已经完成密钥或连接信息填写，并继续进入模型确认步骤。

如果没看到这个结果，先检查什么：
- API Key 是否填写错误。
- endpoint 是否可访问。
- 模型名是否写错。

### 第 2.3 步：保存默认模型

现在做什么：
- 按提示确认默认模型，并完成保存。

为什么做这一步：
- 只有保存成功，后面直接执行 `hermes` 时才会用这套配置启动。

看到什么算成功：
- 屏幕上出现“配置已保存”“默认模型已更新”或同类明确成功反馈。
- 配置流程已经结束，可以回到终端继续下一步。

如果没看到这个结果，先检查什么：
- 额度或权限是否正常。
- 当前网络是否正常。
- 模型是否被当前提供方支持。

## 第 3 步：启动 Hermes

现在做什么：
- 在终端里执行：

```bash
hermes
```

为什么做这一步：
- 你要验证前面的模型配置已经真正可用，而不是只停留在“配置过了”。

看到什么算成功：
- 你已经进入 Hermes 的交互界面。
- 屏幕上出现可继续输入消息的状态。

如果没看到这个结果，先检查什么：
- 默认模型是否真的保存成功。
- `hermes doctor` 是否已经通过。
- 当前网络是否正常。

## 第 4 步：发送第一条消息

现在做什么：
- 直接输入一句最简单的话，例如：
  - 你好，Hermes
  - 请介绍一下你自己
  - 请确认你现在已经可以正常工作

为什么做这一步：
- 这一步要验证的是“你已经能正常发消息，并收到真实回复”。

看到什么算成功：
- 你发出的消息已经被 Hermes 接收。
- Hermes 返回了一条完整自然语言回复。
- 对话结束后，界面仍然处于可继续输入的状态。

如果没看到这个结果，先检查什么：
- 终端里是否已经出现报错信息。
- 默认模型是否真的可用。
- 当前网络是否正常。

## 第 5 步：如果没有正常回复，先按位置排查

### 情况 A：在 `hermes model` 里就卡住了

先检查：
- API Key 是否填写正确。
- 账号权限或额度是否正常。
- endpoint 是否可访问。
- 模型名是否正确。

### 情况 B：`hermes` 能启动，但发消息后没回复

先检查：
- 默认模型是否已经保存成功。
- 当前网络是否正常。
- 终端里是否已经出现明显报错。

### 情况 C：你分不清是安装问题还是模型问题

先执行：

```bash
hermes doctor
```

如果 doctor 明确提示环境问题，先修环境；如果环境正常，再回到模型配置继续查。

## 这一步完成后，你应该看到什么

满足下面 3 件事，就说明你已经把 Hermes 真正跑起来了：

1. 你已经通过 `hermes model` 选好并保存了一个可用模型。
2. 你可以用 `hermes` 正常进入交互界面。
3. 你已经收到 Hermes 的第一条正常回复。

这意味着你已经完成了“先跑起来”整个阶段。
