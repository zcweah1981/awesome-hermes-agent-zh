# 配好 AI 大模型并完成第一次互动

现在 Hermes 已经装好了，但它还不能直接工作。
你还需要接上一个可用的 AI 大模型，然后在命令行里完成第一次正常互动。离开这页时，你应该已经能启动 Hermes，并看到它给出第一条正常回复。

---

## 1. 页面定位

这是“先跑起来”阶段的第四步，也是这个阶段的收口页。
它的任务是让用户把 Hermes 接上一个可用模型，并在命令行里完成第一次正常互动。

---

## 2. 页面目标

看完这页后，你应该已经完成下面四件事：

1. 完成模型选择或最小模型配置
2. 在命令行里成功启动 Hermes
3. 对 Hermes 说出第一句话
4. 得到 Hermes 的正常回复

---

## 3. 解决什么问题

这一页主要解决下面几个问题：

- 为什么 Hermes 装好了却还不能直接工作
- 最少还需要补齐什么
- 怎样用最短路径把模型接进去
- 怎样确认 Hermes 已经开始正常回应

---

## 4. 不解决什么

这一页不展开讲下面这些内容：

- 全部模型的详细对比
- 高级配置
- 多模型切换
- Web UI 接入
- 多助手协作

现在的目标只有一个：让第一次互动发生。

---

## 5. 页面结构

### 5.1 你现在还差什么

如果你已经装好了 Hermes，但启动后还不能顺利工作，通常还差这几样：

- 一个可用的 AI 大模型
- 对应的 API Key 或接入凭据
- 一次最小可运行配置

### 5.2 先选一个最容易开始的模型

第一次跑通时，不建议先研究最全的模型选型。
更稳的做法是：先选一个你当前最容易接入、最容易拿到 Key、最容易完成最小配置的模型。

如果你还拿不准，可以先去看模型选型的国内落地内容：

- [占位：国内落地 / 模型怎么选](TODO_LINK_CHINA_MODEL_SELECTION)

### 5.3 把模型接进去

先执行：

```bash
hermes model
```

这一命令的目标不是让你研究全部高级选项，而是尽快完成最小可用配置。
只要你能顺利选择或填入一个可用模型，先继续往下走。

### 5.4 启动 Hermes

模型准备好之后，直接启动：

```bash
hermes
```

如果一切正常，你会进入 Hermes 的命令行交互界面。

### 5.5 对 Hermes 说第一句话

现在不要测试复杂任务，先说一句最普通的话，确认链路通了就够：

- 你好，Hermes
- 请介绍一下你自己
- 请确认你现在已经可以正常工作

这一步的重点不是提示词技巧，而是确认“模型接入 + CLI 交互”已经打通。

### 5.6 一个最典型实例：先选一个最容易接入的模型

这一页采用的典型实例，不是指定某一个供应商，而是“先选一个你最容易接入的模型”。

原因很现实：

- 中文用户所在网络环境差异很大
- 可拿到的 Key、可接受的价格、可用的供应商也不同
- 第一波次内容更需要保证可执行，而不是提前替用户做最终选型

所以这一步只强调最小可跑通路径，不强行做大而全对比。

### 5.7 怎样算第一次互动成功

如果你已经做到下面这些，就说明第一次互动已经完成：

- `hermes` 能正常启动
- 你能在命令行里输入一句话
- Hermes 能返回一段正常回复
- 整个过程没有被模型配置错误卡住

### 5.8 模块完成后去哪里

完成这一步后，“先跑起来”阶段就闭环了。
