# 配好 AI 大模型并完成第一次互动

现在 Hermes 已经装好了，下一步就是接上一个可用的 AI 大模型，然后在命令行里和 Hermes 说上第一句话。  
**离开这页时，你应该已经能在命令行里启动 Hermes，并看到它正常回复。**

---

## <img src="../assets/icon-check-success.svg" width="18" alt="差什么图标" /> 你现在还差什么

如果你已经装好了 Hermes，但还没有完成第一次互动，现在还差的只有三样：

- 一个可用模型
- 一次最小模型配置
- 一次真实回复

现在做什么：
- 先把这三样当成这一页唯一目标，不要提前研究更复杂的 provider 或多模型玩法。

为什么做这一步：
- 这一页是“先跑起来”的收口页，任务不是选最强模型，而是把第一次互动闭环跑通。

看到什么算成功：
- 你已经知道这页只剩“模型配置 + 启动 Hermes + 第一次回复”三件事。

如果没看到这个结果，先检查什么：
- 你是不是还在回头研究安装细节。
- 你是不是把“最小配置”误解成“所有配置都要做完”。

---

## <img src="../assets/icon-run.svg" width="18" alt="选模型图标" /> 先选一个最容易开始的模型

如果你还不确定该选哪个，这一页就先走当前已经能跑通的一条最小路径，不做全部 provider 对比。

现在做什么：
- 不要求你在这一页比较所有模型，只要求你先确定一条能跑通的默认模型路径。

为什么做这一步：
- 这一页的目标是“第一次成功”，不是“模型研究”。

看到什么算成功：
- 你已经接受这一页先走一条可跑通路径，而不是继续扩展选择范围。

如果没看到这个结果，先检查什么：
- 你是不是又想把“模型选择”扩成一页大全。

---

## <img src="../assets/icon-build.svg" width="18" alt="模型配置图标" /> 把模型接进去

```bash
hermes model
```

![Hermes 模型设置成功图：在终端里完成 provider 和默认模型确认，系统返回模型已设置结果](../assets/rm2-2-first-hello-01-model-setup-success.png)

现在做什么：
- 在终端执行 `hermes model`。
- 选定一个可用 provider 和默认模型，并完成保存。

为什么做这一步：
- 只有默认模型配置完成，后面的 `hermes` 才知道该调用哪个模型。

看到什么算成功：
- 终端里已经明确显示当前 provider / model。
- 配置流程已经给出“默认模型已设置”或等价的成功反馈。

如果没看到这个结果，先检查什么：
- 你是不是还没有可用 provider。
- 你是不是选了自己实际上不能用的模型。
- 你是不是还没有把默认模型真正保存下来。

---

## <img src="../assets/icon-terminal-entry.svg" width="18" alt="启动图标" /> 启动 Hermes

```bash
hermes
```

现在做什么：
- 在模型配置完成后，启动 Hermes。

为什么做这一步：
- 你要验证前面的模型配置已经真正可用，而不是只停留在“配置过了”。

看到什么算成功：
- 你已经进入 Hermes 的交互状态，可以继续输入消息。

如果没看到这个结果，先检查什么：
- 默认模型是否真的保存成功。
- 安装页里的 `hermes version` 和 `hermes doctor` 是否已经通过。

---

## <img src="../assets/icon-check-success.svg" width="18" alt="第一次互动图标" /> 对 Hermes 说第一句话

你可以直接发一句最简单的话，例如：
- 你好，Hermes
- 请介绍一下你自己
- 请用一句中文确认你已经可以正常工作

![Hermes 第一次成功互动图：在终端里发出第一句话，并收到正常中文回复](../assets/rm2-2-first-hello-02-first-reply-success.png)

现在做什么：
- 在 Hermes 里发出第一句最简单的中文请求。

为什么做这一步：
- 这一步要验证的不是“界面能打开”，而是“你已经能真正发出请求并拿到回复”。

看到什么算成功：
- 你的输入已经发出去。
- Hermes 返回了一条正常中文回复。
- 命令执行完成后，终端仍然处于可继续使用的状态。

如果没看到这个结果，先检查什么：
- 模型配置是否真的保存成功。
- 当前 provider / model 是否可用。
- 网络或鉴权是否报错。

---

## <img src="../assets/icon-check-success.svg" width="18" alt="收口图标" /> 这一页什么时候算通过

满足下面三件事，这一页就通过：

1. 你已经通过 `hermes model` 配好一个可用模型。  
2. 你已经能正常启动 `hermes`。  
3. 你已经收到 Hermes 的第一条正常回复。  

这也意味着你已经完成了“先跑起来”整个阶段。
