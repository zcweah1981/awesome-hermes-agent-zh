# 先跑起来

这一阶段只解决一件事：让你第一次把 Hermes 真正跑通。
先别急着研究高级配置、外部系统或者工作流优化。现在最重要的，是先完成一次完整闭环：准备环境、进入终端、安装 Hermes、接上模型并拿到第一次回复。

---

## 1. 页面定位

这是《从这开始》模块的第一阶段入口页。
它不替代下面四个具体页面，只负责把“第一次跑通 Hermes”的最短路径讲清楚，并告诉你这一阶段到底做到什么才算完成。

---

## 2. 页面目标

看完这页后，你应该明确三件事：

1. 这一阶段只追求第一次成功跑通，不追求一步到位学全
2. 这一阶段包含哪四步，以及它们的顺序
3. 完成之后应该进入哪里继续学习

---

## 3. 解决什么问题

这一页主要解决的是“跑通路径”问题：

- 第一次使用 Hermes，最短应该走哪几步
- 为什么这四步不能随意跳

这些都重要，但不属于“先跑起来”的边界。

## 5. 页面结构

### 5.1 这一阶段的目标

这一阶段的目标非常单纯：

- 你已经有一个可用运行环境
- 你已经进入正确终端
- 你已经把 Hermes 装好
- 你已经接上一个可用模型
- 你已经拿到第一次正常回复

做到这里就够了。先别给自己加难度。

### 5.2 这四步分别是什么

1. [先准备运行环境](./prepare-environment.md)
2. [进入终端并连接服务器](./connect-terminal.md)
3. [把 Hermes 装上去](./install-hermes.md)
4. [配好 AI 大模型并完成第一次互动](./first-hello.md)

### 5.3 为什么建议按顺序走

这四步看起来简单，但顺序不要乱：

- 没有运行环境，就谈不上安装位置
- 没进入终端，就无法继续执行安装命令
- 没装好 Hermes，就谈不上接模型和第一次互动
- 没有第一次成功回复，就还不能算真的跑通

### 5.4 一个最典型的跑通场景

这一阶段默认采用的典型场景是：

- 你已经决定先用一台 Linux 云主机来跑 Hermes
- 你通过 SSH 进入服务器
- 你按官方推荐方式完成安装
- 你接上一个最容易开始的模型
- 你在命令行里收到 Hermes 的第一次正常回复

这条路径对大多数中文用户来说最清晰，也最容易稳定复现。

### 5.5 成功标志

如果你完成了下面这些，就说明这一阶段已经结束：

- Hermes 已经安装成功
- 模型已经接上
- 你已经能在命令行里和 Hermes 正常说第一句话
- Hermes 已经给出正常回复

### 5.6 下一步

完成后不要停在“能跑”这个状态，接下来应该进入：

- [开始上手](../get-started/index.md)
