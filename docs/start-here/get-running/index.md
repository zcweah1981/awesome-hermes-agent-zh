# 先跑起来

![先跑起来的 4 步路径图：准备环境、进入终端、安装 Hermes、第一次互动](../assets/rm2-2-get-running-index-01-four-step-flow.png)

## ✨ 这一阶段要解决什么

这一阶段只解决一件事：把 Hermes 真正跑通，并拿到第一条正常回复。

如果你现在还没有完成安装、模型配置和第一次对话，就先不要往后看更复杂的内容，先把这一段走通。

走完以后，你会得到：
- 一个已经装好的 Hermes
- 一个已经配置好的可用模型
- 一次真实可用的第一次对话闭环

---

## 👥 这一阶段适合谁

这一阶段适合你，如果你现在属于下面任意一种情况：
- 你第一次接触 Hermes，还没真正跑通过
- 你已经看过介绍，但还没完成第一次可用对话
- 你想先验证 Hermes 能不能真正工作，再决定要不要继续深入

如果你已经满足下面 3 件事，就不用停在这一阶段：
- 已经完成 Hermes 安装
- 已经配好一个可用模型
- 已经拿到第一条正常回复

---

## 📌 它和下一阶段有什么区别

“先跑起来”只关心最短闭环：
- 准备环境
- 进入终端
- 安装 Hermes
- 第一次互动

这里不展开：
- 日常怎么稳定使用 Hermes
- 会话怎么管理
- 常用命令先学哪些
- Skills 应该怎么挑

这些内容属于下一阶段“开始上手”。

换句话说：
- 这一阶段的目标是“先跑通”
- 下一阶段的目标才是“稳定上手”

---

## 🧭 你应该按哪 4 步走

先按下面这条顺序往下走，不要跳步：

| 步骤 | 当前重点 | 进入页面 |
| --- | --- | --- |
| 第 1 步：准备环境 | 先决定 Hermes 跑在本地、WSL2 还是云主机 | [先准备运行环境](./prepare-environment.md) |
| 第 2 步：进入终端 | 进入正确终端，并确认 Git 已经可用 | [进入终端并连接服务器](./connect-terminal.md) |
| 第 3 步：安装 Hermes | 完成安装，并确认 `hermes` 命令已经生效 | [把 Hermes 装上去](./install-hermes.md) |
| 第 4 步：第一次互动 | 配置模型，启动 Hermes，拿到第一次回复 | [配好 AI 大模型并完成第一次互动](./first-hello.md) |

---

## ✅ 什么算这一阶段完成

满足下面 3 件事，就算你已经把 Hermes 真正跑起来了：

1. 你已经在目标环境里完成 Hermes 安装。
2. 你已经通过 `hermes model` 选好一个可用模型。
3. 你已经在 `hermes` 交互界面里收到第一条正常回复。

---

## 🚦 你现在应该从哪一步开始

按你当前的状态直接选：

- 还没决定 Hermes 跑在哪里 → 从 [先准备运行环境](./prepare-environment.md) 开始
- 已经有环境，但还没进入正确终端 → 去 [进入终端并连接服务器](./connect-terminal.md)
- 已经在正确终端里，而且 Git 可用 → 去 [把 Hermes 装上去](./install-hermes.md)
- 已经安装好 Hermes，但还没完成第一次回复 → 去 [配好 AI 大模型并完成第一次互动](./first-hello.md)

如果你现在还拿不准，就默认从第 1 步开始。

---

当你已经跑通第一次完整闭环，就继续进入下一阶段：
