# 先跑起来

![先跑起来的 4 步路径图：准备环境、进入终端、安装 Hermes、第一次互动](../assets/rm2-2-get-running-index-01-four-step-flow.png)

这一阶段只解决一件事：让你第一次把 Hermes 真正跑通。  
不要在这里提前研究高级配置，也不要试图一次搞懂所有功能。

---

## <img src="../assets/icon-run.svg" width="18" alt="先跑起来图标" /> 这一阶段的目标

走完这一阶段，你应该已经完成三件事：

1. 你已经把 Hermes 安装到一个可用环境里。  
2. 你已经接上一个可用模型。  
3. 你已经拿到 Hermes 的第一次正常回复。  

这一阶段不解决的内容，我这里直接帮你收住：
- 不展开斜杠命令深度用法
- 不展开 Skills
- 不展开持久记忆
- 不展开外部系统接入

这些都放到后面的阶段再学。

## <img src="../assets/icon-terminal-entry.svg" width="18" alt="顺序图标" /> 建议阅读顺序

按上面的顺序依次完成，不要跳步。

如果你是第一次安装用户，或者从来没有在终端里跑通过 Hermes，就默认从第 1 步开始。

如果你中途停过，也按当前状态直接回到对应步骤继续，不要提前跳到后面的阶段。

## <img src="../assets/icon-check-success.svg" width="18" alt="成功图标" /> 成功标志

当下面这件事已经成立，这个阶段就完成了：

- 你已经完成安装、接入模型，并成功得到 Hermes 的第一次回复。

换句话说，这一阶段真正追求的是“第一次成功跑通”，不是“先把所有能力看懂”。
