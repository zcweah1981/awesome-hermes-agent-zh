# 先跑起来

这一阶段只解决一件事：让你第一次把 Hermes 真正跑通。
不要在这里提前研究高级配置，也不要试图一次搞懂所有功能。现在最重要的，是先完成一次完整闭环：准备环境、进入终端、安装 Hermes、接上模型，并拿到第一次正常回复。

---

## 1. 页面定位

这是“从这开始”模块的第一阶段入口页。
它不替代下面四个具体页面，只负责把“第一次跑通 Hermes”的最短路径讲清楚。

## 3. 默认顺序

按上面的顺序依次完成，不要跳步。

如果你还没决定 Hermes 跑在哪里，就先看运行环境；
如果你还没进入正确终端，就先别急着安装；
如果你还没看到第一次正常回复，就还不算这一阶段真的完成。

---

## 4. 成功标志

当你已经完成安装、接入模型，并成功得到 Hermes 的第一次回复，这个阶段就完成了。
