## 5. 页面结构

### 5.1 官方推荐安装方式

对于第一次跑通的用户，最稳妥的方式就是直接采用官方推荐的一键安装路径。
这样做的好处是：

- 路径最短
- 跟官方后续文档最容易对齐
- 出问题时也更容易排查

### 5.2 直接开始安装

执行下面这条命令：

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

如果你的环境网络受限，这一步可能会比较慢，或者需要你先解决网络问题。

### 5.3 安装完成后重新加载终端环境

安装完成后，建议重新加载一次当前 shell 环境。

#### Bash

```bash
source ~/.bashrc
```

#### Zsh

```bash
source ~/.zshrc
```

如果你不确定自己现在用的是哪种 shell，最简单的办法是先重新打开一个终端窗口再继续。

### 5.4 检查有没有安装成功

接下来执行：

```bash
hermes version
hermes doctor
```

如果 `hermes version` 能正常返回版本信息，说明命令已经就位。
如果 `hermes doctor` 没有明显错误，说明当前环境基本可继续下一步。

### 5.5 一个最典型实例：官方一键安装

对第一次安装的用户来说，最典型、也最推荐的实例就是直接走官方一键安装。

你不需要在这一步先研究多种安装路径，也不需要一开始就挑最复杂的自定义方式。
先用官方推荐路径把 Hermes 装上去，才是最低阻力路线。

### 5.6 安装失败时先看什么

如果现在安装没有成功，先检查最小集合，不要立刻发散：

- 安装命令有没有复制完整
- 当前网络是否正常
- 你现在是不是在正确的终端环境里
- Git 是否已经可用
- 终端里有没有出现明显报错信息

如果确认以上都没问题，再进入后续更完整的安装排障页。
