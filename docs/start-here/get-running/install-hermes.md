# 把 Hermes 装上去

这一步完成后，你的环境里应该已经可以直接使用 `hermes` 命令。

## 第 1 步：先确认你已经满足安装前提

现在做什么：
- 确认你已经在正确终端里。
- 确认 `git --version` 已经能正常返回版本号。
- 确认当前网络正常。

为什么做这一步：
- 如果这 3 件事没准备好，安装命令很容易中途失败。

看到什么算成功：
- 你已经可以明确回答这 3 个问题：
  - 我现在就在目标环境里。
  - Git 已经可用。
  - 当前网络可用。

如果没看到这个结果，先检查什么：
- 回上一页重新确认终端环境和 Git 状态。

## 第 2 步：执行官方推荐安装命令

现在做什么：
- 在终端里执行：

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

为什么做这一步：
- 这是官方推荐安装方式，会自动完成大部分安装准备。

看到什么算成功：
- 终端开始输出安装过程。
- 你能看到下载、安装或配置相关的真实输出。
- 命令执行完成后，没有停在明显的报错信息上。

如果没看到这个结果，先检查什么：
- 安装命令是否完整复制。
- 当前网络是否正常。
- 你是不是在正确的 Linux / macOS / WSL2 终端里执行。

## 第 3 步：重新加载当前 shell

现在做什么：
- 先执行下面这条命令，确认你当前用的是哪种 shell：

```bash
echo $SHELL
```

- 如果结果里是 Bash，再执行：

```bash
source ~/.bashrc
```

- 如果结果里是 Zsh，再执行：

```bash
source ~/.zshrc
```

为什么做这一步：
- 安装结束后，重新加载 shell 才能让新的 `hermes` 命令立刻生效。

看到什么算成功：
- `echo $SHELL` 已经让你明确知道自己当前用的是哪种 shell。
- `source` 命令执行后没有报错。
- 终端回到提示符，允许继续输入下一条命令。

如果没看到这个结果，先检查什么：
- 你是不是搞错了自己当前使用的 shell。
- 对应的配置文件是否存在。

## 第 4 步：确认 `hermes` 命令已经生效

现在做什么：
- 先执行：

```bash
hermes version
```

- 再执行：

```bash
hermes doctor
```

为什么做这一步：
- 只有这两条命令都能正常工作，才说明安装真正完成，而且当前环境适合进入下一步。

看到什么算成功：
- `hermes version` 返回真实版本信息。
- `hermes doctor` 完成检查，并给出可继续使用的结果。
- 执行完后，终端回到提示符，可以继续下一页。

如果没看到这个结果，先检查什么：
- 如果 `hermes version` 提示 `command not found`：说明 shell 还没正确重新加载，或者 PATH 还没生效。
- 如果 `hermes doctor` 报错：先按它给出的提示修当前环境，再重新执行一次。

## 第 5 步：只要没通过，就先复查，不要往下跳

### 情况 A：安装命令中途失败

先检查：
- 网络是否正常。
- 命令是否复制完整。
- 当前终端是否真的是 Linux / macOS / WSL2 终端。

### 情况 B：`hermes` 找不到

先检查：
- 你有没有执行 `echo $SHELL` 确认 shell。
- 你有没有执行正确的 `source ~/.bashrc` 或 `source ~/.zshrc`。
- 重新加载后，是否再次执行了 `hermes version`。

### 情况 C：`hermes doctor` 仍然报错

先检查：
- 报错具体指向什么环境问题。
- 当前缺的是网络、依赖，还是别的基础条件。
- 修完后，再重新执行一次：

```bash
hermes doctor
```

## 这一步完成后，你应该看到什么

满足下面两件事，就说明 Hermes 已经装好了：

1. 终端已经能识别 `hermes` 命令。
2. 你执行 `hermes version` 和 `hermes doctor` 时，都已经看到正常输出。
