# 先准备运行环境

在安装 Hermes 之前，你需要先准备一台运行它的电脑。
这台电脑可以是你的本地电脑，比如 macOS、Windows WSL2 或 Linux；也可以是云主机，比如阿里云、腾讯云，或者其他国内外云主机。
**对大多数用户，我们更推荐优先使用云主机来安装和运行 Hermes。**

---

## 1. 页面定位

这是“先跑起来”阶段的第一步。
它不负责安装 Hermes，也不负责配置 AI 大模型。
它只负责帮你先确定：Hermes 准备运行在哪里。

---

## 2. 页面目标

用户离开这页时，应该明确三件事：

1. 自己准备在哪个环境中运行 Hermes
2. 如果还没有环境，应该去哪里准备
3. 准备好之后，下一步应该进入哪里

---

## 3. 解决什么问题

- 本地 macOS、Linux、Windows WSL2、云主机分别是什么角色
- 自己当前应该选哪一种运行环境
- 如果还没有服务器，应该跳去“国内落地”
- 如果已经有环境，应该继续往后走

---

## 4. 不解决什么

这一页不展开讲：

- Hermes 怎么安装
- AI 大模型怎么配置
- 命令行怎么使用
- Web UI 和 CLI 的详细对比
- 远程连接细节

---

## 5. 页面结构

### 5.1 你可以在哪些环境运行 Hermes

| 运行环境 | 适合谁 | 建议 |
|---|---|---|
| 本地 macOS | 使用苹果电脑、想先快速尝试的人 | 可用 |
| 本地 Linux | 已有 Linux 环境或习惯 Linux 的人 | 可用 |
| Windows WSL2 | 使用 Windows 的用户 | 可用，但建议先看 WSL2 单独说明 |
| 云主机 | 想正式安装、长期运行、远程访问的人 | 优先推荐 |

### 5.2 如果你没有运行环境怎么办

如果你还没有准备好服务器或运行环境，可以先去“国内落地”模块查看：

### 5.3 如果你已经有运行环境

如果你已经满足下面任意一种情况，就可以直接进入下一步：

- 已经有一台可用的 Linux 云主机

- 已经准备好本地 Linux 环境
- 已经完成 Windows WSL2 准备
