# 先准备运行环境

在安装 Hermes 之前，你需要先决定：它到底跑在哪台机器上。
这台机器可以是你的本地电脑，也可以是一台云主机。对大多数想稳定使用、长期在线、方便远程访问的用户来说，优先选择云主机会更省心。

---

## 1. 页面定位

这是“先跑起来”阶段的第一步。
它不负责安装 Hermes，也不负责配置模型，只负责帮你先把“运行位置”定下来。

---

## 2. 页面目标

看完这页后，你应该明确三件事：

1. 自己准备在哪个环境中运行 Hermes
2. 如果还没有环境，应该先去哪里准备
3. 环境确定后，下一步该进入哪一页

---

## 3. 解决什么问题

这一页主要帮你解决下面几个选择问题：

- 本地 macOS、Linux、Windows WSL2、云主机分别适合什么情况
- 自己当前更适合哪一种运行环境
- 如果还没有服务器，应该去哪里补齐
- 如果已经准备好了，应该继续往下走哪一步

## 5. 页面结构

### 5.1 你可以在哪些环境运行 Hermes

| 运行环境 | 适合谁 | 建议 |
|---|---|---|
| 本地 macOS | 想先快速体验、手上就是 Mac 的用户 | 可用 |
| 本地 Linux | 已经长期使用 Linux 的用户 | 可用 |
| Windows WSL2 | 使用 Windows、愿意先准备 WSL2 的用户 | 可用，但建议先确保 WSL2 已就绪 |
| 云主机 | 想正式安装、稳定运行、便于远程访问的用户 | 优先推荐 |

### 5.2 为什么大多数用户更适合云主机

如果你只是想快速试一下，本地环境当然可以。
但如果你希望后面继续接消息平台、长期在线、随时远程进入，云主机通常更稳，也更符合后面的使用路径。

特别是下面这些情况，更建议直接从云主机开始：

- 你不想受本地电脑开关机影响
- 你后续大概率会长期运行 Hermes
- 你希望随时通过 SSH 远程进入
- 你后面可能还要接更多服务

### 5.3 如果你还没有运行环境怎么办

如果你现在还没有服务器，也还没决定怎么准备运行环境，不用卡在这里。

### 5.4 如果你已经有运行环境

只要你满足下面任意一种情况，就可以继续进入下一步：

- 已经有一台可用的 Linux 云主机
- 已经准备好本地 macOS 环境
- 已经准备好本地 Linux 环境
- 已经完成 Windows WSL2 准备

这一步的关键不是“环境有多高级”，而是“它能不能成为你继续安装 Hermes 的地方”。

### 5.5 一个最典型实例：阿里云云主机

如果你完全没有现成环境，又希望后面走得更顺，最典型的做法就是先准备一台阿里云 Linux 云主机。

你不需要在这页把购买、镜像、计费方式全部搞懂。对这一步来说，只需要知道：

- 你可以用一台云主机作为 Hermes 的运行位置
- 它更适合长期在线和后续扩展
- 选好后，你就应该进入终端连接这一步
