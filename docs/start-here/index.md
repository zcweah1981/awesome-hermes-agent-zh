# 从这开始

![Hermes 学习路径总览](./assets/rm2-learning-path.svg)

如果你是第一次来到 Hermes 中文站，不要把这里当成功能目录去翻。
这一组内容的作用，是帮你判断：你现在处在哪个阶段，应该先解决什么问题，下一步该去哪里。

## 先用一句话理解这页

《从这开始》不是资料堆，而是一条学习路径。
它从“先跑通一次”开始，逐步带你走到“真正搭起自己的 AI 工作流”。

## 四个阶段怎么选

| 阶段 | 适合谁 | 这阶段主要解决什么 | 学完你能达到什么 | 入口 |
|---|---|---|---|---|
| <img src="./assets/icon-run.svg" width="22" alt="先跑起来图标" /> <br /><strong>先跑起来</strong> | 还没跑通过 Hermes，或者还没完成第一次正常互动的人 | 运行环境、终端、安装 Hermes、接上模型并完成第一次互动 | 你能真正把 Hermes 跑通，并拿到第一条正常回复 | [进入这一阶段](./get-running/index.md) |
| <img src="./assets/icon-hands-on.svg" width="22" alt="开始上手图标" /> <br /><strong>开始上手</strong> | 已经装过一次，但还不会稳定使用的人 | 日常使用方式、会话管理、常用命令、第一批值得先看的 Skills | 你能把 Hermes 当成日常助手稳定用起来 | [进入这一阶段](./get-started/index.md) |
| <img src="./assets/icon-advanced.svg" width="22" alt="玩出花样图标" /> <br /><strong>玩出花样</strong> | 已经会用 Hermes，想让它更像你、更顺手的人 | 人格、记忆、模型、工具开关、终端主题 | 你能把一个助手调成更符合自己习惯的工作方式 | [进入这一阶段](./advanced-usage/index.md) |
| <img src="./assets/icon-build.svg" width="22" alt="自己造东西图标" /> <br /><strong>自己造东西</strong> | 想把 Hermes 接进工作流、编辑器或外部系统的人 | Profiles、外部记忆、MCP、API、自动化、IDE | 你能从“用一个助手”进入“搭一套系统” | [进入这一阶段](./build-your-own/index.md) |

## 如果你不想自己判断，就按这个最简单的分流走

- 还没跑通过一次 → 去“先跑起来”
- 已经跑通过，但不够稳定 → 去“开始上手”
- 已经会用，想更顺手 → 去“玩出花样”
- 想接系统、做自动化、多助手协作 → 去“自己造东西”

如果你还是拿不准，默认从“先跑起来”开始。

## 推荐阅读顺序

第一次系统看 Hermes，建议按这个顺序往下走：

1. [先跑起来](./get-running/index.md)
2. [开始上手](./get-started/index.md)
3. [玩出花样](./advanced-usage/index.md)
4. [自己造东西](./build-your-own/index.md)

你不需要一次把四段都看完。
先把当前这一段走通，再往下推进，理解会更稳。
