# 从这开始

如果你是第一次接触 Hermes，最容易踩的坑不是不会装，而是一上来就把文档当资料库乱翻。
这一组内容不是按功能堆料，而是按学习路径来带你走：先跑起来，再开始上手，然后玩出花样，最后自己造东西。

---

## 1. 页面定位

这是《从这开始》模块的总入口页。
它不负责展开安装命令、模型配置或高级接入步骤，只负责帮你判断：你现在处在什么阶段，下一步该往哪里走。

---

## 2. 页面目标

看完这页后，你应该明确四件事：

1. “从这开始”是一条学习路径，不是一堆零散资料
2. 四个阶段各自解决什么问题
3. 你现在最适合从哪个阶段进入
4. 后续默认阅读顺序是什么

---

## 3. 解决什么问题

这一页主要帮你解决下面几个判断问题：

- 第一次接触 Hermes，应该先学什么
- 已经装过一次，但还不会稳定使用，应该补哪一段
- 想做个性化配置，应该跳到哪里
- 想把 Hermes 接进自己的工作流或系统，应该从哪里开始

换句话说，它解决的是“怎么走这条路”，不是“每一步具体怎么做”。

---

## 4. 不解决什么

这一页不展开讲下面这些内容：

- 具体安装命令
- 具体模型配置步骤
- 具体斜杠命令怎么用
- 具体 Skills 怎么挑
- MCP、API Server、Automation 等高级能力的实操细节

如果你已经知道自己要做哪件事，请直接进入对应阶段页，不用在这里停太久。

---

## 5. 页面结构

### 5.1 为什么这里按学习路径组织

Hermes 的能力很多，但对大多数中文用户来说，真正高效的顺序不是“先把所有功能名词看完”，而是：

1. 先把它跑起来
2. 再让自己会稳定地用
3. 再去做个性化和效率优化
4. 最后再进入系统化搭建

这样做的好处是，你每走一步都能马上得到一个可用结果，不会在最开始就被配置细节压住。

### 5.2 四个阶段分别是什么

#### 第一阶段：先跑起来

这一阶段只追求一件事：让 Hermes 真正跑通，并完成第一次正常互动。
如果你还没有运行环境、还没打开终端、还没安装 Hermes，默认就从这里开始。

入口：
- [先跑起来](./get-running/index.md)

#### 第二阶段：开始上手

这一阶段解决的不是“能不能装上”，而是“平时到底怎么用”。
你会开始理解 Hermes 的基本使用方式、常用命令、会话管理，以及第一批最值得看的 Skills。

入口：
- [开始上手](./get-started/index.md)

#### 第三阶段：玩出花样

当你已经不是“能用就行”，而是希望它更像你、更顺手，这一阶段才有意义。
这里会进入持久人格、持久记忆、自定义模型、工具开关、终端外观这些内容。

入口：
- [玩出花样](./advanced-usage/index.md)

#### 第四阶段：自己造东西

如果你已经不满足于“用一个助手”，而是想把 Hermes 接进自己的工作流、编辑器、外部系统，甚至做成自动化能力，就进入这一阶段。
这里开始从单助手使用，转向系统化使用。

入口：
- [自己造东西](./build-your-own/index.md)

### 5.3 你应该从哪一段开始

你可以直接按下面的状态判断：

| 你现在的状态 | 建议入口 |
|---|---|
| 第一次接触 Hermes，还没跑通过 | [先跑起来](./get-running/index.md) |
| 已经装过一次，但不会稳定使用 | [开始上手](./get-started/index.md) |
| 已经会日常使用，想做更像自己的配置 | [玩出花样](./advanced-usage/index.md) |
| 想接外部系统、做多助手或自动化 | [自己造东西](./build-your-own/index.md) |

如果你拿不准，默认从“先跑起来”开始，最稳。

### 5.4 默认阅读顺序

如果你是第一次系统学习 Hermes，建议按下面顺序往下走：

1. [先跑起来](./get-running/index.md)
2. [开始上手](./get-started/index.md)
3. [玩出花样](./advanced-usage/index.md)
4. [自己造东西](./build-your-own/index.md)

### 5.5 一个最典型的进入方式

如果你是第一次接触 Hermes，可以把这条路径理解成：

- 先让 Hermes 真正回复你一次
- 再学会平时怎么和它配合
- 再把它调成你喜欢的工作方式
- 最后再把它接进更完整的个人系统

不要一上来就研究所有高级能力。先把第一条路走通，后面的理解会轻松很多。

### 5.6 下一步

如果你没有特别明确的目标，直接进入第一阶段即可：

- [进入“先跑起来”](./get-running/index.md)

如果你已经知道自己现在处在哪个阶段，也可以直接跳到对应入口页。

## 6. 单独实例

这一页采用的典型实例是：第一次接触 Hermes 的新用户。

他的真实状态通常不是“什么都不懂”，而是：

- 听说过 Hermes
- 想尽快试一次
- 还不知道先装、先配、先学哪一部分
- 容易被文档里的名词和扩展能力带偏

所以这页的写法不会把所有功能摊开，而是先把学习顺序定住。对新用户来说，这比一开始列一长串功能更有帮助。
