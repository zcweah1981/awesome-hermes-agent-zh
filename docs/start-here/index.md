# 从这开始

如果你是第一次接触 Hermes，不要试图一次读完整个文档库。
这里不是按功能把资料堆在一起，而是按学习路径带你往前走：先跑起来，再开始上手，然后玩出花样，最后自己造东西。

## 为什么这里按学习路径组织

Hermes 的能力很多，但大多数用户真正需要的不是先看完所有概念，而是先知道自己现在该做什么、下一步该去哪里。

所以《从这开始》不按资料分类来排，而是按一条最容易走通的路径来组织：

- 先让你把 Hermes 真正跑通
- 再让你学会一个助手的日常使用
- 再让它更像你、更顺手
- 最后带你进入系统化使用

## 四个阶段分别是什么

### 先跑起来

如果你还没有跑通过 Hermes，或者还没有完成第一次正常互动，就从这里开始。
这一阶段只解决一件事：让 Hermes 真正跑起来。

入口：
- [先跑起来](./get-running/index.md)

### 开始上手

如果你已经装过一次 Hermes，但还不会稳定使用，就进入这一阶段。
这里会带你认识基础日常使用方式、常用命令、会话管理，以及第一批最值得看的 Skills。

入口：
- [开始上手](./get-started/index.md)

### 玩出花样

如果你已经会日常使用，接下来想让 Hermes 更像你、更顺手，就进入这一阶段。
这里开始进入持久人格、持久记忆、自定义模型、工具开关和终端外观这些内容。

入口：
- [玩出花样](./advanced-usage/index.md)

### 自己造东西

如果你已经不满足于“用一个助手”，而是想把 Hermes 接进自己的工作流、编辑器或外部系统，就进入这一阶段。
这里开始从单助手使用，转向系统化使用。

入口：
- [自己造东西](./build-your-own/index.md)

## 你应该从哪一段开始

按你当前的状态选择入口：

| 你现在的状态 | 建议入口 |
|---|---|
| 第一次接触 Hermes，还没跑通过 | [先跑起来](./get-running/index.md) |
| 已经跑通过一次，但不会稳定使用 | [开始上手](./get-started/index.md) |
| 想做更长期的个性化配置 | [玩出花样](./advanced-usage/index.md) |
| 想搭自己的工作流或系统 | [自己造东西](./build-your-own/index.md) |

如果你拿不准，默认从“先跑起来”开始。

## 默认阅读顺序

如果你是第一次系统学习 Hermes，建议按下面顺序往下走：

1. [先跑起来](./get-running/index.md)
2. [开始上手](./get-started/index.md)
3. [玩出花样](./advanced-usage/index.md)
4. [自己造东西](./build-your-own/index.md)
