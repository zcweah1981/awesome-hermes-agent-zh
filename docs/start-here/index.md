# 从这开始

![Hermes 学习路径总览](./assets/rm2-learning-path-gemini-final.jpg)

## ✨ 你在这里能很快知道什么

来到这一页，你应该快速弄清四件事：

- 我现在更适合从哪一段开始
- 这一段主要会帮我解决什么问题
- 学完这一段以后，我能达到什么状态
- 下一步应该进入哪个阶段页

---

## 📌 它和普通文档站有什么不同

普通文档站更像“功能目录”：
先把功能、命令、配置项都列出来，再由你自己决定从哪里开始。

这里不是这样。
这里按学习路径组织，先帮你判断：

- 你现在最该先解决什么问题
- 哪些内容现在不用急着看
- 哪一段学完以后，再进入下一段最顺

所以你在这里看到的，不是资料分类，而是四个清晰的学习阶段。

---

## 🧭 四个阶段怎么选

### <img src="./assets/icon-run.svg" width="20" alt="先跑起来图标" /> [先跑起来](./get-running/index.md)
适合还没跑通 Hermes、还没完成第一次正常互动的人。  
你会解决：环境、终端、安装、模型接入。  
结果：先把 Hermes 真正跑通。

### <img src="./assets/icon-hands-on.svg" width="20" alt="开始上手图标" /> [开始上手](./get-started/index.md)
适合已经装过一次，但还不会稳定使用的人。  
你会解决：基本使用、会话管理、常用命令、第一批 Skills。  
结果：从“跑通一次”进入“稳定可用”。

### <img src="./assets/icon-advanced.svg" width="20" alt="玩出花样图标" /> [玩出花样](./advanced-usage/index.md)
适合已经会用 Hermes，想让它更像你的人。  
你会解决：人格、记忆、模型、工具工作流。  
结果：让一个助手开始变得顺手。

### <img src="./assets/icon-build.svg" width="20" alt="自己造东西图标" /> [自己造东西](./build-your-own/index.md)
适合想把 Hermes 接进工作流、做自动化和外部接入的人。  
你会解决：Profiles、外部记忆、MCP、API、IDE。  
结果：从“用一个助手”进入“搭一套系统”。

---

## 📖 默认顺序

第一次系统看 Hermes，建议按这个顺序往下走：

1. [先跑起来](./get-running/index.md)
2. [开始上手](./get-started/index.md)
3. [玩出花样](./advanced-usage/index.md)
4. [自己造东西](./build-your-own/index.md)

如果你现在还拿不准，就默认从 [先跑起来](./get-running/index.md) 开始。
