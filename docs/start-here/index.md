# 从这开始

![Hermes 学习路径总览](./assets/rm2-learning-path.svg)

Hermes 的能力很多，但你不需要一上来就把所有东西都弄明白。
这页不是资料目录，也不是功能大全。它只做一件事：帮你找到最适合自己的起点。

## 这条学习路径怎么走

《从这开始》按一条更容易走通的顺序组织：

先跑起来 → 开始上手 → 玩出花样 → 自己造东西

这不是唯一顺序，但它最适合大多数中文用户：先让 Hermes 真正跑通，再让它稳定好用，最后再进入更个性化、更系统化的阶段。

## 四个阶段怎么选

### <img src="./assets/icon-run.svg" width="22" alt="先跑起来图标" /> [先跑起来](./get-running/index.md)

如果你还没跑通过 Hermes，或者还没完成第一次正常互动，就从这里开始。

适合谁：
- 第一次接触 Hermes 的人
- 已经看过一些资料，但还没真正跑起来的人
- 想先用一条最短路径验证 Hermes 能不能工作的用户

这一阶段主要解决什么：
- 运行环境怎么选
- 终端怎么进入
- Hermes 怎么安装
- 模型怎么接上
- 怎样拿到第一次正常回复

学完你能达到什么：
- 你能真正把 Hermes 跑通
- 你知道一条最基础、最稳的使用起点

---

### <img src="./assets/icon-hands-on.svg" width="22" alt="开始上手图标" /> [开始上手](./get-started/index.md)

如果你已经装过一次 Hermes，但还不会稳定使用，这一阶段最适合你。

适合谁：
- 已经跑通过一次，但还不熟的人
- 想开始把 Hermes 当成日常助手的人
- 需要先建立“平时怎么用”感觉的人

这一阶段主要解决什么：
- 日常使用方式
- 会话管理
- 常用命令
- 第一批值得先看的 Skills
- 从命令行走向更顺手的日常协作方式

学完你能达到什么：
- 你能把 Hermes 稳定地用起来
- 你知道日常使用时最该先掌握哪些东西

---

### <img src="./assets/icon-advanced.svg" width="22" alt="玩出花样图标" /> [玩出花样](./advanced-usage/index.md)

如果你已经会用 Hermes，接下来想让它更像你、更顺手，就进入这一阶段。

适合谁：
- 已经形成基本使用习惯的人
- 想做个性化配置的人
- 希望助手更贴合自己表达和工作方式的人

这一阶段主要解决什么：
- 人格
- 记忆
- 模型
- 工具开关
- 终端主题

学完你能达到什么：
- 你能把一个助手调成更符合自己习惯的工作方式
- 你会明显感觉它不是“能用”，而是“顺手”

---

### <img src="./assets/icon-build.svg" width="22" alt="自己造东西图标" /> [自己造东西](./build-your-own/index.md)

如果你已经不满足于“用一个助手”，而是想把 Hermes 接进自己的工作流、编辑器或外部系统，就进入这一阶段。

适合谁：
- 想做多助手协作的人
- 想把 Hermes 接进系统的人
- 想做自动化、外部记忆、API、IDE 集成的人

这一阶段主要解决什么：
- Profiles
- 外部记忆
- MCP
- API
- 自动化
- IDE 集成

学完你能达到什么：
- 你能从“用一个助手”进入“搭一套系统”
- 你会开始拥有自己的 Hermes 工作流

## 如果你不想自己判断，就按这个最简单的分流走

- 还没跑通过一次 → 去 [先跑起来](./get-running/index.md)
- 已经跑通过，但不够稳定 → 去 [开始上手](./get-started/index.md)
- 已经会用，想更顺手 → 去 [玩出花样](./advanced-usage/index.md)
- 想接系统、做自动化、多助手协作 → 去 [自己造东西](./build-your-own/index.md)

如果你还是拿不准，默认从 [先跑起来](./get-running/index.md) 开始。
