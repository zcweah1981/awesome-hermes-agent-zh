# 从这开始

![Hermes 学习路径总览](./assets/rm2-learning-path.svg)

Hermes 的能力很多，但你不需要一上来就把所有资料都看完。
这个站点不是把功能、命令、配置项一股脑摊开的“文档资料站”，而是按学习路径帮你判断：你现在最该先解决什么问题，学完这一段以后能走到哪里。

## 这页和普通文档站的区别

普通文档站更像“功能目录”：你先看到有什么，再自己决定从哪里看起。

这里不一样。
这里更像一条分阶段的学习路径：

- 先帮你把 Hermes 跑起来
- 再帮你学会一个助手的日常使用
- 再让它更像你、更顺手
- 最后再进入系统化搭建

所以这页最重要的，不是把所有功能都列给你，而是帮你选对入口。

## 如果你不想自己判断，就按这个最简单的分流走

- 还没跑通过一次 → 去 [先跑起来](./get-running/index.md)
- 已经跑通过，但不够稳定 → 去 [开始上手](./get-started/index.md)
- 已经会用，想更顺手 → 去 [玩出花样](./advanced-usage/index.md)
- 想接系统、做自动化、多助手协作 → 去 [自己造东西](./build-your-own/index.md)

如果你还是拿不准，默认从 [先跑起来](./get-running/index.md) 开始。

## 推荐阅读顺序

第一次系统看 Hermes，建议按这个顺序往下走：

1. [先跑起来](./get-running/index.md)
2. [开始上手](./get-started/index.md)
3. [玩出花样](./advanced-usage/index.md)
4. [自己造东西](./build-your-own/index.md)

你不需要一次把四段都看完。
先把当前这一段走通，再往下推进，理解会更稳。
