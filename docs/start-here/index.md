# 从这开始

![Hermes 学习路径总览](./assets/rm2-learning-path.svg)

Hermes 的能力很多，但你不需要一上来就把所有东西都弄明白。
这页不是资料目录，也不是功能大全。它只做一件事：帮你找到最适合自己的起点。

## 这条学习路径怎么走

《从这开始》按一条更容易走通的顺序组织：

先跑起来 → 开始上手 → 玩出花样 → 自己造东西

这不是唯一顺序，但它最适合大多数中文用户：先让 Hermes 真正跑通，再让它稳定好用，最后再进入更个性化、更系统化的阶段。

## 四个阶段怎么选

| 阶段（点击直达） | 适合谁（你的现状） | 这一阶段主要解决什么 | 学完你能达到什么 |
|---|---|---|---|
| <img src="./assets/icon-run.svg" width="20" alt="先跑起来图标" /> <br /> **[先跑起来](./get-running/index.md)** | 还没跑通过 Hermes，或者还没完成第一次正常互动的人 | 别急着研究高级能力，我们先把最基础的一条路走通：运行环境、终端、安装 Hermes、接上模型、完成第一次互动。 | 你能真正把 Hermes 跑通，并拿到第一条正常回复。 |
| <img src="./assets/icon-hands-on.svg" width="20" alt="开始上手图标" /> <br /> **[开始上手](./get-started/index.md)** | 已经装过一次，但还不会稳定使用的人 | 这一阶段不再解决“能不能装上”，而是解决“平时到底怎么用”：日常使用方式、会话管理、常用命令、第一批值得先看的 Skills。 | 你能把 Hermes 当成日常助手稳定用起来。 |
| <img src="./assets/icon-advanced.svg" width="20" alt="玩出花样图标" /> <br /> **[玩出花样](./advanced-usage/index.md)** | 已经会用 Hermes，想让它更像你、更顺手的人 | 这一阶段开始进入个性化能力：人格、记忆、模型、工具开关、终端主题。重点不再是“能用”，而是“顺手”。 | 你能把一个助手调成更符合自己习惯的工作方式。 |
| <img src="./assets/icon-build.svg" width="20" alt="自己造东西图标" /> <br /> **[自己造东西](./build-your-own/index.md)** | 想把 Hermes 接进工作流、编辑器或外部系统的人 | 当你不再满足于“用一个助手”，这里会带你进入 Profiles、外部记忆、MCP、API、自动化、IDE 集成这些系统化能力。 | 你能从“用一个助手”进入“搭一套系统”。 |

## 如果你不想自己判断，就按这个最简单的分流走

- 还没跑通过一次 → 去 [先跑起来](./get-running/index.md)
- 已经跑通过，但不够稳定 → 去 [开始上手](./get-started/index.md)
- 已经会用，想更顺手 → 去 [玩出花样](./advanced-usage/index.md)
- 想接系统、做自动化、多助手协作 → 去 [自己造东西](./build-your-own/index.md)

如果你还是拿不准，默认从 [先跑起来](./get-running/index.md) 开始。

## 推荐阅读顺序

第一次系统看 Hermes，建议按这个顺序往下走：

1. [先跑起来](./get-running/index.md)
2. [开始上手](./get-started/index.md)
3. [玩出花样](./advanced-usage/index.md)
4. [自己造东西](./build-your-own/index.md)

你不需要一次把四段都看完。
先把当前这一段走通，再往下推进，理解会更稳。

> 如果你是第一次接触 Hermes，最稳的起点就是：
> 
> [进入“先跑起来”](./get-running/index.md)

如果你已经知道自己现在处在哪个阶段，也可以直接跳到对应入口页。
