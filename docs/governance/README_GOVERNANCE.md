# Hermes Agent 中文站 V2 — 治理说明

## 目标
本目录用于承接 Hermes Agent 中文站 V2 的最小治理信息，保证 GitHub 仓库作为内容真源时，入口命名、页面来源与冻结边界都可审计。

## 当前治理范围
当前仅冻结 P0 最小治理：
1. README 六模块固定入口
2. page-source-map 正式来源映射
3. freeze 文档

## 固定模块命名
V2 只允许以下 6 个固定入口名称：
1. 首页
2. 从这开始
3. 现成方案
4. 国内落地
5. 遇到问题
6. 从 OpenClaw 过来

不得重新引入并列一级入口名称，例如：
- 学习路径
- examples
- starter
- FAQ 作为一级主入口

## 变更规则
1. README 顶层入口变更，必须同步更新 page-source-map。
2. 模块命名变更，必须先更新内部治理文件，再允许进入仓库入口改动。
3. RM 是仓库内容源，SM 是独立站表达层；未完成对应 RM，不得放行对应 SM。
4. legacy site 仅可作为历史遗留文件存在，不得作为 V2 模块完成证据。
