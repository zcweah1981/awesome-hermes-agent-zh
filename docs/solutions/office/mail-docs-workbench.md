# 邮件文档工作台

适合把零散的邮件与文档处理任务压成可接单、可整理、可回传的办公执行面。

## 这页解决什么问题
很多办公任务同时涉及邮件往来、附件阅读、文档整理与结论回传，但缺少一条稳定的页面层入口与实现层落点，导致处理方式总是临时拼接，无法复用。

## 页面层样板
- 页面定位：RM3 办公流程下的首个场景页
- 页面路径：`docs/solutions/office/mail-docs-workbench.md`
- 用户入口：待处理邮件、附件文档、会议纪要、审批说明、资料汇总需求
- 目标输出：邮件摘要、文档要点、回复草稿、归档清单

## 实现层样板
- 实现映射文件：`docs/solutions/office/agents/mail-docs-workbench-agents.md`
- 当前职责：登记推荐 agent 角色、输入输出、执行边界与后续真实脚本落点
- 当前状态：占位说明已建立，可作为后续实现层扩写入口

## 最小执行单
1. 准备一组待处理邮件或文档材料
2. 明确需要摘要、回复、整理还是归档
3. 按实现层映射选择或补齐 agent 角色
4. 产出一版可发送或可留档结果，再补回传说明

## 输入
- 邮件正文、附件或文档链接
- 处理目标
- 回复语气或文档格式约束
- 是否需要归档、提醒、待办提取

## 输出
- 邮件与文档摘要
- 回复草稿
- 待办事项清单
- 归档与回传说明

## 当前边界
- 本页只提供 RM3 的页面层+实现层双映射样板
- 不扩展到站点实现、测试、发布配置
