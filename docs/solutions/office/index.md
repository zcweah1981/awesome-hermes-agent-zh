# 办公流程方案

适合把 Hermes 用在邮件、文档、表格、知识整理和个人工作流辅助上。

## 适合谁
- 想减少重复文档处理工作的人
- 想把邮件、表格、会议整理等日常事务做成流程的人

## 当前问题
办公任务往往碎片化，单次提问能解决一点，但很难形成可复用做法。

## 你会得到什么
- 办公类任务的统一入口
- 面向真实工作流而不是单点技巧的使用方式
- 后续可扩展为邮件处理、资料整理、文档协作等场景页

## 最短开始方式
先挑一个高频重复任务，例如整理一封邮件、一页文档或一张表格。

## 推荐模型或工具
先用你已经稳定可用的基础模型与文件/网页工具，不急着引入复杂自动化。

后续将沉淀为更接近日常办公的首批方案页。
