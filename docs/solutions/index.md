# 现成方案

如果你已经不想从零摸索，而是想直接参考一类可落地的做法，就从这里开始。

这里不是 Example 链接堆，也不是抽象功能说明，而是把更接近真实工作的场景按用途分成四类，让你先选方向，再进入对应方案页。

## 这页适合谁
- 已经跑通过 Hermes，下一步想更快进入真实任务的人
- 不想自己拼装全部流程，想先看可直接参考的方案结构的人
- 想按工作类型而不是按工具名选入口的人

## 四类方案入口

### 1. 内容生产（content）
适合内容改写、分发、摘要、资料整理等任务。
- 入口：[内容生产方案](./content/index.md)
- 适合谁：做文章、社媒、知识整理、批量内容处理的人
- 你会得到什么：更适合内容型工作的任务入口、改写方向与交付预期

### 2. 办公流程（office）
适合邮件、文档、表格、知识库和个人工作流整理。
- 入口：[办公流程方案](./office/index.md)
- 适合谁：想把日常办公室工作流交给 Hermes 辅助的人
- 你会得到什么：从文档处理到信息汇总的典型使用方式

### 3. 项目管理（management）
适合 PM 巡查、任务编排、状态汇报、流程推进与协作交接。
- 入口：[项目管理方案](./management/index.md)
- 适合谁：需要把多角色协作与项目节奏管起来的人
- 你会得到什么：更接近真实团队推进的方案入口

### 4. 开发交付（dev）
适合仓库改造、文档工程、自动化开发、调试与交付辅助。
- 入口：[开发交付方案](./dev/index.md)
- 适合谁：正在做代码、仓库、脚本、部署或工程化工作的开发者
- 你会得到什么：面向开发与交付的可执行场景入口

## 使用顺序
1. 先选最接近你当前工作的那一类
2. 再看该类下的首批样板与最短开始方式
3. 做出第一次可见结果后，再决定是否扩展到更多方案
