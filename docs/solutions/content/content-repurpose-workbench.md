# 内容改写工作台

适合把一份已有素材快速改成可发布、可分发、可归档的中文内容成品。

## 这页解决什么问题
很多人已经有原始素材，但缺少一条稳定的页面层入口与实现层落点，导致内容任务只能临时提问，无法复用。

## 页面层样板
- 页面定位：RM3 内容生产下的首个场景页
- 页面路径：`docs/solutions/content/content-repurpose-workbench.md`
- 用户入口：已有长文、录音整理稿、访谈纪要、FAQ 草稿、社媒素材
- 目标输出：发布版文章、摘要版、分发版、归档版

## 实现层样板
- 实现映射文件：`docs/solutions/content/agents/content-repurpose-workbench-agents.md`
- 当前职责：登记推荐 agent 角色、输入输出、执行边界与后续真实脚本落点
- 当前状态：占位说明已建立，可作为后续实现层扩写入口

## 最小执行单
1. 准备一份已有素材
2. 明确目标渠道与输出格式
3. 按实现层映射选择或补齐 agent 角色
4. 产出一版可发布文本，再补摘要与归档版本

## 输入
- 原始素材链接或正文
- 目标渠道
- 风格约束
- 是否需要摘要、标题、标签、FAQ

## 输出
- 主发布版正文
- 渠道适配短版
- 摘要与要点
- 归档说明

## 当前边界
- 本页只提供 RM3 的页面层+实现层双映射样板
- 不扩展到站点实现、测试、发布配置
