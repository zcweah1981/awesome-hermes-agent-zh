# PM 巡查工作台

适合把一个正在推进的项目压成可巡查、可派单、可回传的管理执行面。

## 这页解决什么问题
很多团队知道项目在推进，但缺少一个稳定的页面层入口与实现层落点，导致巡查、派单、收口都只能临时组织，无法复用。

## 页面层样板
- 页面定位：RM3 项目管理下的首个场景页
- 页面路径：`docs/solutions/management/pm-inspection-workbench.md`
- 用户入口：正在推进的项目、待收口任务、风险项、状态汇报需求
- 目标输出：巡查结论、任务拆分、阻塞清单、下一步执行单

## 实现层样板
- 实现映射文件：`docs/solutions/management/agents/pm-inspection-workbench-agents.md`
- 当前职责：登记推荐 agent 角色、输入输出、执行边界与后续真实脚本落点
- 当前状态：占位说明已建立，可作为后续实现层扩写入口

## 最小执行单
1. 准备一个正在推进的项目上下文
2. 明确当前块、目标、阻塞与时间要求
3. 按实现层映射选择或补齐 agent 角色
4. 产出一版可执行巡查结论，再补任务与风险收口

## 输入
- 项目目标
- 当前执行块
- 已知阻塞
- 期望交付时间或节奏

## 输出
- 巡查结论
- 任务拆分单
- 阻塞与风险清单
- 下一步执行建议

## 当前边界
- 本页只提供 RM3 的页面层+实现层双映射样板
- 不扩展到站点实现、测试、发布配置
