# 项目管理方案

适合把 Hermes 用在 PM 巡查、任务编排、状态汇报、流程推进和协作交接上。

## 适合谁
- 需要持续推进项目，而不是只做一次性问答的人
- 需要把多人/多角色协作压成可执行节奏的人

## 当前问题
项目管理最怕状态散落、任务过大、没人收口，最后变成“知道很多但推进很慢”。

## 你会得到什么
- 面向项目推进的方案入口
- 从巡查、派单、留痕到接管的结构化做法
- 后续可扩展为 PM 巡查、日报、风险监控等场景页

## 最短开始方式
先把一个正在推进的项目压成“目标 + 当前块 + 阻塞 + 下一步”的固定格式。

## 推荐模型或工具
优先用文件驱动与可见证据方式推进，先保证状态可回溯，再扩展到外部通知链路。

## 交付结果
后续将沉淀为项目巡查、任务编排与执行接管的首批方案页。
