# 腾讯云轻量服务器部署教程

## 0. 页面信息

**所属栏目**
国内落地 / 部署

**页面类型**
教程页

**适合谁**
已经决定使用腾讯云 Lighthouse 部署 Hermes 的用户。

**这页解决什么问题**
这页不帮你选模型，也不展开飞书、企微、钉钉等入口配置。
这页只负责让你完成下面三件事：

1. 买到或准备好腾讯云 Lighthouse 实例
2. 成功进入 SSH 或腾讯云 Web 终端
3. 启用内置 Hermes 实例并确认已经可用

---

## 1. 先看结果：你做完后应该达到什么状态

当你完成这页后，你应该已经做到：

- 控制台里有一台可用的 Lighthouse 实例
- 你可以通过 SSH 或腾讯云 Web 终端进入服务器
- Hermes 的基础初始化已经完成
- 你已经能在终端里完成一次基本交互

---

## 2. 开始前先知道两件事

### 2.1 腾讯云这条官方路径是什么

腾讯云当前主推的是 **Lighthouse 轻量应用服务器 + Hermes Agent 镜像** 这条路径。
购买一台 Lighthouse 实例后，可以无需复杂配置快速完成环境准备。

### 2.2 这页只做到“实例可用”

腾讯云自己的材料已经延伸到了更后面的内容，比如配置 IM 通道、接飞书和企业微信。
但这页故意收口到更前面：只把实例买好、连上、初始化好，不继续展开消息通道接入。

---

## 3. 第一步：购买 Hermes Agent 的 Lighthouse 实例

### 3.1 新购买路径

直接进入腾讯云 Lighthouse 控制台，新购实例时选择 **Hermes Agent** 应用镜像 / 模板，然后按页面流程完成购买。

### 3.2 已有实例路径

如果你已经有一台 Lighthouse，也不一定要重新买新机器。
当前官方公开说明是：可以通过 **新购实例** 或 **重装旧实例** 两种方式一键部署 Hermes Agent。

已有实例用户如果走重装系统切换到 Hermes Agent 镜像，同样要先确认原实例上的数据是否需要保留。

### 3.3 购买时不用把后面的事全想完

这一步先把机器准备好就行。
活动页虽然同时给了“选购模型服务”和“配置 IM 通道”的后续入口，但本页不要求你在购买阶段一次性把所有后续动作都做完。

你只需要先确保：

- 实例已创建成功
- 你已经能在控制台里找到它

---

## 4. 第二步：进入 SSH 或腾讯云 Web 终端

实例创建完成后，下一步就是进入服务器环境。
如果你已经习惯本地终端，可以直接用 SSH 登录；如果你不想先折腾本地 SSH，也可以直接使用 **腾讯云 Web 终端（OrcaTerm）** 进入服务器环境。

这一步的目标很简单：

- 你已经成功进入服务器
- 你已经拿到一个可以执行命令的终端
- 你准备开始 Hermes 的初始化

只要做到这里，就说明“买机器”已经真正过渡到了“可操作的服务器环境”。

---

## 5. 第三步：执行内置 Hermes 初始化

进入服务器后，不要先急着折腾飞书、企微或别的入口。
先执行腾讯云当前文章里给出的内置初始化向导：

```bash
hermes setup
```

在向导里，你会完成下面几件事：

- 选择模型提供商
- 填入对应 API Key
- 按提示完成配置

这一页不展开“模型怎么选”，所以你在这里的要求只有两个：

- 把向导跑完
- 让 Hermes 至少具备基础可用的模型能力

如果中间填错了，不用自己去猜配置文件。
当前腾讯云 Lighthouse 快速部署文章已经给出提示：

- `hermes setup` 可以重新运行完整配置向导
- `hermes setup model` 可以只重配模型 / 提供商

---

## 6. 第四步：确认 Hermes 已经就绪

这页的真正完成标准，不是“实例买完了”，也不是“终端能打开了”，而是 **Hermes 能完成一次正常对话**。

所以在这一步，你应该做的是：

- 启动 Hermes
- 发一条最简单、最容易验证的问题
- 确认它能正常回复，而不是报 provider 或认证错误

做到这里，这篇部署教程的核心目标就已经完成了。

---

## 7. 这页到这里就收住，不继续往后写

你现在可能已经会自然想到下一步：

“那我能不能顺手把飞书或企业微信也一起接上？”

答案是：可以，但不在这一页展开。

当前腾讯云活动页本来就把“配置 IM 通道”作为后续步骤；腾讯云开发者社区也已经有更完整的“在腾讯云上搭建 Hermes Agent + 飞书 + 企业微信全套方案”文章。

但这页故意停在这里，原因很简单：

如果基础聊天都还没跑通，就继续往后接 IM 通道，只会把问题越叠越乱。

## 8. 这页最常见的误区

### 误区一：买完实例就等于已经配置完成
不是。
真正可用还差一步初始化，也就是进入服务器后执行 `hermes setup`。

### 误区二：一进服务器就先接飞书 / 企微
不建议。
基础聊天先跑通，再去接消息通道，排错会更稳。

### 误区三：向导里填错了，就得自己手改很多配置
不一定。
可以重新运行 `hermes setup`，或者只运行 `hermes setup model` 重配模型。

### 误区四：这页应该顺便把所有后续能力都讲完
不是。
这页只负责把服务器买好、连上、初始化并确认基础可用。
