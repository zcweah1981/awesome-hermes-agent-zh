# 03-国内落地 | 总览

> 一句话先说清楚：这一页不是把国内环境里的所有问题揉成一团，而是先帮你判断你现在卡在“部署”“模型”还是“入口”，再进入正确的二级、三级页面。

## 🎯 为什么需要“国内落地”

国内用户真正落地 Hermes 时，最常卡住的往往不是功能本身，而是下面 3 类现实问题：
1. 网络与环境：机器放在哪、哪家云厂商更适合你的起步路线
2. 模型与成本：先按量跑通、先买套餐，还是直接复用已有兼容接口
3. 触达与交互：最终是从 CLI 用、从网页前端用，还是接入飞书、企业微信、钉钉、个人微信

所以“国内落地”不是一个大杂烩模块，而是把这三层决策拆开，让你少走弯路。

| 二级模块 | 解决什么问题 | 你什么时候先看它 | 推荐下一页 |
|---|---|---|---|
| [01-国内部署](./01-国内部署/01-总览.md) | 先把机器、环境、云厂商路径选对 | 你还没把 Hermes 放到一台稳定可用的国内机器上 | 默认先看 [02-阿里云轻量服务器部署教程](./01-国内部署/02-阿里云轻量服务器部署教程.md) |

如果你只记一句：
- 没机器、没环境 → 先看国内部署
- 有机器了，但还没想好模型 → 先看国内模型
- 部署和模型都差不多了，想真正开始用 → 先看国内入口
