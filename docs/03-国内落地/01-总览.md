# 国内落地

如果你在中国境内使用 Hermes，这一模块先帮你把两件最重要的事理顺：

1. 先决定怎么部署
2. 再决定怎么选模型

它不是一堆碎片教程的集合，而是给你一条更稳的进入路径。

## 先从哪边开始

- 如果你已经决定先把环境准备好，去 [《01-国内部署》](./01-国内部署.md)
- 如果你已经想先看模型与接口怎么选，去 [《国内模型总览》](./02-国内模型/01-总览.md)

## 推荐顺序

如果你是第一次进国内落地模块，建议按这个顺序：

1. 先看《部署说明》或直接看对应云厂商教程
2. 部署好之后，再看《国内模型总览》
3. 如果你已经明确想走某一条模型路线，再进入对应单页
