## 🎯 为什么需要“国内落地”

国内用户真正落地 Hermes 时，最常卡住的往往不是功能本身，而是下面 3 类现实问题：
1. 网络与环境：机器放在哪、哪家云厂商更适合你的起步路线
2. 模型与成本：先按量跑通、先买套餐，还是直接复用已有兼容接口
3. 触达与交互：最终是从 CLI 用、从网页前端用，还是接入飞书、企业微信、钉钉、个人微信

所以“国内落地”不是一个大杂烩模块，而是把这三层决策拆开，让你少走弯路。

## ❓ 国内落地常见问题

### Hermes Agent 在国内能用吗？

可以。Hermes Agent 支持接入国内主流大模型（DeepSeek、阿里云百炼、腾讯云、智谱GLM、MiniMax、Kimi），也支持通过自定义兼容接口复用已有的 OneAPI / NewAPI / Ollama 等兼容层。国内部署推荐阿里云或腾讯云轻量服务器，部署流程参见 [01-国内部署](./01-国内部署/01-总览.md)。

### 国内模型怎么选？哪条路线最适合起步？

如果你只想先用最低门槛跑通，建议走 [DeepSeek 按量计费接口](./02-国内模型/07-DeepSeek按量计费接口.md)——不需要买套餐，充值余额就能用。如果你想要统一入口覆盖多家模型，看 [阿里云百炼](./02-国内模型/02-阿里云百炼Token%20plan.md) 或 [腾讯云 Token Plan](./02-国内模型/03-腾讯云Token%20Plan.md)。如果你已经有兼容层，直接看 [自定义兼容接口](./02-国内模型/08-自定义兼容接口.md)。

### 国内用户推荐从哪个入口开始用 Hermes？

个人用户推荐先用 [CLI 命令行](./03-国内入口/04-命令行（CLI）.md) 跑通。团队使用推荐接入 [飞书](./03-国内入口/05-飞书.md)、[企业微信](./03-国内入口/06-%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%EF%BC%88AI%20Bot%EF%BC%89.md) 或 [钉钉](./03-国内入口/07-钉钉.md)。如果你需要 Web 界面，可以用 [网页控制台](./03-国内入口/02-网页控制台（Dashboard）.md) 或 [Open WebUI](./03-国内入口/03-API%20%E6%9C%8D%E5%8A%A1%E4%B8%8E%20Open%20WebUI.md)。

### Hermes 中文站和官方英文文档是什么关系？

中文站不是官方英文文档的翻译，而是从中文用户视角出发的实战路径。官方英文文档在 [hermes-agent.nousresearch.com/docs](https://hermes-agent.nousresearch.com/docs)。中文站专注于帮国内用户解决部署、模型接入、使用入口等本地化问题。
