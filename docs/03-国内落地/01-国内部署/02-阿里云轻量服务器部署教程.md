# 02-阿里云轻量服务器部署教程

![阿里云轻量服务器部署 Hermes 的官方流程图](./assets/aliyun-hermes-flow-v3.png)

这一页只讲一条最短路径：购买阿里云轻量应用服务器，拿到 SSH / Workbench 连接，直接使用阿里云已经提供的 Hermes 镜像。

这页不讲模型选择，不讲大模型对比，不讲长期使用策略。

## 一眼看完

如果你是第一次来这一步，先记住这四件事：

1. 先买一台带 Hermes 镜像的阿里云轻量应用服务器
2. 再进入控制台找到远程连接入口
3. 用 SSH / Workbench 登录服务器
4. 按官方提示启动 Hermes 并验证它能响应

## 这页做完后你应该看到什么

- 控制台里有一台可用的轻量应用服务器
- 你能打开这台服务器的远程连接
- 你能进入 SSH / Workbench 终端
- 你能按官方镜像提示启动 Hermes
- 你能确认 Hermes 已经可用

> 说明：阿里云现在已经提供 Hermes 镜像，所以最短路径不是自己装，而是直接买官方镜像并用起来。

## Step 1：购买预装 Hermes 镜像的轻量服务器

### 现在做什么
在阿里云轻量应用服务器里，直接购买预装 Hermes 的实例。

### 为什么做
因为官方已经提供镜像，直接买现成镜像是最省事、最稳的起步方式。

### 具体怎么做
- 进入阿里云轻量应用服务器购买页
- 选择预装 Hermes 的镜像
- 按默认配置先创建实例
- 如果你已经有轻量服务器，也可以通过重置系统切换到 Hermes 镜像，但要先备份数据，因为重置会清空系统盘

### 看到什么算成功
- 控制台里出现一台新的轻量应用服务器
- 实例状态正常
- 你能进入这台服务器的详情页

### 不成功先查什么
- 地域有没有选错
- 支付 / 创建有没有完成
- 实例是不是还在初始化
- 你是不是误选了别的镜像

## Step 2：进入实例详情，找到远程连接入口

### 现在做什么
进入这台轻量服务器的详情页，找到远程连接入口。

### 为什么做
因为后面的 SSH / Workbench 登录，都从这里进。

### 具体怎么做
- 打开轻量应用服务器控制台
- 找到目标实例
- 点击实例卡片进入详情页
- 先只确认远程连接入口在哪里

### 看到什么算成功
- 你能看到这台实例的详情页
- 你能看到远程连接相关入口
- 你知道下一步从哪里登录

### 不成功先查什么
- 你是不是点错实例
- 控制台是不是还没刷新出来
- 账号权限是不是不够

## Step 3：用 SSH / Workbench 登录服务器

### 现在做什么
通过阿里云提供的远程连接方式进入服务器。

### 为什么做
因为真正的使用入口在终端里，先连上服务器，才能继续验证 Hermes。

### 具体怎么做
- 在实例详情页点击远程连接
- 优先使用 Workbench 一键连接
- 如果你习惯 SSH，就按控制台给出的方式连入
- 进入终端后，确认你已经拿到命令行提示符

### 看到什么算成功
- 浏览器或客户端里打开了终端窗口
- 你看到了命令行提示符
- 你可以开始输入命令

### 不成功先查什么
- 密码或密钥有没有配对
- 远程连接按钮有没有点对
- 安全组或访问权限有没有限制
- 实例是不是还没准备好

## Step 4：按官方镜像提示启动 Hermes 并验证

### 现在做什么
在终端里按官方镜像的提示启动 Hermes，并确认它能正常响应。

### 为什么做
因为这一步才是真正验证“买来就能用”的闭环。

### 具体怎么做
- 先按官方镜像页面提示完成最小初始化
- 然后在终端里输入 `hermes`
- 按终端返回继续交互

### 看到什么算成功
- Hermes 能进入交互状态
- 终端有正常响应
- 你确认这台服务器已经可以使用

### 不成功先查什么
- 远程连接是不是已经断开
- 终端里有没有按官方镜像要求完成最小初始化
- 你是不是还没有进入正确的实例
- 你是不是漏掉了镜像页面上的必要提示

## 这页最常见的误区

### 误区一：买完实例就算完成
不是。至少要连上 SSH / Workbench，并验证 Hermes 能响应。

### 误区二：一定要自己先搭一整套环境
不是。阿里云已经提供 Hermes 镜像，最短路径就是直接用官方镜像。

### 误区三：远程连接只是看一眼
不是。远程连接是这页的核心动作之一，最终要在终端里完成验证。

### 误区四：这页要先研究模型
不是。这页只管购买、连接和使用，不展开模型选择。

## 做完后，你应该检查什么

请按下面这份清单收口：

- 轻量应用服务器已创建完成
- 实例详情页能正常打开
- 远程连接入口可用
- SSH / Workbench 能正常登录
- 终端里能执行 `hermes` 并得到响应

如果这些都成立，这页就算完成。
