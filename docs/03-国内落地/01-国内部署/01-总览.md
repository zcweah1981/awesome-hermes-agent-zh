# 01-国内部署

这一页在“国内落地”闭环里只解决一件事：先帮你选对国内部署路线，再进入对应云厂商教程。

## 🧭 先按你的当前状态分流

| 目标页面 | 解决什么 | 推荐下一页 |
|---|---|---|
| [02-阿里云轻量服务器部署教程](./02-阿里云轻量服务器部署教程.md) | 适合更看重官方镜像、模型生态、标准化起步的人 | 默认先看这一页 |
| [03-腾讯云轻量服务器部署教程](./03-腾讯云轻量服务器部署教程.md) | 适合更看重低门槛起步、长期在线、IM 触达链路的人 | 如果你更偏飞书 / 企业微信 / 钉钉场景，优先看这一页 |

如果你只记一句：

- 更看重模型和官方镜像 → 阿里云
- 更看重低门槛起步和消息链路 → 腾讯云

## 📦 这两个部署页分别适合谁

### 02-阿里云轻量服务器部署教程
更适合：

- 你想沿着官方镜像和标准化路径起步
- 你后面大概率会继续走阿里云百炼 / DashScope / Qwen 这一侧模型生态
- 你希望先把机器和模型环境一起理顺

### 03-腾讯云轻量服务器部署教程
更适合：

- 你想用更低门槛方式先把一台长期在线机器跑起来
- 你后面大概率会接飞书、企业微信、钉钉这类国内协作入口
- 你更关心部署稳定、聊天链路和长期可用性

## ⭐ 默认主线

如果你完全不想自己判断，默认先走这条线：

1. [02-阿里云轻量服务器部署教程](./02-阿里云轻量服务器部署教程.md)
2. 部署完成后回到 [03-国内落地总览](../01-总览.md)
3. 再进入 [02-国内模型 / 01-总览](../02-国内模型/01-总览.md)

为什么默认先推阿里云：

- 起步路径更标准化
- 更适合作为“国内落地”第一台机器的基线方案
- 后续衔接模型模块更顺
