# 01-总览

这一页只做一件事：帮你在国内部署这条线上，快速选对入口，然后直接进入对应教程。

## 你先怎么选

如果你更在意模型生态、官方镜像、DashScope / Qwen 这条线，先去阿里云。

如果你更在意消息接入、长期在线、低成本起步，先去腾讯云。

如果你只是想先把国内部署跑通，不想在入口上反复犹豫，就按“先选一条最顺手的路”处理：

- 模型侧优先 → 阿里云
- 通道侧优先 → 腾讯云

## 这一层只负责什么

国内部署这一层只负责把环境跑起来，不替你做更上层的选择。

你在这一层应该得到的是：

- 一台能用的国内轻量服务器
- 一个能进入的 SSH 或 Web 终端
- 一个已经启用、可以继续往下走的 Hermes 实例

## 这一层不展开什么

下面这些内容不在这一层解决：

- 模型接口怎么选
- 哪个套餐更适合长期使用
- 消息平台怎么接
- 日常怎么把 Hermes 当助手用起来

这些会分别回到后面的模型页和应用页。
