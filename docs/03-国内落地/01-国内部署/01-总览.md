# 01-国内部署 | 总览

> 一句话先说清楚：这一页不是教你立刻敲命令，而是先帮你选对国内部署路线，再进入正确的云厂商教程。

## 👀 这一层现在解决什么

国内部署这一层只解决 3 件事：
- 先把 Hermes 放到一台稳定可用的国内机器上
- 先判断你更适合阿里云还是腾讯云
- 先把“机器在哪跑”这件事和后面的模型、入口选择拆开

如果你现在还没有一台长期可用的国内机器，就先从这一层进。

| 路线 | 这条路主要解决什么 | 你什么时候先看它 | 推荐下一页 |

| [02-阿里云轻量服务器部署教程](./02-阿里云轻量服务器部署教程.md) | 用更标准化的方式先把第一台机器落下 | 你更看重官方镜像、模型生态和标准起步路径 | 默认先看这一页 |
| [03-腾讯云轻量服务器部署教程](./03-腾讯云轻量服务器部署教程.md) | 用更低门槛方式先把一台长期在线机器跑起来 | 你更看重低门槛起步、消息链路和长期在线 | 如果你后面更偏飞书 / 企业微信 / 钉钉，优先看这一页 |

## 🧩 这两条部署路到底怎么选

### 02-阿里云轻量服务器部署教程
更适合：
- 你想沿着更标准化的路径起步
- 你后面大概率会继续走阿里云百炼 / DashScope / Qwen 这侧模型生态
- 你希望先把机器、系统环境和后续模型衔接一起理顺

直接进入：
- [02-阿里云轻量服务器部署教程](./02-阿里云轻量服务器部署教程.md)

### 03-腾讯云轻量服务器部署教程
更适合：
- 你想用更低门槛方式先把一台长期在线机器跑起来
- 你后面大概率会接飞书、企业微信、钉钉这类国内协作入口
- 你更关心部署稳定、聊天链路和长期可用性

直接进入：
- [03-腾讯云轻量服务器部署教程](./03-腾讯云轻量服务器部署教程.md)

## ⭐ 默认主线

如果你完全不想自己判断，默认先走这条线：

1. [02-阿里云轻量服务器部署教程](./02-阿里云轻量服务器部署教程.md)
2. 部署完成后回到 [03-国内落地总览](../01-总览.md)

- 后续衔接模型模块更顺
