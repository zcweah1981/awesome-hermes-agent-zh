这一页只做一件事：帮你把 Hermes 在国内云上先跑起来。

如果你已经决定走国内部署，这里不用再反复做选择题，直接按你的目标进入对应教程就行。

## 先按你的目标选

### 如果你更看重模型侧和官方镜像
先去阿里云。

阿里云这条路更适合这类情况：

- 你更关注阿里云自己的大模型生态，比如百炼 / DashScope / Qwen
- 你希望用官方预装镜像或官方最佳实践直接起步
- 你更想先把模型调用、API Key、Coding Plan 这条线理顺
- 你希望起步方式尽量标准化，少走绕路

阿里云官方这条线的信号很明确：

- 轻量应用服务器是主要入口
- Hermes Agent 有官方帮助页和最佳实践页
- 默认建议实例内存 2GiB 及以上
- 默认地域是北京
- 模型侧默认会落到百炼 / Coding Plan 这类路径上

### 如果你更看重 IM 接入和低成本起步
先去腾讯云。

腾讯云这条路更适合这类情况：

- 你更在意企业微信、飞书、钉钉这类聊天通道
- 你希望先用 Lighthouse 快速起一台能长期在线的机器
- 你更在意“先跑起来、先接通、先能用”
- 你想从低成本配置开始，再按需升级

腾讯云官方这条线的信号也很明确：

- Lighthouse 首发支持 Hermes Agent
- 官方强调 7×24 小时在线和本地数据隔离
- 选配时明确建议国内模型配国内地域，聊天通道也优先国内地域
- 2核4G 是更稳的起步建议，2核2G 只适合简单体验
- Token Plan 对 AI 编码场景的价格优势很强

### 如果你是 OpenClaw 老用户
你可以把这页当成“换到 Hermes 之后，先从哪条国内路起步”的入口。

一般可以这样理解：

- 你原来主要靠聊天通道协作，先看腾讯云
- 你原来主要靠模型生态和标准化镜像，先看阿里云

不要在这里重新研究一遍整个体系，先选一条你最顺的路，跑通第一台机器更重要。

## 默认怎么走

如果你现在还没有明确偏好，建议按这个顺序：

1. 先看这一页，确认自己要走国内部署
2. 如果你更偏模型和百炼体系，直接进阿里云教程
3. 如果你更偏企业微信 / 飞书 / 钉钉和低成本起步，直接进腾讯云教程
4. 部署完成后，再去看国内模型总览
