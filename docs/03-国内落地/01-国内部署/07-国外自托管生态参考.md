# 国外自托管生态参考：Umbrel、TrueNAS、AUR、Docker

> 本页整理国外社区已有的 Hermes Agent 自托管方案。**这些是社区提供的便利通道，不是官方首选部署方式。** 国内用户仍建议优先参考本站 [VPS 部署教程](02-阿里云轻量服务器部署教程.md) 或 [Docker 部署](01-总览.md)。

## 适合谁

- 有 NAS 设备（Umbrel、TrueNAS）的家庭用户
- Arch Linux 用户想通过包管理器安装
- 想了解 Docker 镜像详情的用户
- 对比不同自托管方案的技术决策者

---

## 方案 1：Docker Hub 官方镜像

### 概况

| 项目 | 内容 |
|------|------|
| **来源** | Docker Hub 官方镜像 |
| **镜像地址** | `nousresearch/hermes-agent` |
| **拉取量** | 100 万+ |
| **镜像大小** | 约 1.1 GB |
| **更新频率** | 极高（几乎每日更新） |
| **协议** | MIT |

### 部署方式

```bash
docker pull nousresearch/hermes-agent
```

### 适合谁

几乎所有自托管用户。这是最通用、最推荐的部署方式。

### 关键亮点

- 官方维护的镜像，质量有保障
- 支持 VPS、GPU 集群、无服务器基础设施（Daytona、Modal）
- 可通过 Telegram 远程控制
- 详细的 Docker 使用文档见[官方 Docker Guide](https://hermes-agent.nousresearch.com/docs/user-guide/docker)

### 注意事项

- 镜像较大（1.1 GB），首次拉取需要一定带宽
- 需要配置 AI Provider API Key
- 国内拉取 Docker Hub 可能较慢，建议配置镜像加速器

来源：[Docker Hub](https://hub.docker.com/r/nousresearch/hermes-agent)

## 方案 2：Umbrel App Store

### 概况

| 项目 | 内容 |
|------|------|
| **来源** | Umbrel 官方 App Store |
| **版本** | 2026.5.29.2（与 Docker 镜像同步） |
| **分类** | AI |
| **需要** | Umbrel 硬件或 umbrelOS 环境 |

### 部署方式

在 umbrelOS App Store 中搜索「Hermes Agent」，点击一键安装。

### 适合谁

已有 Umbrel 设备的家庭用户。最简单的图形化部署方案。

### 关键亮点

- 真正的图形化一键部署
- 与 umbrelOS 深度集成
- 版本与官方同步

### 注意事项

- 需要 Umbrel 硬件或已安装 umbrelOS
- 国内访问 Umbrel 服务可能需要网络配置
- 这是社区便利通道，官方文档中的 VPS + Docker 方案仍是主力推荐

来源：[Umbrel App Store](https://apps.umbrel.com/app/hermes-agent)

## 方案 3：TrueNAS SCALE Apps

### 概况

| 项目 | 内容 |
|------|------|
| **来源** | TrueNAS Community Apps |
| **版本** | v2026.5.29.2 |
| **分类** | AI |
| **基础** | Docker（镜像 `nousresearch/hermes-agent`） |

### 部署方式

在 TrueNAS SCALE 的 Apps Market 中搜索「hermes-agent」，通过社区目录（community train）安装。

### 配置项

- **Gateway API Key**（必填）
- 是否允许所有用户访问 Gateway
- 是否启用不安全的 Dashboard 访问
- 网络端口（Gateway 端口 + Dashboard 端口）
- 存储挂载路径
- CPU / 内存资源限制

### 适合谁

已有 TrueNAS SCALE 设备的 NAS 用户、中小型办公网络。

### 关键亮点

- 完整的 TrueNAS 原生配置界面
- 支持细粒度的网络/存储/资源配置
- 元数据引用 GitHub 源码和 Docker Hub

### 注意事项

- ⚠️ 容器以 root（UID 0, GID 0）运行，需注意安全风险
- 需要手动输入 Gateway API Key
- 默认关闭不安全的 Dashboard 访问（需手动开启）

来源：[TrueNAS Apps](https://apps.truenas.com/catalog/hermes-agent_community)

## 方案 4：Arch Linux AUR

### 概况

| 项目 | 内容 |
|------|------|
| **来源** | Arch Linux User Repository (AUR) |
| **版本** | 0.15.2-4 |
| **提交者** | y0uCeF |
| **维护者** | y0uCeF + evorster |
| **许可** | MIT |
| **首次提交** | 2026-04-02 |

### 部署方式

```bash
# 使用 paru 或 yay 等 AUR helper
paru -S hermes-agent

# 或手动构建
git clone https://aur.archlinux.org/hermes-agent.git
cd hermes-agent
makepkg -si
```

### 适合谁

Arch Linux 用户，想通过包管理器统一管理 Hermes 的安装和更新。

### 关键亮点

- Arch Linux 原生包管理
- 上游指向 GitHub NousResearch/hermes-agent
- 活跃维护（多次更新修复）

### 注意事项

⚠️ **已知问题较多**，不适合新手：
1. 构建 `python311` 来自 AUR，编译耗时长
2. `rsync` 缺失于 makedepends（已有人报告）
3. shebang 路径可能指向构建缓存目录，清理缓存后导致包损坏
4. `pip install -e .[all]` 的可编辑安装模式可能导致路径问题
5. 某些依赖不在 `[all]` 中，依赖 lazy install

**建议**：如果遇到问题，优先考虑 Docker 方案。

来源：[AUR — hermes-agent](https://aur.archlinux.org/packages/hermes-agent)

## 国内用户建议

1. **首选 VPS + Docker**：这是最通用、国内最可行的方案。参考本站 [阿里云部署教程](02-阿里云轻量服务器部署教程.md) 或 [腾讯云部署教程](03-腾讯云轻量服务器部署教程.md)。
2. **Docker Hub 镜像加速**：国内拉取 Docker Hub 较慢，建议配置阿里云/腾讯云的 Docker 镜像加速器。
3. **Umbrel / TrueNAS**：如果你的网络环境可以流畅访问这些服务，它们提供了更简单的图形化部署体验。但在国内网络环境下可能需要额外配置。
4. **AUR 不推荐新手**：构建问题较多，除非你是经验丰富的 Arch 用户，否则优先 Docker。
