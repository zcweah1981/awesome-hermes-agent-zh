# 03-国内入口 | 总览

> 一句话先说清楚：这一页不是直接教你配某个平台，而是先帮你选对 Hermes 的使用入口，再进入正确的入口页面。

## 👀 这一层现在解决什么

国内入口这一层只解决 3 件事：
- 先判断你应该从 CLI、网页前端、管理面板还是消息平台开始
- 先把“真正从哪里用 Hermes”这件事拆清楚
- 先避免把 Dashboard、Open WebUI、CLI、飞书 / 企业微信 / 钉钉 / 个人微信混成一件事

如果你已经有部署和模型基础，下一步通常就该从这一层进。

## 💬 这些入口到底怎么分

### 1. CLI：第一主入口
优先看：[04-命令行（CLI）](./04-命令行（CLI）.md)

适合：
- 第一次开始真正使用 Hermes
- 需要排错、切模型、改配置
- 想先拿到一个最稳定的可验证闭环

### 2. API 服务与 Open WebUI：网页前端路线
优先看：[03-API 服务与 Open WebUI](<./03-API%20%E6%9C%8D%E5%8A%A1%E4%B8%8E%20Open%20WebUI.md>)

适合：
- 想让浏览器聊天界面连上 Hermes
- 想先分清前端和后端分别是什么

### 3. Dashboard：管理面板路线
优先看：[02-网页控制台（Dashboard）](./02-网页控制台（Dashboard）.md)

适合：
- 想看会话、任务、状态、配置管理
- 但要先记住：Dashboard 是管理面板，不是聊天前端

### 4. 飞书 / 企业微信 / 钉钉 / 个人微信：消息入口路线
优先看：
- [05-飞书](./05-飞书.md)
- [06-企业微信（AI Bot）](<./06-%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%EF%BC%88AI%20Bot%EF%BC%89.md>)
- [07-钉钉](./07-钉钉.md)
- [08-个人微信](./08-个人微信.md)

适合：
- 想把 Hermes 从“自己可用”推进到“别人也能用”
- 想让 Hermes 进入团队协作流或个人消息触达链路

## 🚦 如果你现在只想快速选一个

直接按当前状态走：
- 第一次真正开始用 Hermes → [04-命令行（CLI）](./04-命令行（CLI）.md)
- 明确想做网页聊天前端 → [03-API 服务与 Open WebUI](<./03-API%20%E6%9C%8D%E5%8A%A1%E4%B8%8E%20Open%20WebUI.md>)
- 明确想先看状态、日志、配置和会话 → [02-网页控制台（Dashboard）](./02-网页控制台（Dashboard）.md)
- 明确想接团队消息平台 → 先看 CLI，跑顺后再进对应平台页

## ⭐ 默认主线

如果你完全不想自己判断，默认先走这条线：

1. [04-命令行（CLI）](./04-命令行（CLI）.md)
2. 跑顺后再回到 [03-国内落地总览](../01-总览.md)
3. 再按需要进入网页前端或消息平台对应页

为什么默认先推 CLI：
- 它是最完整的原生入口
- 它最适合排错和配置
- 后续无论接网页前端还是消息平台，最终都更容易回到 CLI 判断问题在哪一层

## ✅ 看完这页你应该能立刻判断什么

看完国内入口总览，你应该能直接回答这 3 个问题：
1. 我应该先用 CLI、网页前端，还是消息平台？
2. 我下一页应该先点哪个入口页？
3. 我是不是把“管理面板”“网页前端”“消息平台”“原生主入口”混成一件事了？
