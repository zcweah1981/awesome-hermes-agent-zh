# 中国模型总览

如果你已经把 Hermes 跑起来，接下来最重要的不是“谁最强”，而是先决定你要走哪一类模型路径。

这页只帮你做一件事：把 Hermes 原生 provider、聚合型订阅、单厂商订阅和按量 API 先分清，再告诉你默认从哪条路起步。

## 先看结论：先选路径，不先选品牌

国内这批主流方案，已经很清楚地分成三类：

| 路线 | 本质 | 适合谁 | 代表项 |
|---|---|---|---|
| Hermes 原生支持的 provider | 直接接到 Hermes 的常规路径 | 想先把 Hermes 跑顺的人 | GLM / z.ai / zai、Kimi / Moonshot、Kimi / Moonshot China、MiniMax、MiniMax China、Alibaba Cloud / DashScope / Qwen、DeepSeek、Custom endpoint |
| 聚合型 Coding / Token 套餐 | 一份订阅里切多家国产模型 | 想把“选择”交给套餐的人 | 阿里云百炼 Coding Plan、腾讯云 Token Plan |
| 单厂商订阅或按量 API | 单家模型的订阅或接口能力 | 已经认准某一家的人 | GLM Coding Plan、MiniMax Token Plan、Kimi Code、DeepSeek API、Kimi API |

这页最重要的结论不是“谁最强”，而是：

**先决定你要的是 Hermes 原生 provider、聚合订阅，还是按量 API。**

## 如果你的目标是“先把 Hermes 跑顺”

如果你是 Hermes 中文站的主线用户，默认优先级不应该完全照第三方对比文章来，而是先看 Hermes 直接支持得最顺的那批 provider。

这意味着，如果你的目标是：

- 先把 Hermes 连上
- 先跑通一次稳定对话
- 先让站内教程更简单

那优先顺序应该更偏向：

1. **按量计费接口**
2. **Hermes 原生 provider 里的直接可用项**
3. **聚合型 Coding / Token 套餐**
4. **单厂商订阅**
5. **自定义兼容接口**

## 先按人群分流，而不是先按厂商分流

### 你只想先跑起来，先别买月付包
优先看 **按量计费接口**，其次再看 **Kimi API** 这种开放平台按量路线。

### 你想一份订阅里切多家模型
优先看 **阿里云百炼编程套餐** 和 **腾讯云 Token Plan**。

### 你已经认准某一家
那就不要在总览页里继续犹豫。

- 认准智谱 → 走 **智谱编程套餐**
- 认准 MiniMax → 走 **MiniMax Token Plan** 或相关订阅路线
- 认准 Kimi 的 Coding 体验 → 走 **Kimi Code** 或 **Kimi API**

### 你主要做 Hermes，不是主要做 Claude Code / OpenClaw
这种情况下，优先级要再收紧一层。

腾讯云令牌套餐更适合做“扩展路线”，而不适合放在 Hermes 默认第一位。

## 这几条主路线，最本质的区别是什么

### Hermes 原生 provider
它是 **Hermes 能直接接上的路径**，重点是少折腾、少中间层。

### 阿里云百炼编程套餐
它是 **聚合型订阅**，更偏“阿里云生态里的聚合 Coding 套餐”。

### 腾讯云令牌套餐
它也是 **聚合型订阅**，但更偏“AI 编程工具生态里的聚合套餐”。

### 智谱编程套餐
它是 **单厂商订阅**，更适合已经认准智谱模型的人。

### 全模态订阅方案
它是 **单厂商全模态订阅**。

### 编程会员与开放平台接口
这一条必须拆成两条线看：

- **Kimi Code**：会员权益里的个人 Coding 能力
- **Kimi API**：开放平台按量计费能力

### 按量计费接口
**DeepSeek** 是最典型的按量计费 API 路线。

## 如果你只想要一个默认推荐

### 默认推荐 1：先跑起来
**按量计费接口**

因为它没有订阅门槛、协议兼容广、Hermes 原生支持，最适合做第一把钥匙。

### 默认推荐 2：中文写作和阿里云生态
**阿里云百炼编程套餐 / 千问与 DashScope 接口**

### 默认推荐 3：想深用单厂商
在下面三条里选一条，不要同时上三条：

- 智谱编程套餐
- 全模态订阅方案
- 编程会员与开放平台接口

### 默认推荐 4：你其实主要在 AI 编程工具里工作
**腾讯云令牌套餐**

## 这页不要帮用户做什么

这页不应该做三件事：

### 第一，不要把每家价格写成永久真值
总览页给方向，不做最终结算页。

### 第二，不要把“是否 Hermes 原生支持”和“是否国内厂商 Coding 产品”混成一回事

### 第三，不要在这一页里重写每家的购买和接入步骤
这页的任务是对比和分流。真正的购买和使用，应该去后面的单独页面。

## 下一步怎么走

如果你已经看完这页并且有方向，最自然的下一步是先回到国内落地总入口，再进入对应单页：

- 回到 [国内落地总入口](./01-总览.md)
- 想走聚合订阅：阿里云百炼编程套餐 / 腾讯云令牌套餐
- 想深用单厂商：智谱编程套餐 / 全模态订阅方案 / 编程会员与开放平台接口
- 想最低门槛先跑通：按量计费接口

如果你还没决定，那就先按一个最简单的顺序试：

**按量计费接口 → 千问与 DashScope 接口（第二批）→ 智谱编程套餐 / 编程会员与开放平台接口 / 全模态订阅方案 → 再考虑阿里云百炼和腾讯云令牌套餐。**
