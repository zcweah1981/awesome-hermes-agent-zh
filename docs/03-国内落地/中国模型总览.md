# 中国模型总览

## 0. 页面信息

**所属栏目**
国内落地 / 模型

**页面类型**
总览页 / 决策页

**适合谁**
- 已经把 Hermes 跑起来，准备接模型的人
- 想先比较国内几条主流模型 / Coding Plan 路线的人
- 不想一上来就陷进每家控制台细节里的人

**这页的目标**
这页不直接教你把每一家都配上。
这页先帮你回答一个更重要的问题：

**你应该先选哪一类模型路径。**

---

## 1. 先看结论：先选“路径”，不要先选“品牌”

现在国内这批主流方案，已经明显分成了三类：

### 第一类：Hermes 原生支持的 provider
Hermes 官方当前直接列出的中国相关 provider 包括：

- GLM（z.ai / zai）
- Kimi / Moonshot
- Kimi / Moonshot China
- MiniMax
- MiniMax China
- Alibaba Cloud / DashScope / Qwen
- DeepSeek
- Custom endpoint

这意味着，如果你的目标是“先让 Hermes 自己顺滑跑起来”，默认优先级应该更高的是这些原生 provider。

### 第二类：聚合型 Coding / Token 套餐
阿里云百炼 Coding Plan 和腾讯云 Token Plan 都属于这一类。

它们的共同点是：

- 一份订阅里可以切多家国产模型
- 更适合 AI 编程工具场景
- 更像“聚合订阅”，不是标准按量 API

### 第三类：单厂商订阅或按量 API
这又分成两种：

- **单厂商订阅**：GLM Coding Plan、MiniMax Token Plan、Kimi Code
- **按量 API**：DeepSeek API、Kimi API

所以这页最重要的结论不是“谁最强”，而是：

**先决定你要的是 Hermes 原生 provider、聚合订阅，还是按量 API。**

## 3. 先按人群分流，而不是先按厂商分流

### 3.1 你只想先跑起来，先别买月付包
优先看 **六、按量计费接口**，其次看 **五、编程会员与开放平台接口** 里的 Kimi API。

### 3.2 你想一份订阅里切多家模型
优先看 **一、阿里云百炼编程套餐** 和 **二、腾讯云令牌套餐**。

### 3.3 你已经认准某一家
那就不要在总览页里继续犹豫。

- 认准智谱 → 《三、智谱编程套餐》
- 认准 MiniMax → 《四、全模态订阅方案》
- 认准 Kimi 的 Coding 体验 → 《五、编程会员与开放平台接口》

### 3.4 你主要做 Hermes，不是主要做 Claude Code / OpenClaw
这种情况下，优先级要再收紧一层。

腾讯云令牌套餐更适合做“扩展路线”，而不适合放在 Hermes 默认第一位。

---

## 4. 这几条主路线，最本质的区别是什么

### 4.1 阿里云百炼编程套餐
它是 **聚合型订阅**，更偏“阿里云生态里的聚合 Coding 套餐”。

### 4.2 腾讯云令牌套餐
它也是 **聚合型订阅**，但更偏“AI 编程工具生态里的聚合套餐”。

### 4.3 智谱编程套餐
它是 **单厂商订阅**，更适合已经认准智谱模型的人。

### 4.4 全模态订阅方案
它是 **单厂商全模态订阅**。

### 4.5 编程会员与开放平台接口
这一条必须拆成两条线看：

- Kimi Code：会员权益里的个人 Coding 能力
- Kimi API：开放平台按量计费能力

### 4.6 按量计费接口
DeepSeek 是最典型的 **按量计费 API 路线**。

## 6. 这页不要帮用户做什么

这页不应该做三件事：

### 第一，不要把每家价格写成永久真值
总览页给方向，不做最终结算页。

### 第二，不要把“是否 Hermes 原生支持”和“是否国内厂商 Coding 产品”混成一回事

### 第三，不要在这一页里重写每家的购买和接入步骤
这一页的任务是对比和分流。
真正的购买和使用，应该去后面的单独页面。

## 7. 下一步怎么走

如果你在这页看完后已经有方向，最自然的下一步就是直接跳到对应单页：

- 想走聚合订阅 → 《一、阿里云百炼编程套餐》或《二、腾讯云令牌套餐》
- 想深用单厂商 → 《三、智谱编程套餐》《四、全模态订阅方案》《五、编程会员与开放平台接口》
- 想最低门槛先跑通 → 《六、按量计费接口》

如果你还没决定，那就先按一个最简单的顺序试：

**六、按量计费接口 → [七、千问与 DashScope 接口（第二批）](./07-千问与%20DashScope%20接口（第二批）.md) → 三、智谱编程套餐 / 五、编程会员与开放平台接口 / 四、全模态订阅方案 → 再考虑一、二两条聚合套餐**
