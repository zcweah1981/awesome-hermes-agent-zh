# 阿里云轻量服务器部署教程

## 0. 页面信息

**所属栏目**
国内落地 / 部署

**页面类型**
教程页

**适合谁**
已经决定使用阿里云轻量应用服务器部署 Hermes 的用户。

**这页解决什么问题**
这页不帮你选模型，也不教你怎么长期使用 Hermes。
这页只负责把阿里云上的 Hermes 环境准备好，让你完成下面三件事：

1. 买到或准备好阿里云轻量应用服务器
2. 成功进入远程终端
3. 启用内置 Hermes 实例并确认它已经可用

## 2. 开始前先知道两件事

### 2.1 阿里云这条官方路径是什么

阿里云当前已经提供了预装 Hermes Agent 的轻量应用服务器镜像。
如果你是第一次部署，最简单的做法就是直接购买预装 Hermes Agent 的实例；如果你已经有轻量应用服务器，也可以通过重置系统的方式切换到 Hermes Agent 镜像，但这会清空系统盘数据，所以一定要先备份。

阿里云帮助文档当前写明的基本前提是：

- 实例内存至少 2 GiB
- 购买页默认地域是北京
- 默认购买时长是 12 个月

### 2.2 这页只做到“实例可用”

阿里云帮助文档本身也把消息渠道配置和模型切换分别指向 Hermes 的其他文档。
所以这页不会继续展开这些内容，只把重点放在：

- 实例买好
- 终端进得去
- Hermes 初始化成功
- 你知道去哪里验证

---

## 3. 第一步：购买预装 Hermes 的轻量应用服务器

### 3.1 新用户怎么做

直接进入阿里云轻量应用服务器购买页，选择预装 **Hermes Agent** 应用的实例，然后按页面默认配置先完成购买。

这一步不需要自己先装 Hermes，也不需要自己先准备运行环境。
官方推荐方式就是直接购买预装 Hermes Agent 的轻量应用服务器。

### 3.2 已经有轻量服务器怎么办

如果你已经买过轻量应用服务器，也可以不重新买新机器。
官方路径是：对现有实例执行 **重置系统**，然后在应用镜像里选择 **Hermes Agent**。

但这一步会清除系统盘数据，所以必须先确认没有需要保留的内容。

### 3.3 本步骤完成标准

做到下面这几点，就算第一步完成：

- 你已经有一台 Hermes Agent 轻量应用服务器
- 实例状态正常
- 你能在控制台里打开这台服务器的详情页

---

## 4. 第二步：进入实例详情，找到 Hermes 的应用页

购买完成后，进入阿里云轻量应用服务器控制台，点击目标服务器卡片中的 **实例 ID**。
进入服务器概览页后，打开 **应用详情** 页签。

这一页你只需要关注两块内容：

- **配置 Hermes**
- **访问 WebUI 面板**

不要在这里展开别的配置，不然很容易把部署和后续使用混在一起。

---

## 5. 第三步：初始化 Hermes

### 5.1 打开初始化入口

在 **配置 Hermes** 这一块，点击 **初始化**。
这一步会让你开始配置 Hermes 所需的百炼 API Key。

### 5.2 配置百炼 API Key

初始化时，需要先选择百炼地域。
接着，你可以在下拉框里直接选择 Coding Plan 的 API Key，或者手动输入按量计费的 API Key，然后继续下一步。

### 5.3 这里最容易踩的坑

如果你是手动输入 API Key，一定要确认：

**你选择的地域，和这个 API Key 对应的地域一致。**

如果地域不一致，会导致模型无法正常调用。
这个问题不属于 Hermes 本身的使用问题，而是初始化阶段就会遇到的部署问题，所以这一页必须提前提醒。

---

## 6. 第四步：找到 WebUI，但不要把它当成聊天入口

完成初始化后，在 **访问 WebUI 面板** 这一块，点击 **安全代理访问**，就能拿到 Hermes Agent 的 WebUI 地址。

这个页面主要用于查看：

- Hermes Agent 版本
- 日志
- 配置

这里最重要的一句要单独写清楚：

**WebUI 页面暂不支持与 Agent 直接对话。**

很多用户会自然觉得“既然已经有 WebUI 了，那应该就在这里直接开始聊天”。
但在这条部署路径里，WebUI 的职责不是聊天，而是查看与管理。

所以在这页里，你只需要把 WebUI 当成：

- 查看版本的地方
- 看日志的地方
- 看配置的地方

不要把它当成这篇教程里的最终验证入口。

---

## 7. 第五步：登录远程终端，验证 Hermes 已经可用

### 7.1 进入远程连接

回到阿里云轻量应用服务器控制台，在服务器列表里找到目标服务器，点击卡片中的 **远程连接**。
在弹出的连接窗口中，使用 **Workbench 一键连接** 进入终端。

### 7.2 在终端里验证 Hermes

进入终端后，直接输入：

```bash
hermes
```

阿里云当前帮助文档给出的官方验证方式，就是在远程连接窗口里输入 `hermes` 与 Hermes Agent 对话。

### 7.3 为什么这里才算真正完成

这篇教程的真正完成标准，不是 WebUI 打开了，而是：

- 你能进入远程终端
- 你能启动 Hermes
- 你能完成一次基本交互

做到这里，这页的任务才算完成。

---

## 8. 做完后，你应该检查什么

请用下面这张清单确认自己已经完成：

- 轻量应用服务器已创建完成
- 实例详情页能正常打开
- 应用详情里的初始化已完成
- WebUI 地址可访问
- 远程连接可登录
- 在终端里输入 `hermes` 后，Hermes 可以正常进入交互状态

如果这些都成立，这页的任务就完成了。

## 9. 这页最常见的误区

### 误区一：买完实例就算部署完成
不是。
买完实例只是把环境准备好了，真正的部署完成至少还包括：初始化 Hermes、配置百炼 API Key、进入终端验证 `hermes` 可以运行。

### 误区二：WebUI 就是聊天页
不是。
阿里云当前帮助文档明确写了，WebUI 页面主要看版本、日志和配置，暂不支持和 Agent 直接对话。

### 误区三：API Key 地域无所谓
不是。
如果你手动输入百炼 API Key，地域必须一致，不然模型调用会失败。

### 误区四：已有实例重置系统没有风险
不是。
重置系统会清空系统盘数据，这一步一定要在确认无误后再做。
