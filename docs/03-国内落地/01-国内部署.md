# 01-国内部署

## 0. 页面信息

**所属栏目**
国内落地 / 部署

**页面类型**
说明页 / 分流页

**适合谁**
已经进入“国内落地”模块，并准备上云部署 Hermes 的用户。

**这页解决什么问题**
这页不是云厂商对比，也不是安装大全。
这页只负责把“部署层”的边界说清楚，让用户知道这一层到底教什么、不教什么。

---

## 1. 先说清楚：这一层到底教什么

部署层只教三件事：

1. 购买轻量服务器
2. 登录 SSH 或 Web 终端
3. 启用云厂商内置 Hermes 实例并确认可用

如果你来这一层，是想看：

- 选哪个模型
- 飞书 / 企微 / 钉钉怎么接
- Hermes 日常怎么用
- CLI / Web UI 哪条更适合自己

这些都不在这一层展开。
这些内容统一回到站内其他页面。

---

## 2. 这一层不帮你做选择

这里不帮你做下面这些决策：

- 不帮你选本地还是云端
- 不帮你选阿里云还是腾讯云
- 不帮你比较哪家更便宜
- 不帮你选择模型

原因很简单：
这一层不是决策页，而是教程页。

我们的目标不是让用户在部署页里继续犹豫，
而是让已经决定使用某条云路径的用户，尽快把机器买好、连上、启起来。

---

## 3. 这一层的最终目标是什么

当用户完成部署层后，应该达到的状态是：

- 已经有一台可用的云服务器
- 已经能进入 SSH 或 Web 终端
- 云厂商内置的 Hermes 实例已经启用
- 用户知道 Hermes 已经就绪
- 用户接下来应该回到哪一页继续

这就够了。
部署层做到这里就应该收住，不要继续把模型、入口、解决方案全写进来。

---

## 4. 当前部署层包含哪些页面

本轮已经完成正文的页面只有 2 个：

1. 阿里云轻量服务器部署教程
2. 腾讯云轻量服务器部署教程

这两页都遵循同样的边界：

- 购买实例
- 登录终端
- 启用内置 Hermes
- 验证实例可用
- 然后跳回站内主教程

---

## 5. 为什么部署层要这样写

因为我们已经明确了：

- “国内落地”是站点的支撑层，不是第一主线
- 部署层是纯教程层，不是推荐页
- 用户在这里最需要的是“把它启起来”，不是“再被解释一轮所有选择题”

所以部署层必须尽量短、尽量稳、尽量少分叉。
