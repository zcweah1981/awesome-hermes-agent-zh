# 08-自定义兼容接口

如果你手上已经有一个 OpenAI-Compatible 接口，或者你本来就要接自己的转发层、第三方兼容层，这一页就是给你的。

它不是默认首选，但它是“你已经有现成入口”时最省重复劳动的路线。

## 这条路适合谁

- 你手里已经有兼容接口
- 你要对接的是自建网关或中间层
- 你本来就不打算从官方原生路径开始
- 你已经知道自己为什么需要兼容层

## 你最需要记住的点

自定义兼容接口的前提不是“更高级”，而是“你已经有一个稳定入口”。

没有现成入口时，不建议把这条路当成第一选择。

## 什么时候先别选它

- 你现在只是想第一次跑通 Hermes
- 你还没有稳定的兼容层
- 你不确定自己是否真的需要中间层

## 下一步

- 还没决定时，先回 [国内模型总览](../01-总览.md)
- 如果你已经有兼容接口，就直接按你的现有环境往下走

## 官方依据

- Hermes 官方 provider / routing 说明
- 你自己的 OpenAI-Compatible / 自建兼容层文档
