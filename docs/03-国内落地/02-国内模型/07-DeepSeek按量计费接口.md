# 07-DeepSeek按量计费接口

如果你最想要的是“先跑起来，再按用量付费”，DeepSeek 这条按量接口路线通常是最值得先看的。

它的核心价值很直接：没有订阅门槛，路径清晰，适合做第一把钥匙。

## 这条路适合谁

- 你想先把 Hermes 跑通
- 你希望先少花钱、少做决策
- 你更接受按量付费，而不是先订阅
- 你希望接口路径尽量直接，排查更简单

## 你最需要记住的点

按量接口的优势不是“功能最花哨”，而是“起步最干净”。

如果你现在最关心的是先验证 Hermes 是否能稳定工作，这条路通常会排在很前面。

## 什么时候先别选它

- 你已经确定要用订阅型套餐
- 你更想一份套餐切换多家模型
- 你希望入口尽量统一在某个云厂商生态里

## 下一步

- 还没决定时，先回 [国内模型总览](../01-总览.md)
- 如果你想先跑通，再回头比较订阅型方案，先从这里开始
