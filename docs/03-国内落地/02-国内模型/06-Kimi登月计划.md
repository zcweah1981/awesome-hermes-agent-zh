# 06-Kimi登月计划

Kimi 这条路，适合你更看重 Coding 体验，或者你已经在 Kimi 的官方能力与开放平台之间做过判断。

这一页把它拆成两层：会员能力和开放平台接口。

## 这条路适合谁

- 你已经对 Kimi 的 coding 能力有兴趣
- 你想先看会员型能力，再看 API 路线
- 你希望在写作、编程、日常助理之间保持灵活度
- 你不想把“会员”和“按量接口”混在一起

## 你最需要记住的点

Kimi 这页最重要的是分层：
- Kimi Code 偏会员权益里的个人 coding 能力
- Kimi API 偏开放平台按量计费能力

把这两层分开，你后面选路会清楚很多。

## 什么时候先别选它

- 你现在只想走 Hermes 最低门槛路线
- 你还没决定是会员还是 API
- 你想先把预算和调用方式一并压平再看

## 下一步

- 还没决定时，先回 [国内模型总览](../01-总览.md)
- 如果你已经知道自己想要 Kimi 的哪一层，再继续看后面的具体页
