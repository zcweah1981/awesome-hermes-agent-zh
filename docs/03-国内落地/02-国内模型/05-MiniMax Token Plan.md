# 05-MiniMax Token Plan

MiniMax Token Plan 更像一条偏全模态、偏灵活体验的订阅路线。

如果你希望的不只是单纯文本接口，而是更广的模型能力组合，这条路值得看。

## 这条路适合谁

- 你希望订阅方案里保留更强的多模态想象空间
- 你想先试一条和纯按量 API 不一样的路线
- 你接受先走订阅，再逐步细化到模型使用
- 你更看重体验边界和能力组合，而不只是单个接口

## 你最需要记住的点

MiniMax 这条路不是“最简单”，但它适合你把能力面铺得更宽。

如果你在做 Hermes 的国内落地总览，它更适合被放在“你已经有明确偏好后”的选择里。

## 什么时候先别选它

- 你只是想先把 Hermes 跑起来
- 你更想要按量计费，不想先背订阅
- 你还没想清楚是不是要走全模态或更宽能力路线

## 下一步

- 还没决定时，先回 [国内模型总览](../01-总览.md)
- 如果你已经认定 MiniMax，再往后看具体页面
