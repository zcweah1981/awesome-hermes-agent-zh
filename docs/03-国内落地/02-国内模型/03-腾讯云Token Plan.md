# 03-腾讯云Token Plan

腾讯云 Token Plan 适合你已经在腾讯云生态里，或者你更想用一份聚合订阅把多家国产模型先串起来。

它的核心不是“单个模型有多神”，而是“订阅后可以更快切换和试用”。

## 这条路适合谁

- 你本来就偏腾讯云
- 你想尽量少做多套模型账号管理
- 你偏 AI 编程工具场景，想要一份统一订阅
- 你愿意先接受聚合型路径，再慢慢细化

## 你最需要记住的点

腾讯云 Token Plan 更像“工具生态里的聚合套餐”。
它适合做扩展路线，不一定适合放在 Hermes 第一启动位。

如果你是在做 Hermes 中文站的默认推荐，一般会先把它放在“可选路线”，而不是“唯一首选”。

## 什么时候先别选它

- 你现在只想最低门槛先跑通
- 你不想先处理订阅与套餐选择
- 你已经明确知道要走某个单厂商接口

## 下一步

- 还没决定时，先回 [国内模型总览](../01-总览.md)
- 如果你已经认定腾讯云生态，再继续看后面的具体页面
