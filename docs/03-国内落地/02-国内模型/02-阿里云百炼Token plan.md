# 02-阿里云百炼Token plan

阿里云百炼这条路，适合你想先在阿里云生态里把 Hermes 接顺，同时又希望一份订阅里能切换多家模型。

它不是“最省事的唯一答案”，但它是很典型的聚合型 Coding / Token 路线。

## 这条路适合谁

- 你已经在用阿里云，想尽量少换环境
- 你想要一份订阅里能用多家国产模型
- 你主要关注编码、自动化、日常助理这类场景
- 你希望先把选择范围缩小，再继续往下看具体接入

## 你最需要记住的点

百炼更像“聚合订阅”，不是单一模型的纯 API 页。
它的价值在于：先把多个能力放在一个入口里，再按场景选用。

如果你追求的是“先跑起来”，这条路可以用；
如果你追求的是“最少一步”，那通常要先比较它和按量接口谁更顺。

## 什么时候先别选它

- 你现在只想最快把 Hermes 跑通
- 你还没决定是否要订阅型方案
- 你更想先走单一模型或按量 API

## 下一步

- 已经决定走阿里云生态，就继续看后面的具体页面
