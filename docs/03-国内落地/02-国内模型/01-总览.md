这一页在“国内落地”闭环里只解决一件事：先帮你选对国内模型路线，再进入对应厂商或接口页面。

- 先跑通 → DeepSeek
- 想统一入口 → 阿里云 / 腾讯云 Token Plan

- 已有兼容层 → 自定义兼容接口

## 🧠 这些模型路线到底怎么分

### 1. 最低门槛先跑通
优先看：[07-DeepSeek 按量计费接口](./07-DeepSeek按量计费接口.md)

适合：

- 不想先买套餐
- 想先拿到第一个可验证闭环
- 想把模型接入这件事先做轻、做快

### 2. 想先买一套统一入口
优先看：

- [02-阿里云百炼 Token Plan](./02-阿里云百炼Token%20plan.md)
- [03-腾讯云 Token Plan](./03-腾讯云Token%20Plan.md)

适合：

- 想一份订阅先覆盖更多国产模型路线
- 不想一开始就深绑某一家单厂商体验

### 3. 认准单厂商再深用
优先看：

- [04-智谱 GLM Coding Plan](./04-智谱GLM%20Coding%20Plan.md)
- [05-MiniMax Token Plan](./05-MiniMax%20Token%20Plan.md)
- [06-Kimi 登月计划](./06-Kimi登月计划.md)

适合：

- 已经认准一家厂商
- 更看重其产品形态、生态或会员权益

### 4. 已有兼容层再接 Hermes
优先看：[08-自定义兼容接口](./08-自定义兼容接口.md)

适合：

- 你已经有稳定的 OpenAI-Compatible 兼容层
- 你不想再重新做一遍上游模型接入

## ⭐ 默认主线

如果你完全不想自己判断，默认先走这条线：

1. [07-DeepSeek 按量计费接口](./07-DeepSeek按量计费接口.md)
2. 跑通后再回到 [03-国内落地总览](../01-总览.md)
3. 接着进入 [03-国内入口 / 01-总览](../03-国内入口/01-总览.md)

为什么默认先推 DeepSeek：

- 最少前置决策
- 最容易验证 Hermes 链路是否已通
- 最适合作为整个模型模块的第一把钥匙

## ✅ 看完这页你应该能立刻判断什么

看完国内模型总览，你应该能直接回答这 3 个问题：

1. 我现在该先跑通，还是先买套餐？
2. 我更适合统一入口、单厂商，还是兼容接口？
3. 我下一页应该直接点哪一条模型路线？
