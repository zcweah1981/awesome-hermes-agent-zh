# 02-国内模型 | 总览

复核日期：2026-09-30。本轮是文档与源码复核，不代表已实测国内网络、API 或桌面安装。套餐限制应先于价格比较：百炼个人版与团队版不同，腾讯个人版不得多人共享；后台任务要另查厂商条款。

> **一句话结论**：帮你选对国内模型路线（按量起步 / 统一套餐 / 单厂商深用 / 已有兼容层），再进入正确的厂商或接口页面。

**适合谁**：已经有部署环境、准备接入国内大模型的用户。
**不适合谁**：还没完成 Hermes 部署的用户（先回 [01-国内部署](../01-国内部署/01-总览.md)）；已经跑通模型、只是想换入口的用户（直接去 [03-国内入口](../03-国内入口/01-总览.md)）。
**最短路径**：只想最低门槛先跑通 → 直接进 [DeepSeek 按量计费接口](./07-DeepSeek按量计费接口.md)；想统一套餐入口 → [阿里云百炼](./02-%E9%98%BF%E9%87%8C%E4%BA%91%E7%99%BE%E7%82%BCToken%20plan.md) 或 [腾讯云](./03-%E8%85%BE%E8%AE%AF%E4%BA%91Token%20Plan.md)；已有兼容层 → [自定义兼容接口](./08-自定义兼容接口.md)。
**关键限制**：各模型接口需要分别注册对应平台账号并充值或开通套餐；自定义兼容接口要求你的兼容层提供 OpenAI 兼容格式 API；模型能力差异会影响 Hermes 实际表现，建议先跑通再优化。
**下一步**：最低门槛起步 → [DeepSeek 按量计费接口](./07-DeepSeek按量计费接口.md)；统一入口 → [阿里云百炼](./02-%E9%98%BF%E9%87%8C%E4%BA%91%E7%99%BE%E7%82%BCToken%20plan.md) 或 [腾讯云](./03-%E8%85%BE%E8%AE%AF%E4%BA%91Token%20Plan.md)；已有兼容层 → [自定义兼容接口](./08-自定义兼容接口.md)。

## 👀 这一层现在解决什么

国内模型这一层只解决 3 件事：
- 先判断你是要最低门槛跑通，还是先买套餐
- 先判断你更适合统一入口、单厂商深用，还是已有兼容层接入
- 先把“模型路线”这件事和“部署”“入口”分开

如果你已经能部署，下一步通常就该先从这一层进。

## 🧠 这些模型路线到底怎么分

### 1. 最低门槛先跑通
优先看：[07-DeepSeek按量计费接口](./07-DeepSeek按量计费接口.md)

适合：
- 不想先买套餐
- 想先拿到第一个可验证闭环
- 想把模型接入这件事先做轻、做快

### 2. 想先买一套统一入口
优先看：
- [02-阿里云百炼 Token Plan](<./02-%E9%98%BF%E9%87%8C%E4%BA%91%E7%99%BE%E7%82%BCToken%20plan.md>)
- [03-腾讯云 Token Plan](<./03-%E8%85%BE%E8%AE%AF%E4%BA%91Token%20Plan.md>)

适合：
- 想一份订阅先覆盖更多国产模型路线
- 不想一开始就深绑某一家单厂商体验
- 希望后续切换模型时心智成本更低

### 3. 认准单厂商再深用
优先看：
- [04-智谱GLM Coding Plan](<./04-%E6%99%BA%E8%B0%B1GLM%20Coding%20Plan.md>)
- [05-MiniMax Token Plan](<./05-MiniMax%20Token%20Plan.md>)
- [06-Kimi登月计划](./06-Kimi登月计划.md)

适合：
- 已经认准一家厂商
- 更看重其产品形态、生态或会员权益

### 4. 已有兼容层再接 Hermes
优先看：[08-自定义兼容接口](./08-自定义兼容接口.md)

适合：
- 你已经有稳定的 OpenAI-Compatible 兼容层
- 你不想再重新做一遍上游模型接入

## 🖥️ 桌面短配置卡

1. 先确认产品、账户地区与 Key 类型，选择 **与账户产品和地区对应的 provider**；按量、个人套餐、团队套餐和本地模型分别核对权益，不用模型名称判断计费路线。
2. 打开 **Settings → Model** 设置当前 profile 默认模型，填精确 ID **厂商当前允许的模型 ID**。聊天输入框的模型选择只用于当前聊天，不能用它代替默认模型验收；首次选择及持久化行为以对应版本为准。
3. 若菜单没有模型，使用手动 ID 入口；空目录行为有版本差异，见[桌面教程](/docs/start/personalize/desktop-app)。远端连接时核对服务实际运行的 profile 和凭据位置。
4. 自行发送一条短问答，再执行一个只读取测试文件的工具任务；核对实际 provider、模型、结果及厂商用量记录。**Test、问答和工具任务会发请求，可能收费**，点击前确认余额与套餐允许的用法。
5. 本页只完成文档与源码复核，未进行真实 API、桌面安装或国内网络测试；保存配置或显示连接成功不等于任务和计费路线验证通过。

## ❓ 国内模型常见问题

### Hermes Agent 支持哪些国内大模型？

当前已验证的国内模型路线：DeepSeek（按量计费）、阿里云百炼 Token Plan、腾讯云 Token Plan、智谱 GLM Coding Plan、MiniMax Token Plan、Kimi 登月计划。如果你已有 OneAPI / NewAPI / Ollama 等兼容层，也可以通过 [自定义兼容接口](./08-自定义兼容接口.md) 直接接入。

### 国内模型哪条路线成本最低？

起步阶段推荐 DeepSeek 按量计费——充值少量余额即可跑通，不需要买套餐。跑通后再根据实际用量决定是否切换到统一套餐入口（阿里云百炼 / 腾讯云 Token Plan）或单厂商深用路线。

### 用自定义兼容接口接入时需要注意什么？

确保你的兼容层提供的是 OpenAI 兼容格式的 API，然后按 [08-自定义兼容接口](./08-自定义兼容接口.md) 配置 provider 即可。常见问题（如 401、连接超时、模型名不匹配）在页面底部的 FAQ 里有解答。如果遇到更复杂的 provider 问题，可以看 [模型 Provider 与自定义 endpoint 问题](/docs/issues/provider-endpoint)。
