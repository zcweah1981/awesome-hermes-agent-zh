# 02-国内模型 | 总览

> 一句话先说清楚：这一页不是让你马上挑最强模型，而是先帮你选对国内模型路线，再进入正确的厂商或接口页面。

## 👀 这一层现在解决什么

国内模型这一层只解决 3 件事：
- 先判断你是要最低门槛跑通，还是先买套餐
- 先判断你更适合统一入口、单厂商深用，还是已有兼容层接入
- 先把“模型路线”这件事和“部署”“入口”分开

如果你已经能部署，下一步通常就该先从这一层进。

## 🧠 这些模型路线到底怎么分

### 1. 最低门槛先跑通
优先看：[07-DeepSeek按量计费接口](./07-DeepSeek按量计费接口.md)

适合：
- 不想先买套餐
- 想先拿到第一个可验证闭环
- 想把模型接入这件事先做轻、做快

### 2. 想先买一套统一入口
优先看：
- [02-阿里云百炼 Token Plan](<./02-%E9%98%BF%E9%87%8C%E4%BA%91%E7%99%BE%E7%82%BCToken%20plan.md>)
- [03-腾讯云 Token Plan](<./03-%E8%85%BE%E8%AE%AF%E4%BA%91Token%20Plan.md>)

适合：
- 想一份订阅先覆盖更多国产模型路线
- 不想一开始就深绑某一家单厂商体验
- 希望后续切换模型时心智成本更低

### 3. 认准单厂商再深用
优先看：
- [04-智谱GLM Coding Plan](<./04-%E6%99%BA%E8%B0%B1GLM%20Coding%20Plan.md>)
- [05-MiniMax Token Plan](<./05-MiniMax%20Token%20Plan.md>)
- [06-Kimi登月计划](./06-Kimi登月计划.md)

适合：
- 已经认准一家厂商
- 更看重其产品形态、生态或会员权益

### 4. 已有兼容层再接 Hermes
优先看：[08-自定义兼容接口](./08-自定义兼容接口.md)

适合：
- 你已经有稳定的 OpenAI-Compatible 兼容层
- 你不想再重新做一遍上游模型接入

## 🚦 如果你现在只想快速选一个

直接按当前状态走：
- 只想最低门槛先跑通 → [07-DeepSeek按量计费接口](./07-DeepSeek按量计费接口.md)
- 想先买一套统一套餐入口 → 在 [02-阿里云百炼 Token Plan](<./02-%E9%98%BF%E9%87%8C%E4%BA%91%E7%99%BE%E7%82%BCToken%20plan.md>) 和 [03-腾讯云 Token Plan](<./03-%E8%85%BE%E8%AE%AF%E4%BA%91Token%20Plan.md>) 里按生态偏好选一条
- 已经认准单厂商 → 直接进对应厂商页
- 已经有兼容层 → [08-自定义兼容接口](./08-自定义兼容接口.md)

## ⭐ 默认主线

如果你完全不想自己判断，默认先走这条线：

1. [07-DeepSeek按量计费接口](./07-DeepSeek按量计费接口.md)
2. 跑通后再回到 [03-国内落地总览](../01-总览.md)
3. 接着进入 [03-国内入口 / 01-总览](../03-国内入口/01-总览.md)

为什么默认先推 DeepSeek：
- 最少前置决策
- 最容易验证 Hermes 链路是否已通
- 最适合作为整个模型模块的第一把钥匙

## ✅ 看完这页你应该能立刻判断什么

看完国内模型总览，你应该能直接回答这 3 个问题：
1. 我现在该先跑通，还是先买套餐？
2. 我更适合统一入口、单厂商，还是兼容接口？
3. 我下一页应该直接点哪一条模型路线？
