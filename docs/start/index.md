# 从这开始

如果你是第一次接触 Hermes Agent，先别试图一次学完全部文档。

这一组页面只做一件事：把 Hermes 的上手路径压成一条从低到高、每一步都能看见结果的中文路线。

## 你现在应该从哪一层开始

### 1. 先跑起来
- 适合谁：第一次安装 Hermes、想先验证能不能跑通的人
- 学完能做到什么：完成安装、选好 provider、跑通第一次对话
- 先看哪一页：[先跑起来](./run-first.md)
- 需要准备什么：终端、一个可用的 API key、基础网络环境
- 下一层是什么：开始上手

### 2. 开始上手
- 适合谁：已经跑通一次，但还不知道怎样稳定使用的人
- 学完能做到什么：理解 `.env` / `config.yaml` 分工、provider 选择、基础排错顺序
- 先看哪一页：[开始上手](./start-using.md)
- 需要准备什么：至少完成过一次 `hermes` 对话
- 下一层是什么：玩出花样

### 3. 玩出花样
- 适合谁：已经能稳定使用单 Agent，想尽快做出一个可见成果的人
- 学完能做到什么：会挑 starter / example / 迁移入口，不再只停留在看文档
- 先看哪一页：[玩出花样](./build-something.md)
- 需要准备什么：一个明确的小目标，例如做 demo、跑案例、试迁移
- 下一层是什么：自己造东西

### 4. 自己造东西
- 适合谁：已经做过至少一次闭环，想把尝试沉淀成自己的项目结构的人
- 学完能做到什么：会选择项目骨架、整理角色分工、把一次性尝试变成可维护工作流
- 先看哪一页：[自己造东西](./build-your-own.md)
- 需要准备什么：真实任务、想长期维护的目录结构和协作方式
- 下一层是什么：进入现成方案、国内落地或迁移等更明确场景

## 默认顺序
1. [先跑起来](./run-first.md)
2. [开始上手](./start-using.md)
3. [玩出花样](./build-something.md)
4. [自己造东西](./build-your-own.md)

## 使用规则
- 不按官方章节顺序硬读完整套文档
- 每一层只解决当前阶段最需要的决策
- 如果上一层还没完成，就不要提前跳到更复杂的层级
- 如果你来自 OpenClaw，请先完成前两层，再进入迁移判断
