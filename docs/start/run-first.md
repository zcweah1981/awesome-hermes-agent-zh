# 先跑起来

## 这一层适合谁
- 第一次安装 Hermes 的中文用户
- 想先验证 Hermes 是否真能跑通的人
- 不想一上来就掉进复杂配置的人

## 学完能做到什么
- 完成 Hermes 安装
- 用官方 provider 跑通第一次对话
- 知道遇到首次错误时先查哪里

## 先看哪一页
1. `docs/quick-start.md`
2. `docs/first-run-checklist.md`
3. `docs/known-issues.md`

## 需要准备什么
- 可用终端环境
- 一个官方支持 provider 的 API key
- 基本代理/网络条件（如需要）

## 推荐动作
1. 先按 `docs/quick-start.md` 完成安装
2. 运行 `hermes setup` 或 `hermes model`
3. 先选官方 provider，不要默认走 custom endpoint
4. 启动 `hermes`，完成一次真实对话
5. 如果失败，再按 `docs/known-issues.md` 做标准排查

## 常见卡点
- 安装后命令不可用
- API key 放错位置
- provider / model 选错
- 国内网络、代理或证书问题
- 还没跑通就提前写大量 custom 配置

## 完成标志
- 你已经成功启动过一次对话
- 你知道自己当前的默认 provider
- 你知道下一步该进入“开始上手”而不是继续重复安装

## 下一层是什么
完成本层后进入：[开始上手](./start-using.md)
