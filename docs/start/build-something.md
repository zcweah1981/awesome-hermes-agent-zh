# 玩出花样

## 这一层适合谁
- 已经能稳定使用单 Agent 的用户
- 想尽快做出一个可见成果的人
- 想看 starter、example、团队协作或迁移路径的人

## 学完能做到什么
- 能从 starter / example 中挑出最接近自己的起点
- 能用一个真实任务跑出第一轮成果
- 能判断什么时候该进入团队协作或迁移试点

## 先看哪一页
1. `docs/starters/index.md`
2. `docs/examples/index.md`
3. `docs/team-flow.md`
4. `docs/migrate/compare.md`
5. `docs/migrate/migration.md`

## 需要准备什么
- 基础环境已经稳定
- 有一个明确的小目标
- 愿意先做最小闭环，而不是一口气搭完整系统

## 推荐动作
1. 先选一个最接近自己的 starter
2. 或直接跑一个 example 看真实工作流
3. 如果来自 OpenClaw，先选低风险试点做迁移比较
4. 如果要做协作，先从最小多 Agent 分工开始

## 常见卡点
- 还没稳定使用就直接上复杂团队结构
- 分不清 starter 和 example 的用途
- 想一次迁移全部插件和流程
- 只看概念，不做真实试跑

## 完成标志
- 你已经完成至少一个 starter 或 example 级闭环
- 你知道自己要继续走个人项目、团队协作还是迁移路径
- 你已经有一个值得长期维护的方向
