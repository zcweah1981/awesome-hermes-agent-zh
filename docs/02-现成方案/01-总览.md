# 01-总览｜现成方案

> 一句话先说清楚：这一层不是让你先学概念，而是让你先挑一套已经能直接试跑的现成方案。

## 👀 这层现在有什么

当前这一层先开放 1 条已经能直接进入的路线：

- [02-微信小程序助手](./03-应用开发与快速原型/02-微信小程序助手.md)

如果你现在的目标是：
- 先找一套现成打法，不想从零拆
- 手里已经有明确目标，比如小程序、原型、工作流
- 更关心“能不能马上开始试”，而不是先补一堆背景知识

那就先从这里进。

## 🧩 这条方案到底解决什么

当前已开放的现成方案是：

- 微信小程序助手

它解决的不是“帮你写一篇方案说明”，而是：
- 把一个微信小程序想法压成第一版可开工骨架
- 帮你判断该先走超级个体版，还是团队协作版
- 帮你拿到页面、目录、接口和首批文件建议
- 帮你知道跑完第一轮后，下一句该怎么继续

## 🗺 默认主线

如果你不想选，直接走这一条：

1. 进入 [02-微信小程序助手](./03-应用开发与快速原型/02-微信小程序助手.md)
2. 先跑超级个体版
3. 跑通后再决定要不要转团队协作版

## ✅ 看完这页你应该立刻能判断什么

看完后，你应该能马上判断：
- 我现在是不是更适合先用一个现成方案起步
- 当前仓库里有没有已经能直接拿来试的方案
- 我下一步该不该直接进微信小程序助手页
