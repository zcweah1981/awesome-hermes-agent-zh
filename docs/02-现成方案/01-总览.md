# 01-总览｜现成方案

> **一句话结论**：这一层不让你先学概念，而是让你直接挑一套已经能试跑的现成方案。

**适合谁**：手里已经有明确目标（内容输出、办公整理、快速原型）想直接上手试跑的用户。
**不适合谁**：还没装好 Hermes 的用户；没有具体使用场景、只想先了解概念的用户。
**最短路径**：从本页挑一组匹配你目标的方案 → 进子总览 → 按步骤跑通。
**关键限制**：必须先完成 Hermes 安装并配好可用模型；X/Twitter 相关能力由第三方插件 [Hermes Tweet](https://github.com/Xquik-dev/hermes-tweet) 提供，非 Hermes 官方内置功能。
**下一步**：做内容看 [01-内容创作与发布](./01-内容创作与发布/01-总览.md)；做办公整理看 [02-办公效率与知识整理](./02-办公效率与知识整理/01-总览.md)；做原型看 [03-应用开发与快速原型](./03-应用开发与快速原型/01-总览.md)。

## 👀 这层现在有什么

当前这一层已经能直接进入 3 组现成方案：

| 二级模块 | 这组主要解决什么 | 你什么时候先看它 | 入口页 |
|---|---|---|---|
| 01-内容创作与发布 | 先把小红书、公众号、PPT、X/Twitter、多平台改写这类内容输出跑出来 | 你今天就想先出一版内容、文章、汇报稿或直接操作 X 平台 | [01-内容创作与发布](./01-内容创作与发布/01-总览.md) |
| 02-办公效率与知识整理 | 先把纪要、日报、资料总结、行动计划、消息摘要这类办公输出跑出来 | 你刚开完会、要发日报，或手里有资料要整理 | [02-办公效率与知识整理](./02-办公效率与知识整理/01-总览.md) |
| 03-应用开发与快速原型 | 先把小程序、Web 原型这类开发想法压成第一版可开工结构 | 你已经有产品想法，想先拿页面、目录、接口和骨架 | [03-应用开发与快速原型](./03-应用开发与快速原型/01-总览.md) |

> 💡 **X/Twitter 内容与互动**已收录在"01-内容创作与发布"组下，支持在 Hermes 里搜索推文、读取时间线、发推和回复。该能力由第三方插件 [Hermes Tweet](https://github.com/Xquik-dev/hermes-tweet) 提供，非 Hermes 官方内置功能，写操作需显式授权。详见 [05-X/Twitter 内容与互动助手](./01-内容创作与发布/05-X-Twitter%20内容与互动助手.md)。

如果你现在的目标是：
- 先找一套现成打法，不想从零拆
- 手里已经有明确目标，比如内容、办公整理、原型开发
- 更关心“能不能马上开始试”，而不是先补一堆背景知识

那就先从这里进。

## 🧩 这几组方案到底分别解决什么

### 内容创作与发布
这一组适合你先做：
- 小红书内容
- 公众号文章
- PPT 汇报稿
- X/Twitter 搜索、阅读、发推与互动（第三方插件）
- 多平台内容改写（一篇内容适配多个平台）

如果你想先把"今天就能发 / 今天就能讲"的内容做出来，直接进入：
- [01-内容创作与发布](./01-内容创作与发布/01-总览.md)

### 办公效率与知识整理
这一组适合你先做：
- 会议纪要
- 项目日报
- 资料总结
- 行动计划（把目标拆成可执行任务表）
- 邮件群消息摘要（把长邮件或群消息压成结构化摘要）

如果你想先把“今天就要整理 / 今天就要发”的办公输出做出来，直接进入：
- [02-办公效率与知识整理](./02-办公效率与知识整理/01-总览.md)

### 应用开发与快速原型
这一组适合你先做：
- 微信小程序骨架
- Web 原型
- 第一版页面、目录、接口和可开工结构

如果你想先把“一个想法压成第一版能开工的原型”，直接进入：
- [03-应用开发与快速原型](./03-应用开发与快速原型/01-总览.md)
