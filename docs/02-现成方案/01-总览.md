# 01-总览｜现成方案

> 一句话先说清楚：这一层不是让你先学概念，而是让你先挑一套已经能直接试跑的现成方案。

## 👀 这层现在有什么

当前这一层已经能直接进入 3 组现成方案：

| 二级模块 | 这组主要解决什么 | 你什么时候先看它 | 入口页 |
|---|---|---|---|
| 01-内容创作与发布 | 先把小红书、公众号、PPT 这类内容输出跑出来 | 你今天就想先出一版内容、文章或汇报稿 | [01-内容创作与发布](./01-内容创作与发布/01-总览.md) |
| 02-办公效率与知识整理 | 先把纪要、日报、资料总结这类办公输出跑出来 | 你刚开完会、要发日报，或手里有资料要整理 | [02-办公效率与知识整理](./02-办公效率与知识整理/01-总览.md) |
| 03-应用开发与快速原型 | 先把小程序、Web 原型这类开发想法压成第一版可开工结构 | 你已经有产品想法，想先拿页面、目录、接口和骨架 | [03-应用开发与快速原型](./03-应用开发与快速原型/01-总览.md) |

如果你现在的目标是：
- 先找一套现成打法，不想从零拆
- 手里已经有明确目标，比如内容、办公整理、原型开发
- 更关心“能不能马上开始试”，而不是先补一堆背景知识

那就先从这里进。

## 🧩 这几组方案到底分别解决什么

### 内容创作与发布
这一组适合你先做：
- 小红书内容
- 公众号文章
- PPT 汇报稿

如果你想先把“今天就能发 / 今天就能讲”的内容做出来，直接进入：
- [01-内容创作与发布](./01-内容创作与发布/01-总览.md)

### 办公效率与知识整理
这一组适合你先做：
- 会议纪要
- 项目日报
- 资料总结

如果你想先把“今天就要整理 / 今天就要发”的办公输出做出来，直接进入：
- [02-办公效率与知识整理](./02-办公效率与知识整理/01-总览.md)

### 应用开发与快速原型
这一组适合你先做：
- 微信小程序骨架
- Web 原型
- 第一版页面、目录、接口和可开工结构

如果你想先把“一个想法压成第一版能开工的原型”，直接进入：
- [03-应用开发与快速原型](./03-应用开发与快速原型/01-总览.md)

## 🗺 默认主线

如果你不想选，最稳的顺序是：

1. 内容输出优先走 [01-内容创作与发布](./01-内容创作与发布/01-总览.md)
2. 办公整理优先走 [02-办公效率与知识整理](./02-办公效率与知识整理/01-总览.md)
3. 开发原型优先走 [03-应用开发与快速原型](./03-应用开发与快速原型/01-总览.md)

## ✅ 看完这页你应该立刻能判断什么

看完后，你应该能马上判断：
- 我现在更适合先拿一套内容方案、办公整理方案，还是开发原型方案
- 当前仓库里有哪些已经能直接拿来试的现成方案
- 我下一步该不该直接进内容创作、办公效率，还是应用开发与快速原型总览
