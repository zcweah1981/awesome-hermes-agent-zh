# 02-微信小程序助手

> 一句话定位：这个方案帮助想快速做出微信小程序 MVP 的个人开发者或小团队，在需求还不大、时间很紧的时候，先产出一套能直接开工的结构化实现包。

---

## 1. 这是什么方案

### 核心场景
你已经有一个明确的小程序想法，但还不想一上来就陷入“先写代码还是先画页面”的混乱状态。这个方案会先把需求整理成适合开工的结构化产物。

### 最终结果
你最后会拿到一份可直接进入开发的最小实现包，至少包括：页面清单、功能清单、数据结构建议、接口建议、开发顺序、测试检查单。

### 页面定位
这是一个可直接应用的方案页，不是教程页，也不是概念页。重点不是教你学会微信小程序，而是让你先把一个最典型的小程序 MVP 方案跑通。

---

## 2. 适合谁

### 适合谁
- 有明确业务想法，但还没把小程序需求拆成可执行结构的人
- 想用 Hermes 先把产品、实现、接口、测试顺序整理出来的人
- 想验证“一个人能不能先把 MVP 方案盘清楚”的个人开发者或小团队

### 更适合什么阶段的人
- 新手先跑通：已经知道要做小程序，但还没形成开发清单
- 已经有基础、想提效：不想每次都从空白文档重新拆需求
- 小团队开始协作：希望产品、实现、接口、测试之间先有共同底稿

---

## 3. 你要准备什么

### 最少准备项
- 一个明确的小程序主题
- 一个最小目标用户场景
- 一个你愿意先只做 MVP 的范围边界

### 标准输入
- 业务目标：例如“做一个活动报名微信小程序”
- 场景说明：例如“社群活动发布后，用户能报名、查看时间地点、收到报名结果”
- 约束条件：例如“先不接支付、不做复杂后台、不做裂变”

### 标准输出
- 页面清单
- 功能清单
- 数据结构建议
- 接口建议
- 开发顺序
- 测试检查单

## 5. 默认推荐

### 默认入口
- ACP / CLI

### 默认模型
- 默认推荐：稳定的长上下文编码模型（如 Claude Sonnet 级）
- 备选推荐：稳定的国产编码模型（如 GLM-4.5-Air / DeepSeek-V3.1 级）

### 默认使用方式
先把业务想法和边界喂给 Hermes，不直接要求它“把小程序写完”，而是要求它先输出结构化开工包。也就是说，先要方案骨架，再决定代码实现顺序。

推荐的触发方式是：
- 在 ACP 里围绕当前项目目录协作
- 或在 CLI 里用一段明确任务说明触发

### 默认实现方式
- 默认 Profile：`miniapp-lab`
- 默认 SOUL：微信小程序产品与实现专家
- 默认 SKILL：`wechat-mini-program-assistant`
- 是否需要脚本：首版不强制，但要保留后续补脚本空间

## 6. 5 分钟跑通

### 用户怎么使用
1. 先用一句话说清你要做的小程序场景
2. 再补三个输入：用户是谁、最小闭环是什么、这版先不做什么
3. 让 Hermes 输出页面清单、功能清单、接口建议、开发顺序、测试检查单
4. 用结果去判断：这是一个人先做，还是要切成团队协作版

### 最小触发方式
- 命令 / Slash command / 平台消息触发：

```text
请按“微信小程序助手”方案帮我拆一个活动报名微信小程序 MVP。输出页面清单、功能清单、数据结构建议、接口建议、开发顺序、测试检查单。已知约束：先不做支付、先不做复杂后台、先不上裂变。
```

### 跑通后你会看到什么
- 结果 1：不是泛泛建议，而是一份结构化实现清单
- 结果 2：你能直接判断 MVP 边界是否过大
- 结果 3：你能直接进入开发或分派协作角色

---

## 7. 超级个体版 / 团队协作版

### 超级个体版

#### 定义
一个人独立把“小程序从想法整理成可开工方案”的版本。

#### 最小流程
1. 输入业务目标与最小范围
2. 产出页面清单与功能清单
3. 产出接口建议与开发顺序
4. 用测试检查单确认 MVP 没超范围

#### 交付结果
- 最终拿到什么：一份可直接开始做的 MVP 结构化方案
- 哪一步需要人工确认：页面范围取舍、是否真的先不做支付/后台/裂变

### 团队协作版

#### 是否建议首批上线
- 建议

#### 最小角色
- 角色 1：产品整理
- 角色 2：小程序实现
- 角色 3：接口/后端协作
- 角色 4：测试确认（可选）

#### 最小交接顺序
1. 产品整理出页面清单、功能清单
2. 小程序实现接收页面与交互结构
3. 接口协作确认数据结构与 API 顺序
4. 测试确认最小闭环是否成立

#### 团队版交付物
- 中间产物 1：页面与功能结构表
- 中间产物 2：接口与数据结构建议
- 最终交付物：可进入开发排期的 MVP 实施包
