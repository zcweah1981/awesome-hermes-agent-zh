# 01-总览｜内容创作与发布

> 一句话先说清楚：这一层不是教你系统学内容运营，而是帮你先挑一套已经能直接试跑的内容生成方案，先把第一轮内容做出来。

## 👀 这一层现在有什么

当前这一层已经能直接进入 3 套现成方案：

| 页面 | 这套方案主要解决什么 | 你什么时候先看它 |
|---|---|---|
| [02-小红书内容助手](./02-小红书内容助手.md) | 先把一篇短内容或一周内容线压出来 | 你今天就想先发一篇内容，或先拉一周选题 |
| [03-公众号写作助手](./03-公众号写作助手.md) | 先把一篇文章或一组系列选题压出来 | 你已经知道主题，想先拿文章结构和正文初稿 |
| [04-PPT 助手](<./04-PPT%20%E5%8A%A9%E6%89%8B.md>) | 先把一套汇报结构或逐页讲稿压出来 | 你接下来要讲、要汇报、要做路演或周会材料 |

如果你现在的目标是：
- 今天就想先拿一版内容出来
- 不想自己从选题、结构、标题、正文一路慢慢磨
- 更关心“先跑通一轮”，而不是先学一整套方法论

那就直接从这一层进。

## 🧩 这三套方案分别解决什么

### 小红书内容助手
适合你想先做：
- 今天就能发的一篇小红书
- 围绕一个产品连发一周的内容线
- 标题、开头、正文、封面短句、评论引导一套拿齐

直接进入：
- [02-小红书内容助手](./02-小红书内容助手.md)

### 公众号写作助手
适合你想先做：
- 一篇能继续细修的公众号文章
- 一组连续主题的系列选题
- 标题、导语、正文结构、收口和续写方向

直接进入：
- [03-公众号写作助手](./03-公众号写作助手.md)

### PPT 助手
适合你想先做：
- 一版先能讲通的汇报结构
- 一套逐页可展开的讲稿
- 页序、每页要点、备注、图表提示和继续落版动作

直接进入：
- [04-PPT 助手](<./04-PPT%20%E5%8A%A9%E6%89%8B.md>)

## 🚦 如果你现在只想快速选一个

直接按当前状态走：

- 今天就想先发一篇内容 → [02-小红书内容助手](./02-小红书内容助手.md)
- 想先写一篇更完整、更适合沉淀的长文章 → [03-公众号写作助手](./03-公众号写作助手.md)
- 想先把一次汇报、路演或周会材料讲顺 → [04-PPT 助手](<./04-PPT%20%E5%8A%A9%E6%89%8B.md>)

## 🗺 默认主线

如果你不想自己选，最稳的顺序是：

1. 先从 [02-小红书内容助手](./02-小红书内容助手.md) 跑一轮，最快感受这套方案值不值得用
2. 跑通后，如果你要写更完整的长内容，再进 [03-公众号写作助手](./03-公众号写作助手.md)
3. 如果你的目标其实是汇报、路演、周会材料，再直接进 [04-PPT 助手](<./04-PPT%20%E5%8A%A9%E6%89%8B.md>)

## ✅ 看完这页你应该立刻能判断什么

看完后，你应该能马上判断：
- 我现在更适合先做短内容、长文章，还是汇报材料
- 我应该先跑单篇内容，还是先拉一周 / 一组内容线
- 我下一步该不该直接进小红书、公众号，还是 PPT 助手页
