# 01-总览｜办公效率与知识整理

> 一句话先说清楚：这一层不是教你系统学项目管理或知识管理，而是帮你先挑一套已经能直接试跑的办公效率方案，把第一轮纪要、日报或总结做出来。

## 👀 这一层现在有什么

当前这一层已经能直接进入 3 套现成方案：

- [02-会议纪要助手](./02-会议纪要助手.md)
- [03-项目日报助手](./03-项目日报助手.md)
- [04-资料总结助手](./04-资料总结助手.md)

如果你现在的目标是：
- 会刚开完，想先把纪要整理出来
- 今天就得把日报发出去
- 手里有一堆资料，想先压成一版结构化总结

那就直接从这一层进。

## 🧩 这三套方案分别解决什么

### 会议纪要助手
适合你想先做：
- 把会议内容压成一版可直接发的纪要
- 区分结论、决定、待办和未决问题
- 拉出动作项、负责人和截止时间

直接进入：
- [02-会议纪要助手](./02-会议纪要助手.md)

### 项目日报助手
适合你想先做：
- 今天就能发出去的一版项目日报
- 标准日报和管理者版日报两种输出
- 今日事项、关键结果、风险阻塞、明日计划一次整理清楚

直接进入：
- [03-项目日报助手](./03-项目日报助手.md)

### 资料总结助手
适合你想先做：
- 把零散资料先压成结构化总结
- 快速提炼重点、结论、风险和建议动作
- 先给自己一版能继续展开或继续汇报的摘要底稿

直接进入：
- [04-资料总结助手](./04-资料总结助手.md)

## 🗺 默认主线

如果你不想自己选，最稳的顺序是：

1. 会后整理优先走 [02-会议纪要助手](./02-会议纪要助手.md)
2. 如果你的刚需是日更同步，再进 [03-项目日报助手](./03-项目日报助手.md)
3. 如果你手里是文档、报告、调研材料，再进 [04-资料总结助手](./04-资料总结助手.md)

## ✅ 看完这页你应该立刻能判断什么

看完后，你应该能马上判断：
- 我现在更需要纪要、日报，还是资料总结
- 我该先出完整记录，还是先出更偏管理者 / 决策者视角的版本
- 我下一步该不该直接进会议纪要、项目日报，还是资料总结助手页
