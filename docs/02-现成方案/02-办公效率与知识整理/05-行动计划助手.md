# 行动计划助手

> 一句话先说清楚：这一页不是教你系统学项目管理，而是帮你把一个目标、一场会或一次讨论的结果，直接压成"团队能立刻执行的行动计划表"。

---

## 一、这是什么方案

你手里可能已经有了一堆讨论记录、会议纪要、项目目标文档或飞书/企微/钉钉群里的零散信息。问题是：**下一步到底谁做什么、什么时候交、优先级怎么排？**

行动计划助手做的事很简单：把你喂进去的目标或讨论内容，自动拆成一张行动计划表，包含：

- 动作项（具体要做什么）
- 负责人（谁来做）
- 截止时间（什么时候交）
- 优先级（先做哪个）
- 依赖关系（哪些动作之间有先后）

输出格式直接可复制粘贴到飞书文档、企业微信待办或钉钉任务板。

**典型场景**：产品经理刚开完需求评审会，手上有会议纪要和结论，但还没把结论拆成团队能执行的任务。把纪要喂给 Hermes，直接拿到一张行动计划表，发到群里就能开工。

---

## 二、适合谁

| 你如果像这样 | 这个方案适合你 |
|---|---|
| 会刚开完，纪要有了，但还没拆成具体任务 | ✅ 把纪要喂进去，直接出行动计划 |
| 项目刚启动，目标定了，但执行路径不清晰 | ✅ 把目标文档喂进去，拆出阶段性动作 |
| 飞书/企微/钉钉群里讨论了一堆，但没人总结谁做什么 | ✅ 把聊天记录贴进去，直接出任务分配表 |
| 每周例会后都要手动整理待办，耗时且容易漏 | ✅ 例会后自动生成行动计划，节省整理时间 |
| 接到一个新需求，想快速拆解执行步骤 | ✅ 把需求描述喂进去，得到分解后的行动表 |

---

## 三、你要准备什么

### 必须有

1. **Hermes Agent 已安装并能正常运行**（参见[先跑起来](/docs/start/get-running)）
2. **一段你想要转化为行动计划的原始内容**，比如：
   - 会议纪要文本（飞书导出、手动记录、语音转写都行）
   - 项目目标文档
   - 飞书/企微/钉钉群聊记录（直接复制粘贴）
   - 一次头脑风暴的要点清单

### 建议有

- 团队成员名单（这样行动计划可以直接标注负责人）
- 项目时间线或里程碑（帮助 Agent 推算合理的截止时间）
- 已知的约束条件（比如"下周三之前必须上线"）

---

## 四、页面结构

一个合格的行动计划输出，应该包含以下层级：

```
📋 行动计划输出结构
├── 📌 目标摘要（一句话概括本次行动要达成什么）
├── 🏷️ 行动项列表
│   ├── 动作 1：具体任务 / 负责人 / 截止时间 / 优先级 / 依赖项
│   ├── 动作 2：...
│   └── 动作 N：...
├── ⚠️ 风险与阻塞（哪些动作可能卡住、卡在哪）
├── 📅 建议执行顺序（按依赖关系排的先后次序）
└── ✅ 发送版正文（可直接复制发到飞书/企微/钉钉群）
```

每个动作项至少包含 5 个字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| 动作 | 具体要做什么 | "完成首页改版设计稿" |
| 负责人 | 谁来做 | "@张三" |
| 截止时间 | 什么时候交 | "2026-05-22（周五）" |
| 优先级 | P0/P1/P2 | "P0 — 阻塞后续所有前端" |
| 依赖 | 这个动作依赖哪些前置动作 | "依赖：API 接口文档定稿" |

## 五、默认推荐

如果你不想选，默认走这条路径：

**标准行动计划（先出完整版，再出精简版）**

1. 把原始内容完整喂给 Hermes
2. 先让 Agent 输出完整的行动计划表（包含所有字段）
3. 再让 Agent 输出一版精简版（只保留动作 + 负责人 + 截止时间），方便发群

原因：
- 先出完整版保证不漏信息
- 精简版适合快速同步和群内确认
- 两版都有了，进可攻退可守

## 六、5 分钟跑通

### 第一步：准备原始内容

从飞书、企微或钉钉复制一段会议讨论或项目目标，比如：

```
今天产品评审会结论：
1. 首页改版要做，优先级最高
2. 张三负责设计稿，这周五交
3. 李四负责前端开发，等设计稿出来后开始
4. 数据埋点方案王五这周先出一版
5. 下周三全员对齐进度
```

### 第二步：喂给 Hermes

```
请根据以下内容，帮我生成一份行动计划表。要求：每个动作项包含"具体任务 / 负责人 / 截止时间 / 优先级 / 依赖关系"，最后附一版可以直接发群的消息正文。

[粘贴你的原始内容]
```

### 第三步：拿到结果后检查

重点看这 3 件事：
1. **有没有漏动作**：原始内容里提到的每件事，行动计划里都覆盖了吗？
2. **依赖关系对不对**：谁等谁的东西，逻辑是否正确？
3. **截止时间是否合理**：如果有冲突或太紧，需要手动调整

如果这 3 件事都 OK，直接把发送版正文复制到飞书/企微/钉钉群即可。

## 七、超级个体版 / 团队协作版

### 超级个体版（一个人用）

适合你是独立工作者、自由职业者或一个人负责多个项目的场景。

**你的输入方式**：
- 直接把待办、想法、目标丢给 Hermes
- 不需要标注"负责人"（都是你自己）
- 重点看优先级和执行顺序

**示例 Prompt**：

```
我现在有三个并行任务：
1. 给客户 A 出方案（本周四前）
2. 写一篇技术博客（本周内）
3. 准备下周二的线上分享 PPT

请帮我排一个行动计划，按优先级和依赖关系排序，标注建议的每天时间分配。
```

**你会拿到**：一份按天排列的个人执行计划 + 每个任务的优先级理由。

---

### 团队协作版（多人用）

适合你是项目经理、产品经理或团队负责人，需要把任务拆分给不同人。

**你的输入方式**：
- 把会议纪要、群讨论或项目文档喂给 Hermes
- 附上团队成员名单和各自职责
- 明确项目里程碑和关键日期

**示例 Prompt**：

```
团队：张三（设计）、李四（前端）、王五（数据）、赵六（后端）
项目：小程序 v2.0 上线
目标日期：6 月 15 日

以下是今天的评审会纪要：
[粘贴纪要]

请生成行动计划表，标注每个动作的负责人、截止时间、优先级和依赖关系。最后输出一版可直接发到飞书群的行动计划消息。
```

**你会拿到**：
- 完整行动计划表（飞书/企微/钉钉可直接使用）
- 风险提醒（哪些动作可能卡住）
- 发送版消息（复制粘贴即发）

## 八、模板与下一步

### 可直接使用的 Prompt 模板

**模板 1：会议纪要 → 行动计划**

```
请根据以下会议纪要，生成行动计划表。

要求：
1. 每个动作项包含：具体任务 / 负责人 / 截止时间 / 优先级（P0/P1/P2） / 依赖关系
2. 最后附一版可以直接发到 [飞书/企微/钉钉] 群的行动计划消息
3. 标注可能的风险或阻塞点

会议纪要内容：
[在此粘贴]
```

**模板 2：项目目标 → 阶段性行动计划**

```
请根据以下项目目标，帮我拆解成阶段性行动计划。

项目名称：[填写]
目标日期：[填写]
团队：[列出成员和角色]

要求：
1. 按阶段拆分（准备期 / 执行期 / 收尾期）
2. 每个阶段列出具体动作项
3. 标注关键里程碑和风险点

项目目标内容：
[在此粘贴]
```

**模板 3：群讨论 → 待办清单**

```
请从以下群讨论记录中，提取所有待办事项，生成一份行动计划。

要求：
1. 每个待办标注：任务内容 / 建议负责人 / 建议截止时间
2. 按优先级排序
3. 输出一版可直接发群的消息

群讨论记录：
[在此粘贴]
```
