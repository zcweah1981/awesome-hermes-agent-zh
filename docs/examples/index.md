# 示例项目

Example 是“具体场景怎么做”的参考案例。

它们不只是一个空骨架，而是更接近实际使用方式的内容，所以这里放的是：
- 配置示例
- 技能示例
- 集成案例
- 面向业务或功能的参考实现

如果你需要的是最小起步骨架，请去 [Starter 模板](../starters/index.md)。

---

## 当前 Example 列表

### 1. 配置示例
路径：`/examples/configs`

当前包含：
- `deepseek.yaml`
- `qwen.yaml`

适合：
- 想快速理解某个模型怎么配
- 想看最小配置写法

---

### 2. 技能与集成示例
路径：`/examples/skills/webhook-notifier`

适合：
- 想把 Hermes 输出接到飞书、钉钉或其他 Webhook
- 想参考自定义工具/技能的落地方式

当前示例：
- `webhook-notifier`

---

## 怎么判断该看 Example 还是 Starter

看 Example，如果你需要：
- 一个具体问题的解决方式
- 某类模型配置的参考
- 某种集成方式的样板

不要把 Example 当成项目初始骨架。

看 Starter，如果你需要：
- 从空目录启动一个新项目
- 一套基础目录结构
- 一组可直接复制的初始模板

---

## 使用建议

1. 先确定你的目标是“搭骨架”还是“看案例”
2. 如果是从 0 开始搭项目，先看 [Starter 模板](../starters/index.md)
3. 如果是补某个能力，再看对应 example
