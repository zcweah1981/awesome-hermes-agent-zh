# 示例项目

这里收录更接近真实使用场景的 Hermes Agent 示例。

和 Starter 模板不同，这里的内容更偏“怎么组合成一个实际可用的工作流”。

---

## 适合谁

- 已经跑通 Hermes 基础环境
- 想看更真实的用法参考
- 想把 Agent 能力接到自己的业务流程里

---

## 示例会覆盖什么

### 1. 本地开发工作流
例如：
- 代码库巡检
- 文档整理
- 自动化脚本执行

### 2. 内容与信息处理
例如：
- 网页信息抓取
- 摘要生成
- 内容改写与整理

### 3. 团队协作流程
例如：
- 任务拆解
- 多角色协同
- 报告输出

---

## 怎么使用

### 先理解场景
先看这个示例解决什么问题，而不是先纠结每一行配置。

### 再替换成你的业务
把模型、输入源、输出格式换成你的真实需求。

### 最后做最小验证
先验证一个小流程跑通，再继续扩展。
