# team-basic starter 模板说明

当 single-agent 已经不够用，但你又不想一上来做复杂编排，team-basic 是最稳的过渡层。

---

## 适合谁

- 想从单 Agent 升级到基础协作的团队
- 需要最简单的角色分工
- 想先验证多 Agent 的收益

## 你会拿到什么

- 主控配置
- 多角色 prompt
- 一个基础的分工模板

---

## 适合解决什么问题

适合这类任务：
- 一个角色拆任务
- 一个角色执行
- 一个角色检查或测试

这已经足以覆盖很多轻量团队工作流。

---

## 推荐的起步方式

不要先做复杂团队系统，先做下面这种小闭环：
- PM / 主控：整理任务
- Coder：执行
- QA：验证

如果这个闭环稳定，再考虑更复杂的角色。
