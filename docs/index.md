## 为什么选 Hermes

Hermes Agent 适合那些已经不满足于“只会聊天”的 Agent 工具的开发者。

你来到这里，通常是因为你至少在找其中一件事：
- 先把 Hermes 安装并跑通
- 选一个更稳妥的模型 / provider 方案
- 复制一个能直接参考的案例或模板
- 解决国内环境下的配置、网络与兼容问题
- 判断是否值得从 OpenClaw 迁移过来

这里不把首页写成资料堆，而是把最常见的决策入口先给你排好。

## 核心能力

### 先走官方支持路径
- 优先使用官方 provider，而不是一开始就手写大量 custom 配置
- 先保证能跑通，再决定是否需要额外接入层
- 把复杂度留到真正需要的时候再引入

### 面向真实执行场景
- 不只讲安装，还覆盖方案、排障、迁移与协作
- 既给最短路径，也给接近真实工作的案例入口
- 保持 GitHub 内容源与独立站表达的一致性

### 为中文开发者降低认知成本
- 先用中文解释“为什么这样做”
- 再给对应页面与进一步资料
- 避免把首页写成术语列表或内部说明书
