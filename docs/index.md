## 这是什么？

**Hermes Agent 中文生态** 是一个由开发者驱动的实战门户。我们不翻译枯燥的文档，我们只提供能让你在 30 秒内跑通的配置文件和工作流模板。

## 为什么选择 Hermes？

相比于其他 Agent 框架，Hermes 拥有：
- **原生 ACP 协议**: 极低延迟的多智能体并发协作。
- **内置学习闭环**: 自动从会话中提取并持久化技能。
- **极简部署**: 哪怕是在 $5 的 VPS 上也能流畅运行。
