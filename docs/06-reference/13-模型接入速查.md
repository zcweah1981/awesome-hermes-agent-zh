# 🔎 13-模型接入速查

按厂商、产品与接入方式查找 Hermes Agent 的 provider、协议、endpoint、模型 ID 和最小配置。需要了解套餐适用场景与选型差异时，先看[国内模型总览](/docs/china/models)；遇到连接或密钥报错时，查看[Provider 与 endpoint 排障](/docs/issues/provider-endpoint)。

## 🧭 怎样使用速查

1. 在上方搜索名称、模型 ID、协议或 endpoint，也可先选择厂商、产品 / 套餐与原生或兼容接入方式。
2. 确认同一条记录的产品、区域、密钥类型与套餐权限，再复制模型 ID 或最小配置。将 `<YOUR_API_KEY>` 替换为自己的密钥，不把真实密钥放进聊天、截图或仓库。
3. 需要完整解释时，打开卡片中的“完整接入教程”；卡片也提供排障文档与核验来源。
4. 没有符合条件的记录时，调整搜索或点击“重置筛选”恢复全部接入方式。浏览器返回时保留该页面的筛选状态。

## 📖 核验范围与版本边界

这份速查为社区非官方整理，仅核对资料，未测试付费请求。记录与各厂商接入教程使用同一份模型元数据；独立页面汇总展示，不再把完整速查嵌入每篇介绍。

每条记录分别标注核验日期、Hermes 固定版本、官方来源和套餐权限。核验日期不是整个教程的全面更新承诺，也不代表你的账户已开通该模型。原生 provider 与兼容 API 是不同路线，不混用产品 Key、区域和 Base URL。

自动路由与预览模型的能力、计费及账户权益仍需按具体产品核对；不要只凭模型名称推断权限。主干变化与稳定发布的区别见[最新功能与版本边界](/docs/reference/latest-features)。
