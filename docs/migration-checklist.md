# 迁移后校验清单

从旧工作流迁到 Hermes 后，不要只看“能不能跑”，还要检查“是不是可持续”。

---

## 迁移后至少检查这 6 项

- 已能稳定安装与启动
- 已切换到目标 provider
- 已跑通一个真实任务
- 输出质量达到最低可用标准
- 关键流程可重复执行
- 旧系统与新系统的边界已明确

---

## 三层校验法

### 第一层：能不能跑

- 命令可执行
- 模型可调用
- 输出可产生

### 第二层：能不能复用

- 不是一次性成功
- 同样任务再次执行仍能成功
- 目录、配置、说明足够清楚

### 第三层：能不能交给别人接手

- README 是否说清楚
- 项目文件是否完整
- 决策是否有记录
