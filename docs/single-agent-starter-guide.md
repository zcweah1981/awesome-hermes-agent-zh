# single-agent starter 模板说明

如果你只想先把 Hermes 跑起来，不需要一开始就上多 Agent。single-agent 是最适合起步的 starter。

---

## 适合谁

- 第一次使用 Hermes 的个人开发者
- 想先跑一个单 Agent 助手
- 想从最小结构开始，再逐步扩展

## 你会拿到什么

通常包含：
- 最小 `config.yaml`
- 一个 `system_prompt.txt`
- 可直接复制改造的基础目录结构

---

## 什么时候该先用它

优先在这些场景使用：
- 你还没跑通过 Hermes
- 你只想验证一个模型能否稳定工作
- 你想先把目录结构搭起来

---

## 不适合它的情况

如果你一开始就需要：
- 明确的 PM / Coder / QA 分工
- 复杂代码流程
- 多角色委派

那就应该看：
- [Starter 模板](./starters/index.md)
- team-basic 或 advanced-coding-team

---

## 推荐使用顺序

1. 先看 [快速开始](./quick-start.md)
2. 再看 [模型与 Provider](./models.md)
3. 然后进入 starter 目录做复制和改造
