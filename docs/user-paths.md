# Hermes 中文用户最常见的 3 条使用路径

不是每个人都需要同一套文档顺序。

这篇帮你快速判断：你属于哪条路径，应该先看哪几页。

---

## 路径 1：我只想先跑起来

适合：
- 第一次安装
- 想尽快看到结果
- 不想先研究复杂配置

推荐阅读顺序：
1. [快速开始](./quick-start.md)
2. [模型与 Provider](./models.md)
3. [常见问题](./known-issues.md)

---

## 路径 2：我想搭一个项目骨架

适合：
- 想做自己的 Agent 项目
- 需要 starter
- 需要一个可复制的结构

推荐阅读顺序：
1. [Starter 模板](./starters/index.md)
2. [single-agent starter 模板说明](./single-agent-starter-guide.md)
3. [team-basic starter 模板说明](./team-basic-starter-guide.md)
4. [Hermes 项目目录组织规范](./project-structure.md)

---

## 路径 3：我想做团队协作或迁移旧系统

适合：
- 已经在用其他 Agent 框架
- 想扩到多 Agent
- 想评估 Hermes 的业务价值

推荐阅读顺序：
1. [怎么选，怎么迁](./migrate/compare.md)
2. [从 OpenClaw 过来](./migrate/index.md)
3. [多 Agent 协作](./team-flow.md)
