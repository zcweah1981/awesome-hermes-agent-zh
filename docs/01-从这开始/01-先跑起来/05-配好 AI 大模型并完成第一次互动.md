# 💬 05-配好 AI 大模型并完成第一次互动

现在 Hermes 已经装好了，下一步就是接上一个可用的 AI 大模型，然后在命令行里和 Hermes 说上第一句话。

---

## 🧭 先把最小闭环跑通

这一页只补齐三件事：

- 一个可用模型
- 一次最小模型配置
- 一次真实回复

先别去研究更复杂的 provider、多模型切换或高级工作流，先把第一次互动闭环跑通。

---

## ① 先配置默认模型

```bash
hermes model
```

![Hermes 模型设置成功图：在终端里完成 provider 和默认模型确认，系统返回模型已设置结果](../../assets/rm2-2-first-hello-01-model-setup-success.png)

在 `hermes model` 里，先选一个你当前能用的 provider，再选一个能直接跑通的默认模型并保存。

这一步的目标不是“选到最强模型”，而是先选到“现在就能正常工作”的模型。

配置完成后，你应该能明确知道：

- 当前走的是哪个 provider
- 当前默认模型是什么
- 设置已经被保存，而不是停在半路

---

## ② 启动 Hermes

```bash
hermes
```

模型配置完成后，直接启动 Hermes，确认它能进入交互状态，不要刚启动就退出。

如果启动阶段直接报错，先检查：

- 默认模型是否真的保存成功
- 上一页里的安装与命令检查是否已经通过
- 当前 provider / model 是否还能正常使用

这一层只需要确认一件事：

Hermes 已经能够在你当前环境里顺利进入交互状态。

---

## ③ 对 Hermes 说第一句话

你可以直接发一句最简单的话，例如：

- 你好，Hermes
- 请介绍一下你自己
- 请用一句中文确认你已经可以正常工作

或者直接用这条命令快速验证：

```bash
hermes chat -q "你好，Hermes。请用一句中文确认你已经可以正常工作。"
```

![Hermes 第一次成功互动图：在终端里发出第一句话，并收到正常中文回复](../../assets/rm2-2-first-hello-02-first-reply-success.png)

如果这里能收到一条正常回复，就说明你已经真正完成了第一次互动。

你真正想看到的不是“界面打开了”，而是：

- Hermes 收到你的输入
- Hermes 正常调用模型
- Hermes 返回一条可读的回复

---

## 🔎 如果第一句话没成功，先只查这几件事

先别一下子跳去研究所有 provider 文档。
优先只查这几件事：

1. `hermes model` 里是不是已经真正保存了默认模型
2. 当前 provider 的 key / token 是否可用
3. 你启动的是不是当前这个已经配好的 profile / 环境
4. 你执行 `hermes chat -q` 时有没有返回明确报错

只要你把“模型已设好、Hermes 能启动、能收到第一条回复”这条链闭上，这一页就过了。

---

## ✅ 这一页什么时候算通过

满足下面三件事，这一页就通过：

1. 你已经通过 `hermes model` 配好一个可用模型
2. 你已经能正常启动 `hermes`
3. 你已经收到 Hermes 的第一条正常回复

这也意味着你已经完成了“先跑起来”整个阶段。
