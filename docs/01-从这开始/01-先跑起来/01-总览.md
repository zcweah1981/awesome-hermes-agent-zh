# 🚀 01-先跑起来

![先跑起来四步路径图：准备环境、连接终端、安装 Hermes、第一次回复](../assets/rm2-2-get-running-index-06-stage-map-closed.png)

这一阶段只解决一件事：让你拿到 Hermes 的第一次正常回复。  
不要先研究高级配置，也不要急着看后面的能力页，先把最短闭环跑通。

## 这一页你会完成什么

- 先选对运行环境
- 再连到正确的终端
- 完成 Hermes 安装
- 拿到第一次回复

## 建议阅读顺序

按上面的顺序依次完成，不要跳步。

如果你还没选好环境，先从 [02-准备环境](./02-准备环境.md) 开始。
如果你已经知道要跑在哪台机器上，就直接进入下一页。

## 完成标准

只要下面三件事都成立，这一阶段就算完成：

- 运行环境已经选定
- 终端已经连通
- Hermes 已经能正常回复

这一阶段的目标不是“先把所有能力看懂”，而是“先把第一次跑通”。
