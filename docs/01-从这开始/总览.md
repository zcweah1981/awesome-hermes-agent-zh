# 🧭 01-从这开始

![Hermes 学习路径总览](../assets/rm2-learning-path-gemini-final-v2.jpg)

> 一句话先说清楚：这一组内容不是功能索引，而是 Hermes 中文站的学习主线入口，先帮你判断自己现在该从哪一段开始。

如果你是第一次接触 Hermes，最容易踩的坑不是不会装，而是一上来就把文档当资料库乱翻。
这一组内容按学习路径来带你走：先跑起来，再开始上手，然后玩出花样，最后自己造东西。

## 🚦 你现在应该从哪一段开始

如果你不想先看整张表，直接按当前状态选：

- 你还没完成第一次正常回复 → [01-先跑起来](./01-先跑起来/01-总览.md)
- 你已经装过一次，但平时还不会稳定使用 → [02-开始上手](./02-开始上手/01-总览.md)
- 你已经会日常使用，想让 Hermes 更像你、更顺手 → [03-玩出花样](./03-玩出花样/01-总览.md)
- 你已经不满足于“用一个助手”，想开始接系统、做自动化、多助手协作 → [04-自己造东西](./04-自己造东西/01-总览.md)

如果你还拿不准，就默认从 [01-先跑起来](./01-先跑起来/01-总览.md) 开始。

## 🧩 四个阶段怎么选

| 阶段 | 适合谁 | 这一阶段你会解决什么 | 学完你能达到什么 |
|---|---|---|---|
| [01-先跑起来](./01-先跑起来/01-总览.md) | 还没跑通 Hermes、还没完成第一次正常互动的人 | 选运行环境、进入终端、完成安装、接上模型、拿到第一次正常回复 | 你能真正把 Hermes 跑通，并拥有一条可重复的起步路径 |
| [02-开始上手](./02-开始上手/01-总览.md) | 已经装过一次，但还不会稳定使用的人 | 搞清楚基本用法、会话管理、常用命令、第一批 Skills 和常见入口 | 你能把 Hermes 稳定地用起来，而不是只跑通一次 |
| [03-玩出花样](./03-玩出花样/01-总览.md) | 已经会用 Hermes，想让它更像自己的人 | 调人格、调记忆、调模型、调工具、调外观，让使用体验更贴近自己 | 你能把一个助手调成更符合自己习惯的工作方式 |
| [04-自己造东西](./04-自己造东西/01-总览.md) | 想把 Hermes 接进工作流、做多助手、做自动化的人 | 多助手分工、外部记忆、上下文系统、外部接入、服务化、自动化、编辑器集成 | 你能从“用一个助手”进入“搭一套系统” |

## 🗺 默认顺序

第一次系统看 Hermes，建议按这个顺序往下走：

1. [01-先跑起来](./01-先跑起来/01-总览.md)
2. [02-开始上手](./02-开始上手/01-总览.md)
3. [03-玩出花样](./03-玩出花样/01-总览.md)
4. [04-自己造东西](./04-自己造东西/01-总览.md)

最稳的理解方式是：
- 先让 Hermes 回复你一次
- 再让你会持续使用它
- 再让它更贴近你自己的工作方式
- 最后再让它进入更完整的系统能力

不要一上来就直接看最重的系统层页面。
如果第一步没跑通，后面的理解都会虚。

## 🎯 如果你现在只想选一条最短主线

### 路线 A：第一次接触 Hermes
按这个顺序：
1. [01-先跑起来](./01-先跑起来/01-总览.md)
2. [02-开始上手](./02-开始上手/01-总览.md)

适合：

- 还不知道平时到底怎么用 Hermes

### 路线 B：已经会用，但想更顺手
按这个顺序：
1. [03-玩出花样](./03-玩出花样/01-总览.md)
2. 再按需要进入人格、记忆、模型、工具相关页

适合：
- 已经有稳定日常使用
- 想把 Hermes 调得更像自己

### 路线 C：已经不满足于“一个助手”
按这个顺序：
1. [04-自己造东西](./04-自己造东西/01-总览.md)
2. 再按目标进入多助手、外部记忆、上下文系统或外部接入

适合：
- 已经知道单助手不够
- 想开始搭工作流、系统能力或自动化
