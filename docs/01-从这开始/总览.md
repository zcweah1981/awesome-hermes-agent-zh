# 01-从这开始

![Hermes 学习路径总览](./assets/rm2-learning-path-gemini-final.jpg)

## ✨ 你在这里能很快知道什么

来到这一页，你应该快速弄清四件事：

- 我现在更适合从哪一段开始
- 这一段主要会帮我解决什么问题
- 学完这一段以后，我能达到什么状态
- 下一步应该进入哪个阶段页

---

## 📌 它和普通文档站有什么不同

普通文档站更像“功能目录”：
先把功能、命令、配置项都列出来，再由你自己决定从哪里开始。

这里不是这样。
这里按学习路径组织，先帮你判断：

- 你现在最该先解决什么问题
- 哪些内容现在不用急着看
- 哪一段学完以后，再进入下一段最顺

所以你在这里看到的，不是资料分类，而是四个清晰的学习阶段。
