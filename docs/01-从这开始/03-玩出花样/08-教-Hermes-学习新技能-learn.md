# 08-教 Hermes 学习新技能（/learn）

> 💡 **速答**：`/learn` 让 Agent 能够从你的对话中“提炼逻辑”。当你完成了一次复杂的调试或处理后，输入 `/learn`，Agent 会将这段操作路径固化为永久的 **Skill**。

![Hermes 自进化架构：演示 -> 提炼 -> 固化](../../assets/play-tricks-learn-v1.webp)

---

## 🧠 核心原理：演示即编程
不再需要写复杂的 YAML 技能文件。你只需要：
1. **演示**：带 Agent 执行一遍，如“抓取特定网页 -> 提取价格 -> 存入数据库”。
2. **指令**：任务成功后，直接发送 `/learn`。
3. **成果**：Agent 会说“已提炼技能 `web-price-to-db`”，下次你只需说“帮我执行价格抓取”即可。

---

## ⚠️ 注意事项
- **质量门禁**：仅在 Agent **完美执行**任务后执行 `/learn`。
- **配合 /journey**：你可以先用 `/journey` 查看当前的执行链路，确认逻辑无误后再学习。
