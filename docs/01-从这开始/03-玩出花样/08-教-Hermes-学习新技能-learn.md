# 08-教 Hermes 学习新技能（/learn）

> 💡 **速答**：`/learn` 是 Hermes v0.18.0 引入的自进化能力。当你通过对话成功解决一个复杂问题后，输入 `/learn`，Agent 会自动总结操作路径并将其保存为永久的 **Skill**。

---

## 🧠 核心原理：演示即编程

在 v0.18.0 之后，教 Agent 学习不再需要手动编写代码，只需要“言传身教”：
1. **引导**：你带领 Agent 完成一次复杂的流程。
2. **提炼**：任务成功后输入 `/learn`。
3. **固化**：Agent 生成 Skill 描述，确认后存入 `~/.hermes/skills/`。

## 🛠️ 实战场景：固化数据清理流程

**对话示例：**
- **用户**：\"Hermes，读取 data.csv，删除空行，把日期列转成 ISO 格式，最后按用户 ID 排序。\"
- *(Agent 执行成功)*
- **用户**：`/learn 固化 CSV 标准清洗流程`
- **Agent**：\"收到！我已经提炼了读取 -> 清洗 -> 格式化 -> 排序的逻辑。已保存为 `csv-clean-standard` 技能。\"

---

## 📈 配合 /journey 观察

`/journey` 指令可以让你查看当前任务的逻辑演进图，帮助你确认 Agent 在学习过程中是否理解了正确的逻辑路径。

## ⚠️ 注意事项
- **环境要求**：提炼的 Skill 必须在当前环境下工具可用时才能复现。
- **质量门禁**：只在任务执行完美时使用 `/learn`。
