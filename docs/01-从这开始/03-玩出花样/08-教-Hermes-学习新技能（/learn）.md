# 08-教 Hermes 学习新技能（/learn）

> 💡 **速答**：`/learn` 是 Hermes v0.18.0 引入的“神技”。当你手动带 Agent 完成了一次复杂的、多步骤的任务后，输入 `/learn`，它会自动总结这次成功的经验，并提示你将其保存为一个永久的 **Skill**。下次遇到类似任务，它就能自主执行，不再需要你手把手教。

---

## 🧠 为什么要用 /learn

在 v0.18.0 之前，如果你想给 Hermes 增加新能力，你需要手动编写 `SKILL.md` 文件。
现在，你可以通过“言传身教”来完成：
1. **演示**：你通过对话引导 Agent 完成任务（例如：按照特定格式整理一份日报）。
2. **提炼**：任务成功后，输入 `/learn`。
3. **固化**：Agent 会生成一份 Skill 描述，你确认后，它就成了 Agent 的“肌肉记忆”。

## 🛠️ 指令实战

### 1. 指令语法
```text
/learn [可选描述]
```
如果你不加描述，Agent 会默认复盘整个当前会话。

### 2. 使用场景示例：固化特定的代码审查流程
**用户**："嘿 Hermes，以后查这个项目的 PR，必须先跑 lint，再查 SQL 注入风险，最后按我这个格式输出。"
*(引导 Agent 完成了一次审查)*
**用户**：`/learn 固化本项目专属的代码审查流程`
**Hermes**："收到！我已经提炼了 lint -> SQL 检查 -> 格式化输出的步骤。是否保存为 `custom-repo-review` Skill？"

---

## 📈 配合 /journey 观察成长

`/journey` 指令可以让你以“上帝视角”查看 Agent 是如何思考和推进任务的。
- 它会展示任务的**逻辑树**。
- 它会标记哪些路径是死路，哪些路径最终通向了成功。
- 它是你评估 Agent 是否“学歪了”的重要参考。

## ⚠️ 注意事项

- **环境依赖**：`/learn` 提炼出的 Skill 如果依赖特定的本地工具，请确保环境里已安装。
- **质量第一**：只有当会话结果是**正确且高效**的时候，才使用 `/learn`。如果中间有过多的反复尝试，Agent 提炼时可能会混入无效步骤。
