## 🚦 推荐阅读顺序

如果你没有明确目标，建议按这个顺序走：

**第一周（基础场景）**：

1. 先跑 [每日晨间简报](./01-用%20Hermes%20做每日晨间简报.md)，确认 Cron 自动化价值。
2. 再接 [Telegram](./02-Telegram%20消息入口接入.md)，让结果能送到你真正会看的地方。
3. 接着做 [GitHub 备份](./03-GitHub%20备份%20Cron%20Job.md)，保护本地配置资产。
4. 然后看 [模型级联](./04-月费8美金三层模型级联省钱指南.md) 和 [Token 成本优化](./05-Token%20成本优化避坑指南.md)，把长期使用成本压住。

**第二周（集成扩展）**：

5. 想多入口协作 → [Discord 接入](<./11-Discord%20接入.md>)。
6. 想接外部系统 → [MCP 接入指南](<./12-MCP%20接入指南.md>)。
7. 有显卡想省钱 → [Ollama 本地模型](<./13-Ollama%20本地模型.md>)（原理）或 [最快路径](./21-Hermes%20Agent%20与%20Ollama%20最快路径.md)（速通）。
8. 维护代码仓库 → [GitHub PR 自动审查](<./14-GitHub%20PR%20自动审查.md>)。
9. 想沉淀工作流 → [自定义 Skills](<./15-自定义%20Skills.md>)。

**第三周（生产化）**：

10. **对外部署前必看** → [安全加固](<./16-安全加固.md>)。
11. 想语音交互 → [语音模式](<./17-语音模式.md>)。
12. 最后按需要选择 VPS、SOUL、Obsidian、Kanban 或 Home Assistant。

**第四周（深度进阶）**：

13. 准备生产 → [18-进阶实战](./18-Hermes%20Agent%20进阶实战.md)。
14. 多 Agent 团队 → [19-控制室](./19-Hermes%20Agent%20控制室.md)。
15. 想看真实案例 → [20-60 天工作流](./20-60%20天分析师工作流.md)。
16. 想理解内核 → [22-深度拆解](./22-Hermes%20Agent%20深度拆解与自建指南.md)。

## ✅ 这一组什么时候算跑通

当你至少完成其中一篇，并能回答下面三个问题，就算真正进入实战阶段：

- 这个场景是否解决了我每天/每周真实重复发生的问题？
- 我是否知道如何验证它真的跑通，而不是只看了文章？
- 我是否把 Token、访问令牌、API Key 放在 `.env` / 配置里，而不是写进仓库？
