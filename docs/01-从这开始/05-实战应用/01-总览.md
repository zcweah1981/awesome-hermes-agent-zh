## 🚦 推荐阅读顺序

如果你没有明确目标，建议按这个顺序走：

1. 先跑 [每日晨间简报](./01-用%20Hermes%20做每日晨间简报.md)，确认 Cron 自动化价值。
2. 再接 [Telegram](./02-Telegram%20消息入口接入.md)，让结果能送到你真正会看的地方。
3. 接着做 [GitHub 备份](./03-GitHub%20备份%20Cron%20Job.md)，保护本地配置资产。
4. 然后看 [模型级联](./04-月费8美金三层模型级联省钱指南.md) 和 [Token 成本优化](./05-Token%20成本优化避坑指南.md)，把长期使用成本压住。
5. 最后按需要选择 VPS、SOUL、Obsidian、Kanban 或 Home Assistant。

## ✅ 这一组什么时候算跑通

当你至少完成其中一篇，并能回答下面三个问题，就算真正进入实战阶段：

- 这个场景是否解决了我每天/每周真实重复发生的问题？
- 我是否知道如何验证它真的跑通，而不是只看了文章？
- 我是否把 Token、访问令牌、API Key 放在 `.env` / 配置里，而不是写进仓库？
