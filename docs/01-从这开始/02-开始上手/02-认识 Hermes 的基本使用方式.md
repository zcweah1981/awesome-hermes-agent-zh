# ⚙️ 02-认识 Hermes 的基本使用方式

![终端主入口界面截图：在 Linux 终端执行 `hermes` 后，界面显示已进入 Hermes Agent 交互主入口，并停在可继续输入的提示符位置。](../../assets/rm2-3-basic-usage-01-cli-main-surface.png)

> 这一页不讲高级玩法，只帮你把每天最常用的那条路径练顺：打开 Hermes、问一句、接着追问、最后正常退出。

如果你还没完成第一次互动，先回上一页：
- [01-先跑起来 / 05-配好 AI 大模型并完成第一次互动](../01-先跑起来/05-配好 AI 大模型并完成第一次互动.md)

---

## 🎯 这页做完以后，你应该得到什么

完成这页后，你应该能自然完成下面 4 个动作：
1. 启动 Hermes
2. 发出一条问题
3. 基于上一条回复继续追问
4. 退出会话或清理终端画面

如果这 4 个动作你还做不顺，就先别急着跳去学更多命令。

---

## 🚪 第一步：先记住日常主入口只有一个

平时最常用的入口就是：

```bash
hermes
```

为什么先记这个：
- 这是你以后每天最常回来的主入口
- 它适合连续对话，不是一次问完就结束
- 后面很多会话命令、Skills、工具管理，都是在这个入口里展开

成功标志：
- 你已经进入 Hermes 的交互界面
- 终端没有停在 `command not found` 之类的报错上
- 你知道以后要“开始用 Hermes”，默认先输这一条

如果这一步没成功，先查：
1. Hermes 是否已经安装完成
2. `hermes version` 能不能正常返回
3. 你是不是还在正确的终端环境里

---

## 💬 第二步：先完成一次最小对话闭环

进入 `hermes` 后，不要先研究菜单。
直接打一条最简单的问题，例如：
- 请用一句中文介绍你现在能帮我做什么
- 我刚完成安装，你建议我下一步怎么练习
- 请先用两句话说明你的基本使用方式

等 Hermes 回答后，立刻接一句追问，例如：
- 那你刚才提到的第一种方式，具体怎么做
- 如果我是第一次用，你建议我先做哪一步

为什么要这样练：
- 你需要先建立“连续对话”的肌肉记忆
- Hermes 的价值不只是单次问答，而是带着上下文继续工作

成功标志：
- 第一条消息能正常收到回复
- 第二条追问明显接住了上一轮上下文
- 你开始把 Hermes 当成一个持续工作的入口，而不是一次性命令

如果追问没有接住上下文，先查：
1. 你是不是退出后重新开了一个全新会话
2. 你是不是把问题发到了别的窗口或别的实例
3. 第一轮回复是否其实没有成功完成

---

## ⚡ 第三步：需要一次问完就退出时，用快速请求

有时你只想验证一下状态，或者只想发一个单次问题，不想停在交互界面里。
这时直接用：

```bash
hermes chat -q "请用一句中文确认你已经可以正常工作"
```

![终端快速请求返回截图：在终端执行 `hermes chat -q` 后，界面返回一条正常中文回复，并给出会话恢复信息。](../../assets/rm2-3-basic-usage-02-basic-chat-flow-success.png)

这条命令适合 3 种情况：
- 你只想快速验证 Hermes 现在是否正常
- 你只想问一次，不想留在交互界面
- 你在脚本、自动化或复制示例命令时想先跑最小验证

成功标志：
- 命令直接返回一条正常回复
- 返回结果不是报错、不是空白、不是半截输出
- 你已经能分清“交互式使用”和“单次调用”这两个入口

如果没成功，先查：
1. 引号有没有复制完整
2. 当前模型配置是否仍然可用
3. provider 凭证是否失效

---

## 🧭 第四步：先只学会最基础的 4 个动作

第一次开始上手时，先只练这 4 个动作：

1. 直接输入问题
2. 基于上一条回复继续追问
3. 按 `Ctrl+C` 退出当前使用
4. 执行 `clear` 清掉终端画面

这里最容易混淆的就是后两项：
- `Ctrl+C`：退出当前会话或当前运行
- `clear`：只是把屏幕清干净，不等于退出 Hermes

你现在真正需要的不是更多命令，而是把这 4 个动作练成本能。

成功标志：
- 你能自然完成提问和追问
- 你知道什么时候该退出，什么时候只是想清屏
- 你不会把退出和清屏混成一件事

如果你发现一按 `Ctrl+C` 就慌，先记一句最简单的话：
- 退出不可怕，后面还有会话恢复和历史管理可以接回来

---

## 👀 第五步：进入以后先看什么，不用急着看什么

进入 Hermes 后，先只记住下面 3 个事实：
- 你可以直接输入问题
- 你可以继续追问
- 输入 `/` 可以看到更多命令入口

但这一页先不要急着：
- 背完整斜杠命令表
- 研究 provider / model 切换细节
- 调 Tools、Toolsets、MCP、消息平台

原因很简单：
- 如果最基础的使用动作还不顺，后面学再多入口也会乱

---

## 🛠 如果你觉得“好像会用，但一上手还是乱”，先这样补练

按这个顺序再跑 1 次：
1. 执行 `hermes`
2. 问一句简单问题
3. 再追问一句
4. 按 `Ctrl+C` 退出
5. 执行 `clear`
6. 再执行一次 `hermes chat -q "请用一句中文确认你已经可以正常工作"`

只要这 6 步你能顺下来，你的基本使用方式就已经立住了。

---

## ✅ 这一页什么时候算通过

当下面这些事成立，这一页就通过：
- 你知道平时怎样启动 Hermes
- 你已经完成过一次“提问—追问”的连续对话
- 你知道什么时候用 `hermes`，什么时候用 `hermes chat -q`
- 你知道最基础的 4 个动作：提问、追问、退出、清屏
