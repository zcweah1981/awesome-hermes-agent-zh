# 🏷️ 04-常用 Skills（按日常使用场景精选）

第一次看到很多 Skills 很正常。你不需要一次学完全部，先认识最常用的一小部分就够了。

---

## 🧭 先记住这一页的目的

这一页不是让你背技能目录，而是帮你建立一个最小判断：

“我现在遇到的是哪一类任务，应该先想到哪一类 Skills？”

所以这里不会把所有 Skills 摊开，而是先按 4 个最常见的日常场景来收口。

---

## 🧭 先按 4 个日常场景来认识

![技能场景地图：第一次开始上手时，先认识文档与知识库、办公协作、研究检索、开发协作这 4 类常用 Skills](../../assets/rm2-3-skills-curated-01-skill-scenario-map.png)

### 🔹 文档与知识库

- `obsidian`
- `ocr-and-documents`
- `nano-pdf`
- `qmd`

适合：

- 看笔记
- 读长文档
- 抽取 PDF / 扫描件文字
- 整理资料

这一类的核心价值是：

把“资料在那儿，但你读不动、找不快、提炼不出来”的问题，先交给 Hermes 帮你处理。

### 🔹 办公协作

- `powerpoint`
- `plan`
- `apple-notes`（更适合 macOS 用户）

适合：

- 出提纲
- 做汇报材料
- 整理任务和会议内容

这一类最常见的用法不是“做复杂自动化”，而是先帮你把日常输出组织起来。

### 🔹 研究检索

- `arxiv`
- `duckduckgo-search`
- `blogwatcher`
- `llm-wiki`

适合：

- 查论文
- 查资料
- 跟踪更新
- 做主题研究

这一类适合“我要先搞清楚某个主题”的场景，不适合你还没想清楚问题就乱搜。

### 🔹 开发协作

- `github-auth`
- `codebase-inspection`
- `github-code-review`
- `systematic-debugging`

适合：

- 看仓库
- 做代码巡检
- 做代码 review
- 做调试定位

这一类即使你不是专业程序员，也可能会在“看 repo、查 issue、读代码结构”时很有用。

---

## ✅ 第一次开始用 Skills，最稳的方式是什么

![Skills 调用成功示意图：直接使用 arxiv skill 查找 AI Agents 论文，并返回论文标题、arXiv 编号、作者与中文重点概括](../../assets/rm2-3-skills-curated-02-skill-call-success.png)

第一次开始用 Skills，最稳的做法是：

1. 先看看当前有哪些 Skills
2. 再选一个最贴近日常工作的场景试一次

例如：

- 研究检索场景 → 直接用 `arxiv` 查一篇论文并先读摘要
- 文档场景 → 用 `ocr-and-documents` 处理资料
- 开发场景 → 用 GitHub 相关技能检查仓库

这里最重要的不是“试很多个”，而是先完成一次“按场景选对一个”的正反馈。

---

## 🧩 怎么判断自己先试哪一类

如果你拿不准，直接按你最近最常见的工作来选：

- 你最近总在读资料、读 PDF、整理知识 → 先试文档与知识库类
- 你最近总在写提纲、汇报、会议材料 → 先试办公协作类
- 你最近总在查新东西、做研究 → 先试研究检索类
- 你最近总在看代码、看仓库、查问题 → 先试开发协作类

不要为了“把技能都学完”而学。
先把最贴近你当前工作的一类用顺，价值才最大。

---

## 🔹 Tools 先只会查看就够了

第一次开始使用时，Tools 这层先别展开太深。

先记住：

```bash
/tools list
```

这条命令可以帮助你看当前有哪些工具可用。

这一页只要你先知道“当前有哪些能力在场”，就够了。
还不用立刻进入 toolsets、权限开关和更细的工具配置。

---

## 🚫 哪些先看，哪些先跳过

第一次开始使用，建议先看：

- 文档与知识库
- 研究检索
- 办公协作
- 开发协作

先跳过：

- 消息平台接入相关能力
- Open WebUI 这类接入型玩法
- 小众或非常垂直的 Skills
- 你现在根本用不到的专项能力

一句话原则：

先学“今天就用得上”的，不学“看起来很厉害但现在用不上”的。

---

## ✅ 这一页什么时候算通过

当下面这些事已经成立，这一页就通过：

- 你已经完成过一次 Skills 调用
- 你已经知道至少一类场景该用哪一类技能
- 你已经知道 Tools 先看状态就够
- 你已经知道下一批最值得先试的是哪几类 Skills
- 你不再把 Skills 当成必须一次学完的总目录
