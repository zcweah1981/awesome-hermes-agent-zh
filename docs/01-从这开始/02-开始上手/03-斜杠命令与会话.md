# ⌨️ 03-斜杠命令与会话

Hermes 的斜杠命令很多，这很正常。第一次开始使用时，不需要全记，先抓最常用的一小部分就够了。

## 🧭 先记住这件事

这一页只解决两件事：

- 先认出第一批最常用的命令
- 先学会保存和继续一个会话

## ➡️ 第一批最常用的 6 个命令

![常用斜杠命令分组图：第一次开始使用时先记住 /help、/tools、/model、/save、/title、/history](../assets/rm2-3-slash-commands-01-command-groups.png)

先记住这 6 个就够：

- `/help`：看当前有哪些命令入口
- `/tools`：看当前工具开关状态
- `/model`：确认或切换当前模型
- `/save`：保存当前会话
- `/title`：给当前会话起一个好找的名字
- `/history`：回看以前的会话记录

在 Hermes 交互界面里输入 `/`，先重点认这 6 个命令就行。

## 🔹 会话管理怎么理解

会话不是一次性问答，而是一段连续工作的上下文。

你先只要记住三件事：

- 当前会话可以保存
- 当前会话可以命名
- 退出以后还可以继续回来

## 🔹 两个最实用的会话恢复方式

![会话恢复命令链示意图：先用 `hermes sessions list` 找到会话 ID，再通过 `hermes --continue` 或 `hermes --resume 会话ID` 把旧会话接回来](../assets/rm2-3-slash-commands-02-session-save-resume.png)

最常用的恢复方式就两个；如果你忘了会话 ID，先用 `hermes sessions list` 找回来：

```bash
hermes --continue
hermes --resume 会话ID
```

- `--continue`：继续最近一次会话
- `--resume 会话ID`：恢复指定会话

## 🔹 顺手试试内置人格入口

如果你只是想快速试试不同说话风格，可以先轻量试一次：

```bash
/personality teacher
/personality concise
/personality technical
```

![内置人格命令回显示意图：先看到可用人格列表，再把 `teacher` 设置成功，并在后续回答里看到更偏解释型的输出](../assets/rm2-3-slash-commands-03-persona-command-success.png)

`/personality` 只是轻量试用入口，不是长期人格配置。

## ✅ 这一页什么时候算通过

当下面这些事已经成立，这一页就通过：

- 你知道第一次开始使用时先记哪几个命令

- 你知道怎么继续最近一次会话，或恢复指定会话
- 你知道 `/personality` 是轻量试用入口
