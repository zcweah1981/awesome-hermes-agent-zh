# 🧰 02-开始上手

![开始上手阶段路径图：从跑通一次到日常会用，四步路线一屏看清](../../assets/rm2-3-get-started-index-01-daily-usage-path.jpg)

这一阶段只做一件事：把 Hermes 从“能跑一次”变成“你会反复使用的日常助手”。

如果你已经完成过第一次互动，就从这里继续；如果还没跑通第一次回复，先回到 [01-先跑起来](../01-先跑起来/01-总览.md)。

## ❓ 这一阶段你会学到什么

走完这一阶段，你会建立起 4 个最小能力：

1. 会进入 Hermes，知道怎么提问、追问、退出
2. 会保存、命名、继续、恢复重要会话
3. 会按场景挑第一批常用 Skills
4. 会判断什么时候该把 Hermes 接到消息平台里

## ✅ 过关标准

当下面这些事都成立，这一阶段就算通过：

- 你能自然进入 Hermes 做日常提问
- 你知道怎么保存、命名、继续一个会话
- 你做过至少一次按场景选择 Skills 的最小尝试
- 你能判断自己是不是该进入消息平台接入
