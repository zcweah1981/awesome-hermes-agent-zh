# Governance

本目录只保留当前外部仓真正需要公开保存的最小治理文件。

一句话规则：
- 这里记录“当前外部仓真实存在什么、页面从哪里来、哪些内容不该进仓”
- 不记录内部 PM 派单、巡查、执行看板、角色节拍等内部治理资产

当前治理文件：
- `repo-policy.md`：外部仓保留原则与入仓边界
- `repo-structure.md`：当前真实目录结构与正式模块口径
- `page-source-map.md`：当前已落仓页面与来源映射

当前规则：
1. 外部仓以用户可见交付为中心，只保留正式内容、正式资源、正式治理文件。
2. 当前 docs 正式模块目录固定为：
   - `docs/01-从这开始/`
   - `docs/02-现成方案/`
   - `docs/03-国内落地/`
   - `docs/04-从OpenClaw过来/`
   - `docs/05-遇到问题/`
   - `docs/06-reference/`
3. 旧英文目录名（如 start-here / china / migrate / issues / solutions）只视为历史命名，不再作为当前正式路径口径。
4. 内部执行文件、巡查脚本、任务看板、阶段 dispatch 文件不进入外部仓。
5. governance 只记录当前真实落仓结构与来源映射，不提前铺满未来占位页。
