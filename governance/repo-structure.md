## 结构说明
1. `README.md`
- 仓库总入口，只保留当前真实存在的模块与路线入口

2. `docs/`
- 公开文档主树
- 当前正式口径为编号 + 中文目录树
- 不再以旧英文目录名作为正式路径说明

3. `governance/`
- 公开仓自己的最小治理层
- 只解释外部仓结构、保留规则和页面来源映射
- 不承载内部 PM / 巡查 / 执行控制资产

4. `packs/`
- 面向用户的可下载方案包与配套资源

## 不再采用的旧路径口径

## 一句话规则
当前外部仓结构以“编号中文 docs 树 + 最小 governance + packs”三层为准。
